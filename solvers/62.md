# Project Euler 62 Solution - Cubic Permutations

<https://projecteuler.net/problem=62>:

* [62.py](62.py)
* [62.lean](62.lean)

We need the smallest [integer cube](https://ourbigbook.com/codex/integer-cube) such that **exactly five** [permutations](https://ourbigbook.com/codex/permutation) of its [digits](https://ourbigbook.com/codex/numerical-digit) are also [integer cubes](https://ourbigbook.com/codex/integer-cube).

## Key idea
Two numbers are digit-permutations of each other iff they have the same **digit multiset**.  
So we map each [integer cube](https://ourbigbook.com/codex/integer-cube) to a **signature**: counts of [digits](https://ourbigbook.com/codex/numerical-digit) 0–9 (a 10-tuple).

All [integer cubes](https://ourbigbook.com/codex/integer-cube) sharing a signature are [permutations](https://ourbigbook.com/codex/permutation) of one another.

## Efficient search
[Integer cubes](https://ourbigbook.com/codex/integer-cube) with different digit-lengths can never be [permutations](https://ourbigbook.com/codex/permutation) of each other, so we process [integer cubes](https://ourbigbook.com/codex/integer-cube) grouped by digit-length:

- Iterate `n = 1, 2, 3, ...`, compute `n^3`.
- Compute its [digit](https://ourbigbook.com/codex/numerical-digit) signature and count how many [integer cubes](https://ourbigbook.com/codex/integer-cube) share it for the current digit-length.
- When the [integer cube](https://ourbigbook.com/codex/integer-cube) digit-length increases, finalize the previous length:
  - If any signature occurred exactly `k` times, the smallest [integer cube](https://ourbigbook.com/codex/integer-cube) in those groups is the answer.
  - Otherwise, clear the [dictionary](https://ourbigbook.com/codex/associative-array) and continue with the new length.

The first digit-length that contains a valid group yields the [global minimum](https://ourbigbook.com/codex/global-minimum), since [integer cube](https://ourbigbook.com/codex/integer-cube) values strictly grow with digit-length.

## Result
The smallest [integer cube](https://ourbigbook.com/codex/integer-cube) with exactly five cube-permutations is:
`127035954683` (which equals `5027^3`).
