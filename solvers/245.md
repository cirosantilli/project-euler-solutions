# Coresilience (Project Euler style)

## Key observations
- If `n = A * m` where `A` is the product of distinct [primes](https://ourbigbook.com/codex/prime) and `m` is the remaining [prime powers](https://ourbigbook.com/codex/prime-power), then `n - φ(n) = (A - B) * m` with `B = ∏(p-1)`.  
  The [divisibility](https://ourbigbook.com/codex/divisibility) `n - φ(n) | n - 1` forces `m = 1`, so **all valid `n` are [squarefree](https://ourbigbook.com/codex/squarefree-integer)**.
- For [squarefree](https://ourbigbook.com/codex/squarefree-integer) `n = ∏ p`, we have `φ(n) = B` and `n - φ(n) = A - B`.  
  The [unit fraction](https://ourbigbook.com/codex/unit-fraction) condition is equivalent to **`A - B` dividing `B - 1`**.
- Adding a new [prime](https://ourbigbook.com/codex/prime) `r` to a partial product `(A, B)` yields a linear condition that can be solved
  with a small [integer](https://ourbigbook.com/codex/integer) `u`:
  `r = (B(u+1)+1)/(B - u(A-B))`.  
  Using monotonicity of `r(u)` gives tight bounds for `u`.

## Algorithm
1. **[Semiprimes](https://ourbigbook.com/codex/semiprime) (`k = 2`)**  
   For [primes](https://ourbigbook.com/codex/prime) `p < q`, let `d = p + q - 1`. Then `d` must divide `p^2 - p + 1`.  
   Factor `p^2 - p + 1` ([Pollard Rho](https://ourbigbook.com/codex/pollard-s-rho-algorithm)) and test each [divisor](https://ourbigbook.com/codex/divisor) `d` to get candidate `q`.
2. **`k >= 3` [primes](https://ourbigbook.com/codex/prime)**  
   Recursively pick `k-1` [primes](https://ourbigbook.com/codex/prime) `p1 < ... < p_{k-1}`.  
   From `(A, B)` compute all admissible `u` and derive `r` with the formula above.  
   Check [primality](https://ourbigbook.com/codex/primality) and the [divisibility](https://ourbigbook.com/codex/divisibility) condition.
3. Sum all valid [composite](https://ourbigbook.com/codex/composite-number) `n <= 2e11`.

The [recursion](https://ourbigbook.com/codex/recursion) uses a power bound: if `remaining` [primes](https://ourbigbook.com/codex/prime) are still needed and the next [prime](https://ourbigbook.com/codex/prime) is `p`,
the minimal possible product is `A * p^(remaining+1)`. This bounds the search space tightly.

## Complexity
- [Number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) up to `sqrt(2e11) ≈ 4.5e5`.
- [Semiprime](https://ourbigbook.com/codex/semiprime) phase factors ~`4e4` values near `p^2` using [Pollard Rho](https://ourbigbook.com/codex/pollard-s-rho-algorithm).
- [Recursion](https://ourbigbook.com/codex/recursion) over higher `k` is small due to the power bound.

All computations complete in a few seconds on PyPy3.
