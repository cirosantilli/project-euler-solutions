# Project Euler 713 Solution - Turán's Water Heating System

<https://projecteuler.net/problem=713>:

* [713.py](713.py)

## Key ideas

### 1) Reformulate the “fuse tests” as a graph problem
- There are `N` fuses ([graph vertices](https://ourbigbook.com/codex/vertex-of-a-graph)).
- Exactly `m` are working (good [graph vertices](https://ourbigbook.com/codex/vertex-of-a-graph)), but we don’t know which.
- A “try” is choosing a pair of fuses (querying an [edge of a graph](https://ourbigbook.com/codex/edge-of-a-graph)). The system turns on **iff** both endpoints are good.

To **guarantee** success, we must choose tests so that **every** possible set of `m` good fuses contains at least one tested pair.

That means: the [graph](https://ourbigbook.com/codex/graph) of tested [graph edges](https://ourbigbook.com/codex/edge-of-a-graph) has **no [independent set](https://ourbigbook.com/codex/independent-set) of size `m`** (otherwise those `m` good [graph vertices](https://ourbigbook.com/codex/vertex-of-a-graph) could avoid all tested [graph edges](https://ourbigbook.com/codex/edge-of-a-graph)).

### 2) Turán’s theorem gives the optimal `T(N, m)`
Minimizing the number of tested [graph edges](https://ourbigbook.com/codex/edge-of-a-graph) subject to “[independence number](https://ourbigbook.com/codex/independence-number) `< m`” is equivalent (via [graph complement](https://ourbigbook.com/codex/complement-graph)) to maximizing the number of [graph edges](https://ourbigbook.com/codex/edge-of-a-graph) in a [graph](https://ourbigbook.com/codex/graph) with **no [clique](https://ourbigbook.com/codex/clique) of size `m`**.

By **[Turán's theorem](https://ourbigbook.com/codex/turan-s-theorem)**, the maximum number of [graph edges](https://ourbigbook.com/codex/edge-of-a-graph) in an `N`-vertex [graph](https://ourbigbook.com/codex/graph) with no `K_m` is achieved by the balanced `(m-1)`-partite [Turán graph](https://ourbigbook.com/codex/turan-graph).

Therefore the optimal tested-edge set is the **complement** of that [Turán graph](https://ourbigbook.com/codex/turan-graph):
- Split `N` [graph vertices](https://ourbigbook.com/codex/vertex-of-a-graph) into `k = m-1` parts as evenly as possible.
- Test all pairs **within** each part (a [disjoint union](https://ourbigbook.com/codex/disjoint-union) of [cliques](https://ourbigbook.com/codex/clique)).
- The number of tests is the sum of `C(part_size, 2)`.

This yields a direct formula for `T(N, m)`.

### 3) Fast summation for `L(N)`
We need:

`L(N) = sum_{m=2..N} T(N, m)`.

Let `k = m-1` and `q = floor(N/k)`. After simplifying the closed form, each term depends on `q = floor(N/k)` and on `k` linearly.

The classic trick is to iterate `k` in ranges where `floor(N/k)` is constant:
- For a fixed `q`, all `k` in `[k_min, k_max]` share the same quotient.
- Over that range, the sum becomes a combination of:
  - `count` of terms
  - an [arithmetic series](https://ourbigbook.com/codex/arithmetic-series) `sum(k)`

This reduces the runtime to about `O(sqrt(N))` iterations.

## What the program does
- Implements `T(N, m)` from the balanced-partition (Turán complement) formula.
- Computes `L(10^7)` using divisor-summatory grouping in `O(sqrt(N))`.
- Includes `assert` checks for the sample values given in the problem statement.
