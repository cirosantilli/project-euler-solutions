# Project Euler 550 Solution - Divisor Game

<https://projecteuler.net/problem=550>:

* [550.py](550.py)

## 1) Sprague–Grundy reduction

The game is an [impartial game](https://ourbigbook.com/codex/impartial-game) and played under [normal play convention](https://ourbigbook.com/codex/normal-play-convention).
For each pile size `m`, define its *[nimber](https://ourbigbook.com/codex/grundy-number)* ([Sprague–Grundy value](https://ourbigbook.com/codex/grundy-number)) `g(m)`.

A position with `k` piles is losing **iff** the [XOR](https://ourbigbook.com/codex/bitwise-exclusive-or) of all pile [nimbers](https://ourbigbook.com/codex/grundy-number) is zero:

\[
\text{losing} \iff g(a_1)\oplus g(a_2)\oplus\cdots\oplus g(a_k)=0
\]

So:

\[
f(n,k)= (n-1)^k - \#\{(a_i)\in[2..n]^k:\ \bigoplus g(a_i)=0\}
\]

All arithmetic is done [modulo](https://ourbigbook.com/codex/modulo-operation) `987654321`.

## 2) Nimber depends only on Ω(n)

Let \(\Omega(m)\) be the number of [prime factors](https://ourbigbook.com/codex/prime-factor) of `m` **with multiplicity**.

A move replaces one pile of size `m` by two piles whose sizes are **[proper divisors](https://ourbigbook.com/codex/proper-divisor)** of `m`.
Every [proper divisor](https://ourbigbook.com/codex/proper-divisor) `d` satisfies \(\Omega(d)\le \Omega(m)-1\).

Crucially, for a number with \(\Omega(m)=t\), for every `i` with \(1\le i < t\) there exists a [proper divisor](https://ourbigbook.com/codex/proper-divisor) `d` with \(\Omega(d)=i\)
(choose exponents in the [integer factorization](https://ourbigbook.com/codex/integer-factorization) to sum to `i`).

Using [induction](https://ourbigbook.com/codex/induction) over `t`, this implies:

- all numbers with the same `t = Ω(m)` have the same [nimber](https://ourbigbook.com/codex/grundy-number),
- so we can define a [sequence](https://ourbigbook.com/codex/sequence) `h[t] = g(m)` for any `m` with `Ω(m)=t`,
- and `h[t]` depends only on earlier `h[1..t-1]`:

\[
h(t)=\mathrm{mex}\left(\{\,h(i)\oplus h(j)\ :\ 1\le i,j < t\,\}\right)
\]

For `n = 10^7`, the maximum \(\Omega\) is only 23, so this [sequence](https://ourbigbook.com/codex/sequence) is tiny.

## 3) Counting by Ω via a linear sieve

We need how many [integers](https://ourbigbook.com/codex/integer) `m` in `[2..n]` have each value of `Ω(m)`.
This is computed in \(O(n)\) time using a **linear [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve)** that tracks:

- `spf[m]` = [smallest prime factor](https://ourbigbook.com/codex/smallest-prime-factor) of `m`
- `Ω(m)` in a byte array

This gives counts `cnt[t] = #{ m in [2..n] : Ω(m)=t }`.

## 4) XOR counting with Walsh–Hadamard transform

Let `C[x]` be how many pile sizes in `[2..n]` have [nimber](https://ourbigbook.com/codex/grundy-number) `x`.
We need the number of length-`k` [sequences](https://ourbigbook.com/codex/sequence) whose [XOR](https://ourbigbook.com/codex/bitwise-exclusive-or) is 0.

[XOR-convolution](https://ourbigbook.com/codex/xor-convolution) becomes pointwise multiplication in the [Hadamard transform](https://ourbigbook.com/codex/hadamard-transform) domain:

1. Apply [FWHT](https://ourbigbook.com/codex/fast-hadamard-transform): `F = H(C)`
2. Raise pointwise: `F[u] = F[u]^k`
3. Invert: `C_k = H^{-1}(F)` and take `C_k[0]`

With the standard (unnormalised) [FWHT](https://ourbigbook.com/codex/fast-hadamard-transform):

\[
C_k[0] = \frac{1}{N}\sum_u F[u]^k
\]

where `N` is the transform size (a power of 2).  
`987654321` is odd, so `N` is invertible [modulo](https://ourbigbook.com/codex/modulo-operation) `987654321`.
