# Project Euler 845 Solution - Prime Digit Sum

<https://projecteuler.net/problem=845>:

* [845.py](845.py)

We want `D(n)`: the *n-th* [positive integer](https://ourbigbook.com/codex/positive-integer) whose **sum of decimal [digits](https://ourbigbook.com/codex/numerical-digit) is [prime](https://ourbigbook.com/codex/prime)**, and specifically `D(10^16)`.

## Main techniques used

### 1) Digit-sum dynamic programming (counting)
Instead of scanning [integers](https://ourbigbook.com/codex/integer) one by one, we count how many [digit](https://ourbigbook.com/codex/numerical-digit) strings have a given [digit](https://ourbigbook.com/codex/numerical-digit) sum.

- Let `counts[L][s]` be the number of length-`L` [digit](https://ourbigbook.com/codex/numerical-digit) strings (allowing leading zeros) whose [digits](https://ourbigbook.com/codex/numerical-digit) sum to `s`.
- Transition:
  - Choose the last [digit](https://ourbigbook.com/codex/numerical-digit) `d` (0–9), then the previous `L-1` [digits](https://ourbigbook.com/codex/numerical-digit) must sum to `s-d`.
  - `counts[L][s] = sum_{d=0..9} counts[L-1][s-d]`.

This gives the full distribution of [digit](https://ourbigbook.com/codex/numerical-digit) sums for any remaining suffix length.

### 2) Counting valid *L*-digit positive integers
To count *[positive integers](https://ourbigbook.com/codex/positive-integer) with exactly `L` [digits](https://ourbigbook.com/codex/numerical-digit)*, the first [digit](https://ourbigbook.com/codex/numerical-digit) is restricted to `1..9`.
For each first [digit](https://ourbigbook.com/codex/numerical-digit), we add all suffixes whose total [digit](https://ourbigbook.com/codex/numerical-digit) sum is [prime](https://ourbigbook.com/codex/prime).

This lets us quickly find which digit-length contains the `n`-th valid number.

### 3) Constructing the k-th valid number (lexicographic / digit-by-digit)
Within a fixed length `L`, numeric order matches [lexicographic order](https://ourbigbook.com/codex/lexicographic-order) of [digits](https://ourbigbook.com/codex/numerical-digit).

We build the answer left-to-right:

- At each position, try [digits](https://ourbigbook.com/codex/numerical-digit) in increasing order.
- For a candidate [digit](https://ourbigbook.com/codex/numerical-digit) `d`, count how many ways the remaining suffix can be filled so that the final [digit](https://ourbigbook.com/codex/numerical-digit) sum is [prime](https://ourbigbook.com/codex/prime).
- If that count is smaller than `k`, skip those numbers (`k -= count`) and try the next [digit](https://ourbigbook.com/codex/numerical-digit).
- Otherwise, fix `d` and continue to the next position.

Because [digit](https://ourbigbook.com/codex/numerical-digit) sums are bounded (`<= 9*L`), the per-step counting is tiny and the whole construction is fast.
