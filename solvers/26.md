# Project Euler 26 Solution - Reciprocal Cycles

<https://projecteuler.net/problem=26>:

* [26.py](26.py)
* [26.lean](26.lean)
* [26.py.lean](26.py.lean)

`solve(limit=1000)` searches the positive denominators strictly below the bound, keeping the smallest denominator when lengths tie. It returns zero if no positive denominator lies below the bound. Terminating reciprocals have cycle length zero, so bounds two and three both select denominator one.

For `1/d`, the decimal expansion terminates iff `d` has no [prime factors](https://ourbigbook.com/codex/prime-factor) other than `2` and `5`.
Those factors only affect the non-repeating prefix, so we can reduce:

- Let `d' = d` with all factors of `2` and `5` removed.
- If `d' = 1`, the recurring cycle length is `0`.

When `gcd(d', 10) = 1`, the length of the recurring cycle equals the **[multiplicative order](https://ourbigbook.com/codex/multiplicative-order) of 10 [modulo](https://ourbigbook.com/codex/modulo-operation) `d'`**:
the smallest `k > 0` such that:

`10^k ≡ 1 (mod d')`.

We compute this order by iterating:
`r = 10 % d'`, then repeatedly `r = (r * 10) % d'` until `r == 1`, counting steps.

We evaluate all `d < 1000` and select the one with the maximum cycle length. The result is `983`.

The structural source proofs cover every signed upper bound and prove termination and equivalence to the reference. The factor-removal loops decrease positive denominators, and the remainder loop terminates by the existence of the multiplicative order.
