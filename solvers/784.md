# Project Euler 784 Solution - Reciprocal Pairs

<https://projecteuler.net/problem=784>:

* [784.py](784.py)

## Core number theory reduction

A pair `(p,q)` with `p < q` is **reciprocal** if there exists `r < p` such that:

- `r ≡ p⁻¹ (mod q)`  →  `r p - k q = 1` for some [integer](https://ourbigbook.com/codex/integer) `k ≥ 1`
- `r ≡ q⁻¹ (mod p)`  →  `r q - l p = 1` for some [integer](https://ourbigbook.com/codex/integer) `l ≥ 1`

This gives a [linear system](https://ourbigbook.com/codex/linear-system):

```
r p - k q = 1
-l p + r q = 1
```

Its [determinant](https://ourbigbook.com/codex/determinant) is `d = r² - k l`. Solving by [Cramer's rule](https://ourbigbook.com/codex/cramer-s-rule) yields:

- `p = (r + k) / d`
- `q = (r + l) / d`

Because `q > p` we must have `k < r`, and with `r < p` we get:

`r < (r+k)/d` ⇒ `d < 1 + k/r < 2` ⇒ **`d = 1`**.

So every reciprocal pair corresponds to [positive integers](https://ourbigbook.com/codex/positive-integer) `r,k,l` with:

- `r² - k l = 1`
- `p = r + k`, `q = r + l`, and `k < l`

Equivalently:

`k l = r² - 1`.

## Turning it into divisor enumeration

For a fixed `r ≥ 2`, let `n = r² - 1`. Every [divisor](https://ourbigbook.com/codex/divisor) `k | n` gives `l = n/k`.
The condition `p ≤ N` becomes:

`r + k ≤ N`  ⇒  `k ≤ N - r`.

Also `k < r` automatically implies `k < √(r²-1)`, hence `l > k` and `q > p`.

So we need all [divisors](https://ourbigbook.com/codex/divisor):

`1 ≤ k ≤ min(r-1, N-r)`.

Each contributes:

`p + q = (r+k) + (r+l) = 2r + k + n/k`.

## Implementation techniques

- **[Smallest prime factor](https://ourbigbook.com/codex/smallest-prime-factor) [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) ([SPF](https://ourbigbook.com/codex/smallest-prime-factor))** up to `N+1` to factor numbers `≤ N+1` quickly.
- Use `r² - 1 = (r-1)(r+1)` and the fact `gcd(r-1, r+1)` is `1` or `2`, so [prime factors](https://ourbigbook.com/codex/prime-factor) overlap only at `2`.
- **Generate [divisors](https://ourbigbook.com/codex/divisor) only up to a cutoff** (`min(r-1, N-r)`) to avoid producing large [divisors](https://ourbigbook.com/codex/divisor) that can’t satisfy `p ≤ N`.
- Accumulate the required sum directly from the [divisor](https://ourbigbook.com/codex/divisor) list.
