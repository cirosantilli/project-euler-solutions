# Project Euler 90 Solution - Cube Digit Pairs

<https://projecteuler.net/problem=90>:

* [90.py](90.py)
* [90.lean](90.lean)

We must count distinct (unordered) pairs of 6-digit [cubes](https://ourbigbook.com/codex/cube) that can display all 2-digit [square numbers](https://ourbigbook.com/codex/square-number) below 100:
01, 04, 09, 16, 25, 36, 49, 64, 81.

Key observations:
- Each [cube](https://ourbigbook.com/codex/cube) is a [set](https://ourbigbook.com/codex/set) of 6 distinct [digits](https://ourbigbook.com/codex/numerical-digit) from 0..9, so there are only C(10,6)=210 possible [cubes](https://ourbigbook.com/codex/cube).
- [Digits](https://ourbigbook.com/codex/numerical-digit) 6 and 9 are interchangeable by rotation; for checking displayability we treat any [cube](https://ourbigbook.com/codex/cube) containing 6 or 9 as containing **both**.
- A [square number](https://ourbigbook.com/codex/square-number) `XY` is displayable if one [cube](https://ourbigbook.com/codex/cube) has X and the other has Y (either orientation).

[Algorithm](https://ourbigbook.com/codex/algorithm):
1. Enumerate all 210 [cubes](https://ourbigbook.com/codex/cube) as [bitmasks](https://ourbigbook.com/codex/bit-mask).
2. Expand each [bit mask](https://ourbigbook.com/codex/bit-mask) so that presence of 6 or 9 implies presence of both.
3. For every [unordered pair](https://ourbigbook.com/codex/unordered-pair) of [cubes](https://ourbigbook.com/codex/cube) (i ≤ j), test all required [square number](https://ourbigbook.com/codex/square-number) digit-pairs.
4. Count pairs that satisfy all [square numbers](https://ourbigbook.com/codex/square-number).

This runs very fast because there are only 210·211/2 = 22,155 [cube](https://ourbigbook.com/codex/cube) pairs to check.
The computed answer is `1217`.
