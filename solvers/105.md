# Project Euler 105 Solution - Special Subset Sums: Testing

<https://projecteuler.net/problem=105>:

* [105.py](105.py)

We must identify which given [sets](https://ourbigbook.com/codex/set) are **[special sum sets](https://ourbigbook.com/codex/special-sum-set)**, meaning that for any two non-empty **[disjoint](https://ourbigbook.com/codex/disjoint-sets)** [subsets](https://ourbigbook.com/codex/subset) `B` and `C`:

1. `sum(B) != sum(C)`
2. If `|B| > |C|` then `sum(B) > sum(C)`

### Key ideas

#### Fast check for rule (2)
For [positive integers](https://ourbigbook.com/codex/positive-integer), rule (2) is equivalent to checking only the “worst-case” comparisons:
for each `k = 1..n-1`,

- [sum](https://ourbigbook.com/codex/sum) of the **smallest** `k+1` elements must be greater than
- [sum](https://ourbigbook.com/codex/sum) of the **largest** `k` elements

If this fails for any `k`, the [set](https://ourbigbook.com/codex/set) cannot be special.

#### Checking rule (1) by subset enumeration (n ≤ 12)
Each [set](https://ourbigbook.com/codex/set) has at most 12 elements, so enumerating all non-empty [subsets](https://ourbigbook.com/codex/subset) is feasible (`2^12 - 1 = 4095`).

- Represent each [subset](https://ourbigbook.com/codex/subset) by a [bitmask](https://ourbigbook.com/codex/bit-mask).
- Compute its [sum](https://ourbigbook.com/codex/sum).
- Store [bit masks](https://ourbigbook.com/codex/bit-mask) per [sum](https://ourbigbook.com/codex/sum).
- If another [subset](https://ourbigbook.com/codex/subset) has the same [sum](https://ourbigbook.com/codex/sum), check whether the two [bit masks](https://ourbigbook.com/codex/bit-mask) are [disjoint](https://ourbigbook.com/codex/disjoint-sets) (`mask1 & mask2 == 0`).
  - If [disjoint](https://ourbigbook.com/codex/disjoint-sets), rule (1) is violated.

### Complexity
For each [set](https://ourbigbook.com/codex/set): `O(n * 2^n)` with `n ≤ 12`, easily fast for 100 [sets](https://ourbigbook.com/codex/set).

### Output
The program reads `0105_sets.txt` (or `sets.txt` as a fallback), [sums](https://ourbigbook.com/codex/sum) the totals of all special [sets](https://ourbigbook.com/codex/set), and prints the final answer.
