# Project Euler 27 Solution - Quadratic Primes

<https://projecteuler.net/problem=27>:

* [27.py](27.py)
* [27.lean](27.lean)

We search coefficients `a, b` in:
- `|a| < 1000`  →  `a ∈ [-999, 999]`
- `|b| ≤ 1000`

for the [quadratic polynomial](https://ourbigbook.com/codex/quadratic-polynomial) `n² + a n + b` that produces the longest run of [primes](https://ourbigbook.com/codex/prime-number) for consecutive `n = 0, 1, 2, ...`.

### Key pruning/insights
1. **At n = 0** the expression equals `b`.  
   Therefore `b` must itself be a (positive) [prime](https://ourbigbook.com/codex/prime-number). This reduces `b` to the 168 [primes](https://ourbigbook.com/codex/prime-number) ≤ 1000.

2. **[Integer parity](https://ourbigbook.com/codex/integer-parity) [pruning](https://ourbigbook.com/codex/search-pruning)** (for faster iteration):
   - If `b` is odd (all [primes](https://ourbigbook.com/codex/prime-number) except 2), then for `n = 1` the value is `1 + a + b`.
     Since `1 + b` is even, `a` must be **odd** to make `1 + a + b` odd (and possibly [prime](https://ourbigbook.com/codex/prime-number)).
   - If `b = 2`, then `1 + b = 3` is odd, so `a` must be **even**.

3. **Fast [primality testing](https://ourbigbook.com/codex/primality-testing)**:
   - Use [trial division](https://ourbigbook.com/codex/trial-division) by a precomputed list of [primes](https://ourbigbook.com/codex/prime-number) (via [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve)), plus [memoization](https://ourbigbook.com/codex/memoization) (`cache`) of [primality](https://ourbigbook.com/codex/primality) results.
   - The [quadratic polynomial](https://ourbigbook.com/codex/quadratic-polynomial) values in this problem stay small (≈ a few million), so this is efficient.

### Algorithm
For each candidate [prime](https://ourbigbook.com/codex/prime-number) `b` and each allowed `a` (with [integer parity](https://ourbigbook.com/codex/integer-parity) [pruning](https://ourbigbook.com/codex/search-pruning)):
- Quickly check whether `n=1` produces a [prime](https://ourbigbook.com/codex/prime-number).
- If it passes, count consecutive [primes](https://ourbigbook.com/codex/prime-number) starting from `n=0` until the expression becomes composite.
- Track the maximum run length and corresponding `(a, b)`, then output `a*b`.
