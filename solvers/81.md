# Project Euler 81 Solution - Path Sum: Two Ways

We need the minimal [graph path](https://ourbigbook.com/codex/graph-path) [sum](https://ourbigbook.com/codex/sum) from the top-left to the bottom-right of a rectangular [matrix](https://ourbigbook.com/codex/matrix), moving only **right** and **down**.

## Key Insight (Dynamic Programming)
Because movement is restricted to right/down, the best [graph path](https://ourbigbook.com/codex/graph-path) to any cell `(i, j)` must come from exactly one of:
- the cell above `(i-1, j)`, or
- the cell to the left `(i, j-1)`.

So:
`best(i, j) = matrix[i][j] + min(best(i-1, j), best(i, j-1))`

We compute this efficiently in `O(rows * columns)` time, keeping only one row of [DP](https://ourbigbook.com/codex/dynamic-programming) values (`O(columns)` memory).

The shared argument is a rectangular `list[list[int]]`. Cell values may be negative because right/down movement cannot form a cycle. Empty matrices and matrices with zero columns return zero. The solver preserves the input rows, including shared row objects.
