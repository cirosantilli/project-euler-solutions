# Project Euler 83 Solution - Path Sum: Four Ways

<https://projecteuler.net/problem=83>:

* [83.py](83.py)
* [Python equivalence proof](83.py.lean)
* [83.lean](83.lean)

We need the minimum-cost [graph path](https://ourbigbook.com/codex/graph-path) from the top-left cell to the bottom-right cell in a grid, where moves are allowed in four directions (up/down/left/right). Each cell value is a non-negative cost, and the [graph path](https://ourbigbook.com/codex/graph-path) [sum](https://ourbigbook.com/codex/sum) includes both the starting and ending cells.

### Key insight
This is a shortest-path problem on a [weighted graph](https://ourbigbook.com/codex/weighted-graph):
- Each grid cell is a [graph vertex](https://ourbigbook.com/codex/graph-vertex).
- [Edges](https://ourbigbook.com/codex/edge) connect adjacent cells (4-neighborhood).
- Moving into a neighbor adds the neighbor cell's value to the total cost.
- Start distance is the value of the top-left cell.

Because all [edge](https://ourbigbook.com/codex/edge) weights are non-negative, [Dijkstra's algorithm](https://ourbigbook.com/codex/dijkstra-s-algorithm) finds the optimal [graph path](https://ourbigbook.com/codex/graph-path) efficiently.

### Approach
- Parse the [matrix](https://ourbigbook.com/codex/matrix) (CSV per row).
- Run Dijkstra with a [priority queue](https://ourbigbook.com/codex/priority-queue) (`heapq`) over the `N*M` [graph vertices](https://ourbigbook.com/codex/graph-vertex).
- Maintain a distance [array](https://ourbigbook.com/codex/array) and a visited [array](https://ourbigbook.com/codex/array).
- Stop as soon as the bottom-right [graph vertex](https://ourbigbook.com/codex/graph-vertex) is finalized (popped as the smallest unvisited distance).

### Complexity
For an `80x80` grid (6400 [graph vertices](https://ourbigbook.com/codex/graph-vertex)), Dijkstra runs very fast:
- Time: `O(V log V + E log V)` with `E ≈ 4V`
- Memory: `O(V)`


### Generalized inputs and proof

The shared input is a rectangular `list[list[int]]` with nonnegative entries. Empty dimensions return zero. The [Python equivalence proof](83.py.lean) proves termination and observable equivalence to the [reference implementation](../data/project-euler-statements/data/py/project_euler_statements/p83.py.lean) for every such input, including shared rows. Both calls preserve caller objects; their private allocations may differ. The proofs use only standard Lean axioms, without whole-program computation or fixed input bounds.

The initial distance bound is the sum of all cell costs plus one. [Removing cycles](../ProjectEulerSolutions/Lib/NonnegativeWalkBounds.lean) cannot increase a path's cost, so a simple path visits at most `rows * columns` cells and costs less than that bound. The [grid minimum proof](../ProjectEulerSolutions/Lib/GridShortestPaths.lean) shows that the reference attains a shortest walk. The [array Dijkstra model](../ProjectEulerSolutions/Equiv/P83.lean) is also structurally equivalent to the reference.

The [complete source execution](83.py.lean.d/Execution.lean) covers validation, initialization, the priority-queue loop, and early goal return. Its [runtime invariant](83.py.lean.d/RuntimeState.lean) connects the actual mutable buffers and tuple queue to path witnesses, settled minima, and frontier coverage. The [heap contracts](83.py.lean.d/OrderedQueue.lean) follow both concrete sift phases, retain tuple identities and stale duplicate entries, and establish that each fresh pop has the current minimum distance.

The [neighbor bridge](83.py.lean.d/NeighborGrid.lean) proves that all four Python branches perform the mathematical Dijkstra update. Settled neighbors cannot improve, justifying Python's omitted visited-neighbor guard. The source and model enumerate neighbors in different orders; [commuting relaxations](../ProjectEulerSolutions/Lib/DijkstraRelaxationOrder.lean) justify their agreement, including at grid boundaries.

The [source-loop termination proof](83.py.lean.d/Loop.lean) uses five times the number of unvisited cells plus the queue length. A fresh iteration marks one cell and adds at most four queue entries; a stale iteration removes one entry. Every continuing iteration therefore decreases the measure. Frontier coverage prevents the queue from becoming empty while the goal remains unvisited, and the first fresh goal pop attains the reference minimum.
