## Amicable Numbers (sum under 10000)

We need the [sum](https://ourbigbook.com/codex/sum) of all numbers `a < 10000` such that there exists `b != a` with:
- `d(a) = b`
- `d(b) = a`
where `d(n)` is the [sum of proper divisors](https://ourbigbook.com/codex/proper-divisor-sum) of `n`.

### Key ideas
1. **Fast [divisor-sum](https://ourbigbook.com/codex/divisor-sum) precomputation ([number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve))**
   - Build an [array](https://ourbigbook.com/codex/array) `divsum[n]` for all `n < 10000`, where `divsum[n]` is the [sum of proper divisors](https://ourbigbook.com/codex/proper-divisor-sum).
   - For each potential [divisor](https://ourbigbook.com/codex/divisor) `i`, add it to all [multiples](https://ourbigbook.com/codex/integer-multiple) `2i, 3i, ...` (so it remains a [proper divisor](https://ourbigbook.com/codex/proper-divisor)).

2. **Amicable check**
   - For each `a` from 2 to 9999:
     - compute `b = d(a)`
     - if `b != a` and `d(b) == a`, then `a` is an [amicable number](https://ourbigbook.com/codex/amicable-number) and is included in the total.
   - If `b` happens to be outside the [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) range, compute `d(b)` using [prime factorization](https://ourbigbook.com/codex/prime-factorization) and the [divisor-sum](https://ourbigbook.com/codex/divisor-sum) formula `sigma(n) - n`.

### Complexity
- [Number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) computation: about `N log N` operations with `N = 10000` (very fast).
- Amicable checks: `O(N)` plus occasional factorization for out-of-range `b`.

The program prints the final [sum](https://ourbigbook.com/codex/sum): **31626**.
