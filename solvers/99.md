# Project Euler 99 Solution - Largest Exponential

<https://projecteuler.net/problem=99>:

* [99.py](99.py)
* [99.lean](99.lean)

Logarithms turn power comparison into comparing `exponent * log(base)`, but floating-point rounding can merge different values. For example, the exact integers `2**53` and `2**53 + 1` have distinct order even when their computed logarithms agree.

The Python solver compares powers using integer intervals. A triple `(lower, upper, shift)` represents

$$\mathrm{lower}\,2^{\mathrm{shift}} \le b^e \le \mathrm{upper}\,2^{\mathrm{shift}}.$$

Exponentiation by squaring multiplies the lower and upper endpoints separately. After each multiplication, the solver keeps a chosen number of leading bits: it rounds the lower endpoint down, rounds the upper endpoint up, and adds the removed bit count to `shift`. Thus the interval always contains the exact power.

To compare two intervals, first compare endpoint bit lengths plus their shifts. Only endpoints with equal total bit lengths need aligned mantissas; this avoids allocating an integer containing all the shifted zeroes. Disjoint intervals determine the order. Overlapping intervals cause the precision to double. If both intervals become exact, their endpoints determine equality as well as order.

This process terminates: once precision is large enough to hold both powers, no intermediate multiplication loses bits. Most inputs can be distinguished at much smaller precision. Each attempt performs a logarithmic number of multiplications in the exponents, on integers whose sizes are controlled by the current precision.

Before comparing positive powers, divide both exponents by their greatest common divisor. Raising positive numbers to the same positive power preserves order, so this reduction is exact and can make ties inexpensive. Zero exponents and base one give the value one. Negative exponents reverse the comparison of the corresponding positive powers; opposite signs can be compared directly with one.

The solver scans the input once and updates the winning one-based index only on a strict improvement, retaining the first entry on ties. An empty input returns zero. The [reference](../data/project-euler-statements/data/py/project_euler_statements/p99.py) constructs exact integer numerators and denominators and compares their cross products.
