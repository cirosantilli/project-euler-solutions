# Project Euler 40 Solution - Champernowne's Constant

<https://projecteuler.net/problem=40>:

* [40.py](40.py)
* [40.lean](40.lean)

[Champernowne's constant](https://ourbigbook.com/codex/champernowne-constant) is formed by concatenating [positive integers](https://ourbigbook.com/codex/positive-integer):
`0.1234567891011121314...`

We need the [product](https://ourbigbook.com/codex/product):  
`d1 * d10 * d100 * d1000 * d10000 * d100000 * d1000000`  
where `dn` is the `n`-th [digit](https://ourbigbook.com/codex/numerical-digit) of the [fractional part](https://ourbigbook.com/codex/fractional-part) (1-indexed).

## Key idea
Instead of building the [string](https://ourbigbook.com/codex/string), locate the [digit](https://ourbigbook.com/codex/numerical-digit) position mathematically by scanning blocks of numbers with the same digit length:

- 1-digit numbers: `1..9` contribute `9 * 1` [digits](https://ourbigbook.com/codex/numerical-digit)
- 2-digit numbers: `10..99` contribute `90 * 2` [digits](https://ourbigbook.com/codex/numerical-digit)
- 3-digit numbers: `100..999` contribute `900 * 3` [digits](https://ourbigbook.com/codex/numerical-digit)
- etc.

For a given `n`:
1. Subtract whole blocks until `n` lies inside a block of `k`-[digit](https://ourbigbook.com/codex/numerical-digit) numbers.
2. Determine which number in that block: `(n-1)//k`
3. Determine which [digit](https://ourbigbook.com/codex/numerical-digit) inside that number: `(n-1)%k`
4. Extract the [digit](https://ourbigbook.com/codex/numerical-digit) by converting that number to a [string](https://ourbigbook.com/codex/string).

This runs in `O(log n)` time per query and easily handles `n = 1,000,000`.
