# Project Euler 16 Solution - Power Digit Sum

<https://projecteuler.net/problem=16>:

* [16.py](16.py)
* [16.lean](16.lean)

We need the sum of the decimal digits of \(2^{1000}\).

## Key idea
Python [integers](https://ourbigbook.com/codex/integer) have [arbitrary precision](https://ourbigbook.com/codex/arbitrary-precision-arithmetic), so we can compute \(2^{1000}\) exactly using `2 ** 1000`, convert it to a [string](https://ourbigbook.com/codex/string), and [sum](https://ourbigbook.com/codex/sum) its characters as [digits](https://ourbigbook.com/codex/numerical-digit).

## Steps
1. Compute `n = 2 ** 1000`.
2. Convert to decimal string `str(n)`.
3. [Sum](https://ourbigbook.com/codex/sum) `int(ch)` for each character `ch`.

A small assert validates the example: the [digit sum](https://ourbigbook.com/codex/digit-sum) of \(2^{15}\) is 26.

The program prints the final result.
