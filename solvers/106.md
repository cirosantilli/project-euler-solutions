# Project Euler 106 Solution - Special Subset Sums: Meta-testing

<https://projecteuler.net/problem=106>:

* [106.py](106.py)

We need to count how many disjoint subset pairs must be checked for equal [sums](https://ourbigbook.com/codex/sum), given:

- The [set](https://ourbigbook.com/codex/set) is [strictly increasing](https://ourbigbook.com/codex/strictly-increasing).
- Rule (2) is already guaranteed: if `|B| > |C|` then `S(B) > S(C)`.

### Key observations

1. If `|B| != |C|`, then rule (2) already implies `S(B) != S(C)`.  
   So only pairs with `|B| = |C| = k` can possibly violate rule (1).

2. Even for equal sizes `k`, some pairs are **forced unequal** without checking [sums](https://ourbigbook.com/codex/sum):
   If, after [sorting](https://ourbigbook.com/codex/sorting) both [subsets](https://ourbigbook.com/codex/subset), every element of one [subset](https://ourbigbook.com/codex/subset) is larger than the
   corresponding element of the other [subset](https://ourbigbook.com/codex/subset), then its [sum](https://ourbigbook.com/codex/sum) is larger as well.

3. For a fixed chosen [set](https://ourbigbook.com/codex/set) of `2k` elements, count:
   - Total **unordered** [set partitions](https://ourbigbook.com/codex/set-partition) into two `k`-[subsets](https://ourbigbook.com/codex/subset) is `C(2k,k)/2`.
   - The number of “elementwise comparable” [set partitions](https://ourbigbook.com/codex/set-partition) equals the **[Catalan number](https://ourbigbook.com/codex/catalan-number)**
     `Cat(k) = C(2k,k)/(k+1)`. (This is the standard Dyck-word / [balanced-parentheses](https://ourbigbook.com/codex/balanced-parentheses) count.)

So for each `k`:
```
tests_per_2k_choice = C(2k,k)/2 - Cat(k)
```
and we can choose the involved `2k` elements in `C(n,2k)` ways.

### Final formula

For `n = 12`:
```
Answer = sum_{k=2..6} C(12,2k) * ( C(2k,k)/2 - Cat(k) )
```

The program computes this value and prints the result.
