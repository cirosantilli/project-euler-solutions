# Project Euler 451 Solution - Modular Inverses

<https://projecteuler.net/problem=451>:

* [451.py](451.py)

We need the largest `m < n - 1` such that `m` is its own inverse [modulo](https://ourbigbook.com/codex/modulo-operation) `n`.
This is equivalent to

\[
m^2 \equiv 1 \pmod n.
\]

The excluded value `n - 1` is the always-present root `-1`.

## Local Roots

For an [odd prime](https://ourbigbook.com/codex/odd-prime) power `p^e`, the only roots of `x^2 = 1` are

\[
x \equiv \pm 1 \pmod {p^e}.
\]

Powers of `2` are the special case:

* [modulo](https://ourbigbook.com/codex/modulo-operation) `2`, there is only one root
* [modulo](https://ourbigbook.com/codex/modulo-operation) `4`, the roots are `+1` and `-1`
* [modulo](https://ourbigbook.com/codex/modulo-operation) `2^e` for `e >= 3`, the roots are `+-1` and `2^(e-1) +- 1`

## CRT Projectors

Factor

\[
n=\prod q_j
\]

into [prime powers](https://ourbigbook.com/codex/prime-power). For one factor `q`, set `M = n/q` and choose

\[
E \equiv M^{-1}M \pmod n,
\]

where the inverse is taken [modulo](https://ourbigbook.com/codex/modulo-operation) `q`. This value is `1` [modulo](https://ourbigbook.com/codex/modulo-operation) `q` and `0`
[modulo](https://ourbigbook.com/codex/modulo-operation) every other prime-power factor, so it changes only the local residue for
that factor.

The code starts from the global root `-1`, represented by `n - 1`. For each
prime-power factor, it adds the lifted offsets that move the local root from
`-1` to the other local roots. The resulting list is the full set of roots of
`x^2 = 1 (mod n)`.

The answer `I(n)` is the largest generated root below `n - 1`.

## Implementation Notes

The performance-sensitive part is not the [CRT](https://ourbigbook.com/codex/chinese-remainder-theorem) formula itself, but avoiding
unnecessary allocation while applying it for every `n <= 20,000,000`.

The solver uses an Eratosthenes-style [smallest-prime-factor](https://ourbigbook.com/codex/smallest-prime-factor) table.  During
`I(n)`, it strips each [prime power](https://ourbigbook.com/codex/prime-power) directly from a temporary copy of `n` instead
of first constructing a factor list.  It also updates the current best root as
new [CRT](https://ourbigbook.com/codex/chinese-remainder-theorem) [combinations](https://ourbigbook.com/codex/combination-combinatorics) are generated, so there is no final scan over the root
list.  [Modular inverses](https://ourbigbook.com/codex/modular-inverse) are computed with a small [extended-GCD](https://ourbigbook.com/codex/extended-euclidean-algorithm) routine for the
prime-power cofactor projector.

## Checks

The implementation verifies the examples `I(7)=1`, `I(15)=11`, and `I(100)=51`.
