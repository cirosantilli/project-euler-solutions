# Project Euler 12 Solution - Highly Divisible Triangular Number

<https://projecteuler.net/problem=12>:

* [12.py](12.py)
* [12.lean](12.lean)

We seek the first [triangular number](https://ourbigbook.com/codex/triangular-number)  
\(T_n = \frac{n(n+1)}{2}\)  
with more than 500 [divisors](https://ourbigbook.com/codex/divisor).

### Key insights

1. **[Coprimality](https://ourbigbook.com/codex/coprimality) of consecutive [integers](https://ourbigbook.com/codex/integer)**  
   \(\gcd(n, n+1) = 1\).  
   Since \(T_n\) divides by 2, we rewrite:
   - If \(n\) is even: \(T_n = (n/2)\cdot(n+1)\)
   - If \(n\) is odd:  \(T_n = n\cdot((n+1)/2)\)

   In both cases the two factors are [coprime](https://ourbigbook.com/codex/coprime), so:
   \[
   d(T_n) = d(a)\cdot d(b)
   \]
   where \(d(x)\) is the [number of divisors](https://ourbigbook.com/codex/divisor-count) of \(x\).

2. **Computing the [divisor count](https://ourbigbook.com/codex/divisor-count) via [prime factorization](https://ourbigbook.com/codex/prime-factorization)**  
   If \(m = \prod p_i^{e_i}\), then:
   \[
   d(m) = \prod (e_i + 1)
   \]
   We compute this by [trial division](https://ourbigbook.com/codex/trial-division) using a growing list of [primes](https://ourbigbook.com/codex/prime-number).

3. **Incremental search over n**  
   Iterate \(n = 1,2,3,\dots\), compute \(d(T_n)\) using the [coprime](https://ourbigbook.com/codex/coprime) split, and stop
   when it exceeds the threshold.

### Result

The program prints the first [triangular number](https://ourbigbook.com/codex/triangular-number) with more than 500 [divisors](https://ourbigbook.com/codex/divisor):
`76576500`.

An assertion is included for the example in the statement:
the first [triangular number](https://ourbigbook.com/codex/triangular-number) with more than 5 [divisors](https://ourbigbook.com/codex/divisor) is `28`.
