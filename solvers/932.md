# Project Euler 932 Solution - $2025$

<https://projecteuler.net/problem=932>:

* [932.py](932.py)

## Problem Summary

We seek [square numbers](https://ourbigbook.com/codex/square-number) $n$ below $10^{16}$ whose [decimal expansion](https://ourbigbook.com/codex/decimal-expansion) can be split into a nonempty left part and a nonempty right part so that the [square root](https://ourbigbook.com/codex/square-root) is the sum of those two parts. Writing $n=s^2$, the split has the form

$$n=a10^d+b,\qquad s=a+b,$$

where $b$ has exactly $d$ [digits](https://ourbigbook.com/codex/digit). The title example is $2025=20\mid 25$, because $20+25=45=\sqrt{2025}$. The task is to add all such squares, not all successful splits, so duplicates must be counted only once.

This is closely related to base-10 Kaprekar numbers, but the efficient way to solve the [Project Euler problem](https://ourbigbook.com/codex/project-euler-problem) is to search over the root $s$ and describe the allowed values of $s$ by [modular arithmetic](https://ourbigbook.com/codex/modular-arithmetic).

## Mathematical Approach

Fix a split length $d$ and write

$$M_d=10^d-1.$$

For that fixed $d$, the whole problem is to characterize the roots $s$ for which the split exists.

### Eliminating the two decimal pieces

From $n=s^2=a10^d+b$ and $s=a+b$, substitute $b=s-a$:

$$s^2=a10^d+(s-a)=s+a(10^d-1).$$

Therefore

$$a=\frac{s(s-1)}{M_d},\qquad b=s-a.$$

This already gives the key [divisibility](https://ourbigbook.com/codex/divisibility) condition

$$M_d\mid s(s-1).$$

Once $a$ is an [integer](https://ourbigbook.com/codex/integer) and the [digit](https://ourbigbook.com/codex/digit) conditions hold, the reconstruction is automatic, because

$$a10^d+b=a(10^d-1)+s=s(s-1)+s=s^2.$$

So the search is not really over $(a,b)$; it is over roots $s$ satisfying one [integer congruence](https://ourbigbook.com/codex/integer-congruence) and a few [digit](https://ourbigbook.com/codex/digit) inequalities.

### Why every prime power allows only residue $0$ or $1$

Factor $M_d$ into pairwise [coprime](https://ourbigbook.com/codex/coprime) [prime powers](https://ourbigbook.com/codex/prime-power):

$$M_d=\prod_{i=1}^{t} p_i^{e_i}.$$

Consecutive [integers](https://ourbigbook.com/codex/integer) are [coprime](https://ourbigbook.com/codex/coprime), so $\gcd(s,s-1)=1$. If $p_i^{e_i}$ divides the product $s(s-1)$, then the full [prime power](https://ourbigbook.com/codex/prime-power) must divide exactly one of the two consecutive factors. Hence every valid root satisfies

$$s\equiv 0,1 \pmod{p_i^{e_i}},\qquad 1\le i\le t.$$

That is the crucial structural simplification. Instead of examining all roots below $10^8$, we only have to choose, for every distinct prime-power factor of $10^d-1$, whether $s$ is congruent to $0$ or to $1$.

### Combining the local choices with the Chinese remainder theorem

Each [prime power](https://ourbigbook.com/codex/prime-power) contributes two local options, so a fixed $d$ leads to a collection of global [residue classes](https://ourbigbook.com/codex/residue-class). The [Chinese remainder theorem](https://ourbigbook.com/codex/chinese-remainder-theorem) merges those local choices into unique [integer congruences](https://ourbigbook.com/codex/integer-congruence)

$$s\equiv r \pmod{M_d}.$$

Every admissible root for that split length lies in one [arithmetic progression](https://ourbigbook.com/codex/arithmetic-progression)

$$s=r+kM_d,\qquad k\ge 0.$$

The implementations therefore build all [CRT](https://ourbigbook.com/codex/chinese-remainder-theorem) [residue classes](https://ourbigbook.com/codex/residue-class) first and only then test the corresponding candidate roots.

### The digit bounds that finish the reduction

The modular condition is necessary, but not sufficient. We still need the split to be a genuine decimal split with both parts nonzero and with no leading zeros in the right block.

Because $b=s-a\gt 0$, we need $a\lt s$. Using the formula for $a$,

$$\frac{s(s-1)}{M_d}\lt s,$$

which simplifies to

$$s\lt 10^d.$$

So every valid root must satisfy

$$2\le s\le \min\!\bigl(\lfloor\sqrt{10^{16}-1}\rfloor,\;10^d-1\bigr).$$

There is also an exact range for the right part:

$$1\le b\lt 10 \quad(d=1),\qquad 10^{d-1}\le b\lt 10^d \quad(d\ge 2).$$

The second condition is what rules out right parts such as $01$ or $0017$: they are numerically positive, but they do not occupy exactly $d$ [digits](https://ourbigbook.com/codex/digit).

### Worked example: the title number $2025$

Take $d=2$. Then

$$M_2=10^2-1=99=9\cdot 11.$$

For the [prime powers](https://ourbigbook.com/codex/prime-power) $9$ and $11$, the only local residues are $0$ and $1$. [CRT](https://ourbigbook.com/codex/chinese-remainder-theorem) therefore produces four global [residue classes](https://ourbigbook.com/codex/residue-class) [modulo](https://ourbigbook.com/codex/modulo-operation) $99$:

$$s\equiv 0,\ 1,\ 45,\ 55 \pmod{99}.$$

Since $s\lt 100$, only the representatives $45$, $55$, and $99$ can matter.

For $s=45$,

$$a=\frac{45\cdot 44}{99}=20,\qquad b=45-20=25,$$

so $45^2=2025=20\mid 25$.

For $s=55$,

$$a=\frac{55\cdot 54}{99}=30,\qquad b=55-30=25,$$

so $55^2=3025=30\mid 25$.

For $s=99$,

$$a=\frac{99\cdot 98}{99}=98,\qquad b=1,$$

but $b=1$ is not a two-digit number, so the split $98\mid 01$ is invalid. This example shows exactly why the [algorithm](https://ourbigbook.com/codex/algorithm) needs both pieces: [CRT](https://ourbigbook.com/codex/chinese-remainder-theorem) generates the modular candidates, and the [digit](https://ourbigbook.com/codex/digit) checks remove the false positives.

### Why the final sum must be de-duplicated

The [Project Euler](https://ourbigbook.com/codex/project-euler) question asks for the sum of the numbers $n$, not the sum over all successful pairs $(n,d)$. A square can satisfy the defining property for more than one split length, so the accepted values $n=s^2$ must be stored as distinct [integers](https://ourbigbook.com/codex/integer) before the final [addition](https://ourbigbook.com/codex/addition) is performed.

## How the Code Works

### Precomputation

The C++, Python, and Java implementations precompute powers of $10$, the root bound $\lfloor\sqrt{10^{16}-1}\rfloor$, and a [prime](https://ourbigbook.com/codex/prime) table large enough to factor every repunit-like modulus $10^d-1$ with $1\le d\le 15$.

### Per-split residue construction

For each split length $d$, the implementation factors $10^d-1$ into [prime powers](https://ourbigbook.com/codex/prime-power). It starts from the trivial [integer congruence](https://ourbigbook.com/codex/integer-congruence) [modulo](https://ourbigbook.com/codex/modulo-operation) $1$ and repeatedly merges the two local possibilities $s\equiv0$ and $s\equiv1$ [modulo](https://ourbigbook.com/codex/modulo-operation) each [prime power](https://ourbigbook.com/codex/prime-power). After all merges, the result is the complete [CRT](https://ourbigbook.com/codex/chinese-remainder-theorem) list of admissible residues $r$ [modulo](https://ourbigbook.com/codex/modulo-operation) $10^d-1$.

### Candidate testing and unique accumulation

Each [residue class](https://ourbigbook.com/codex/residue-class) produces a candidate root $s$ in the allowed range. From that root, the implementation computes $a=\frac{s(s-1)}{10^d-1}$, then $b=s-a$, checks positivity, checks the exact [digit](https://ourbigbook.com/codex/digit) range of $b$, reconstructs $n=s^2$, and inserts $n$ into a [hash set](https://ourbigbook.com/codex/hash-set). The C++ implementation also includes small direct-search self-checks for shorter [digit](https://ourbigbook.com/codex/digit) limits before producing the final $10^{16}$ answer.

## Complexity Analysis

Let $\omega(M_d)$ be the number of distinct [prime divisors](https://ourbigbook.com/codex/prime-divisor) of $M_d=10^d-1$. For a fixed $d$, the [CRT](https://ourbigbook.com/codex/chinese-remainder-theorem) stage creates exactly $2^{\omega(M_d)}$ [residue classes](https://ourbigbook.com/codex/residue-class), because each [prime power](https://ourbigbook.com/codex/prime-power) contributes the binary choice $0$ or $1$.

For this particular problem size, the bound $s\lt 10^d$ means that each [residue class](https://ourbigbook.com/codex/residue-class) contributes at most one relevant root candidate. As a result, after factorization the remaining work is essentially one constant-time arithmetic check per [CRT](https://ourbigbook.com/codex/chinese-remainder-theorem) residue. [Memory usage](https://ourbigbook.com/codex/memory-usage) is small: a [prime](https://ourbigbook.com/codex/prime) list, a temporary residue list, and the set of accepted squares. This is far smaller than a naive search over all roots up to $10^8$ and all possible split positions.
