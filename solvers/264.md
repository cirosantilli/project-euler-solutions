# Project Euler 264 Solution - Triangle Centres

<https://projecteuler.net/problem=264>:

* [264.py](264.py)

This repository contains a fast, self‑contained solver for **Project Euler 264**.

## Key observations

### 1) Orthocenter as a vector sum
Place the [circumcenter](https://ourbigbook.com/codex/circumcenter) at the origin and represent the [polygon vertices](https://ourbigbook.com/codex/vertex-of-a-polygon) by [position vectors](https://ourbigbook.com/codex/position-vector)
`a, b, c ∈ Z²`.

For a [triangle](https://ourbigbook.com/codex/triangle) whose **[circumcenter](https://ourbigbook.com/codex/circumcenter) is the origin**, the [orthocenter](https://ourbigbook.com/codex/orthocenter) [vector](https://ourbigbook.com/codex/vector) is

`h = a + b + c`.

Here `h = (5, 0)`, so we must find [integer](https://ourbigbook.com/codex/integer) [vectors](https://ourbigbook.com/codex/vector) `a, b, c` on the **same [circle](https://ourbigbook.com/codex/circle)**
(`|a| = |b| = |c|`) satisfying `a + b + c = (5, 0)`.

### 2) Reduce a 3‑point condition to an orthogonal 2‑vector condition
Let

* `d = b + c` (so `a = h − d`)
* `P = b − c` (so `b = (d + P)/2`, `c = (d − P)/2`)

Because `|b| = |c|`, the cross term cancels and we get

* `d · P = 0`  (they are perpendicular)

and a short algebraic manipulation gives a **closed form** for the required
length of `P` in terms of `d = (dx, dy)`:

`|P|² = 3|d|² − 40·dx + 100`.

So the problem becomes:

*enumerate [integer](https://ourbigbook.com/codex/integer) [vectors](https://ourbigbook.com/codex/vector) `d` for which there exists an [integer](https://ourbigbook.com/codex/integer) [vector](https://ourbigbook.com/codex/vector) `P`
perpendicular to `d` with that exact squared length, and such that `(d ± P)/2`
are [lattice points](https://ourbigbook.com/codex/lattice-point).*

### 3) Parameterize perpendicular lattice vectors using a primitive direction
Write `d = g(p, q)` where `g ∈ Z\{0}` and `gcd(p, q) = 1`.

All [integer](https://ourbigbook.com/codex/integer) [vectors](https://ourbigbook.com/codex/vector) perpendicular to `(p, q)` are [integer multiples](https://ourbigbook.com/codex/integer-multiple) of `(q, −p)`,
so we can write

`P = t(q, −p)`

for some [integer](https://ourbigbook.com/codex/integer) `t`.

Let `m = p² + q²`. Then `|P|² = t² m`, and the length condition becomes the
single [Diophantine equation](https://ourbigbook.com/codex/diophantine-equation)

`3 g² m − 40 g p + 100 = t² m`.

### 4) Massive pruning via a modular constraint
Rearranging the equation shows

`3 g² m − 40 g p + 100` must be divisible by `m`, which is equivalent to the
simple [integer congruence](https://ourbigbook.com/codex/integer-congruence):

`(40p) g ≡ 100 (mod m)`.

For each primitive `(p, q)` we solve this [linear congruence](https://ourbigbook.com/codex/linear-congruence) (using a [modular
inverse](https://ourbigbook.com/codex/modular-inverse)) and only test `g` values in that [arithmetic progression](https://ourbigbook.com/codex/arithmetic-progression).

### 5) Strong bounds on the search space
For any [triangle](https://ourbigbook.com/codex/triangle) inscribed in a [circle](https://ourbigbook.com/codex/circle) of [radius](https://ourbigbook.com/codex/radius) `R`, the [perimeter](https://ourbigbook.com/codex/perimeter) is at least
`4R` (degenerate limit), so with [perimeter](https://ourbigbook.com/codex/perimeter) ≤ `P` we have `R ≤ P/4`.

From `|d| = |b + c| ≤ |b| + |c| = 2R` we also get `|d| ≤ P/2`.

Combining these bounds with the [divisibility](https://ourbigbook.com/codex/divisibility) constraint yields a tight global
bound on `m = p² + q²`, making the brute‑force loop over primitive directions
feasible in Python.

### 6) Deduplication
The same [triangle](https://ourbigbook.com/codex/triangle) can be generated multiple times by choosing a different [polygon vertex](https://ourbigbook.com/codex/vertex-of-a-polygon)
as `a`. The implementation stores each [triangle](https://ourbigbook.com/codex/triangle) as a sorted triple of [polygon vertices](https://ourbigbook.com/codex/vertex-of-a-polygon)
in a [set](https://ourbigbook.com/codex/set) to ensure each is counted exactly once.

## Numerical handling

[Perimeters](https://ourbigbook.com/codex/perimeter) involve [square roots](https://ourbigbook.com/codex/square-root). The solver uses `math.hypot` for distances and
`math.fsum` for a stable floating‑point sum, then formats the final answer to
four decimals.

## Built‑in checks

The problem statement provides a test case:

* For [perimeter](https://ourbigbook.com/codex/perimeter) ≤ 50 there are **9** [triangles](https://ourbigbook.com/codex/triangle) and the [perimeter](https://ourbigbook.com/codex/perimeter) sum rounded to
  4 decimals is **291.0089**.

`main.py` includes asserts for both values.
