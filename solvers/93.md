# Project Euler 93 Solution - Arithmetic Expressions

<https://projecteuler.net/problem=93>:

* [93.py](93.py)
* [93.lean](93.lean)

We must choose 4 distinct [digits](https://ourbigbook.com/codex/numerical-digit) `a<b<c<d` (from 0–9). Using each [digit](https://ourbigbook.com/codex/numerical-digit) exactly once and the operations `+ - * /` with arbitrary parentheses, we can form many values. For each [digit](https://ourbigbook.com/codex/numerical-digit) [set](https://ourbigbook.com/codex/set), we want the longest consecutive run of [positive integers](https://ourbigbook.com/codex/positive-integer) starting at 1 (i.e., `1..n` all representable).

## Key idea

Generate **all possible expression results** for a given 4-digit [set](https://ourbigbook.com/codex/set) by exploring all [binary expression trees](https://ourbigbook.com/codex/binary-expression-tree):

- Start with the 4 numbers as exact rational values (`fractions.Fraction`).
- Repeatedly pick any pair `(x, y)` from the current [multiset](https://ourbigbook.com/codex/multiset) and replace it with each possible operation result:
  - `x+y`, `x-y`, `y-x`, `x*y`, `x/y` (if `y!=0`), `y/x` (if `x!=0`)
- Recurse until only one value remains; collect all such results.

This [recursion](https://ourbigbook.com/codex/recursion) implicitly covers all [digit](https://ourbigbook.com/codex/numerical-digit) orders and all parenthesizations.

## Exact arithmetic

To avoid floating-point errors, all computations use `Fraction`, so checking “is a [positive integer](https://ourbigbook.com/codex/positive-integer)” is exact (`denominator == 1` and [numerator](https://ourbigbook.com/codex/numerator) > 0).

## Optimization

A [memoization](https://ourbigbook.com/codex/memoization) [dictionary](https://ourbigbook.com/codex/associative-array) keyed by the sorted [tuple](https://ourbigbook.com/codex/tuple) of current `Fraction` values avoids recomputing identical subproblems (same [multiset](https://ourbigbook.com/codex/multiset) of intermediate values).

## Result selection

For each 4-digit [combination](https://ourbigbook.com/codex/combination-combinatorics):
- compute all reachable values
- keep the [set](https://ourbigbook.com/codex/set) of reachable [positive integers](https://ourbigbook.com/codex/positive-integer)
- measure the consecutive run length from 1 upward

The best [digit](https://ourbigbook.com/codex/numerical-digit) [set](https://ourbigbook.com/codex/set) is printed as a concatenated [string](https://ourbigbook.com/codex/string) `abcd`.

The included asserts verify:
- `{1,2,3,4}` has run length 28 and maximum value 36 (as stated)
- the final answer is `1258` with run length 51
