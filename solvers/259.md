# Project Euler 259 Solution - Reachable Numbers

<https://projecteuler.net/problem=259>:

* [259.py](259.py)

The [digits](https://ourbigbook.com/codex/numerical-digit) `1` through `9` must be used in order. Between adjacent [digits](https://ourbigbook.com/codex/numerical-digit) we may
concatenate or use a [binary operation](https://ourbigbook.com/codex/binary-operation), and parentheses may be placed arbitrarily.

## Key ideas

Treat each of the eight gaps between consecutive [digits](https://ourbigbook.com/codex/numerical-digit) as a small code. A gap can
be one of the four [arithmetic operations](https://ourbigbook.com/codex/arithmetic-operation), or it can be concatenation. There are
only \(5^8\) such gap patterns. Once concatenations are resolved, a pattern gives
a short list of [integer](https://ourbigbook.com/codex/integer) tokens and a fixed list of arithmetic operators between
them.

For one fixed token/operator list, parentheses are handled by an [interval dynamic
program](https://ourbigbook.com/codex/interval-dynamic-programming). Let \(R(l,r)\) be the exact [rational](https://ourbigbook.com/codex/rational-number) values obtainable from the token
[interval](https://ourbigbook.com/codex/interval) \(l..r\). The base [interval](https://ourbigbook.com/codex/interval) contains the token itself, and a larger
[interval](https://ourbigbook.com/codex/interval) is formed by choosing the final [binary operation](https://ourbigbook.com/codex/binary-operation) position:

\[
R(l,r)=\bigcup_{l\le s<r} R(l,s)\operatorname{ op}_s R(s+1,r).
\]

Here \(\operatorname{op}_s\) is fixed by the gap pattern. Division by zero is
skipped. Each [interval](https://ourbigbook.com/codex/interval) stores a [set](https://ourbigbook.com/codex/set), so repeated values from different
parenthesizations collapse immediately.

[Fractions](https://ourbigbook.com/codex/fraction) are stored as reduced `(numerator, denominator)` pairs with positive
[denominators](https://ourbigbook.com/codex/denominator). This keeps all arithmetic exact and avoids losing [integer](https://ourbigbook.com/codex/integer) results
that pass through fractional intermediate values.

At the end of each pattern, pairs with [denominator](https://ourbigbook.com/codex/denominator) `1` and positive [numerator](https://ourbigbook.com/codex/numerator) are
inserted into one global [set](https://ourbigbook.com/codex/set). The requested answer is the sum of that final [set](https://ourbigbook.com/codex/set),
so [integers](https://ourbigbook.com/codex/integer) reached by several different expressions are counted once.

The full search over \(5^8\) patterns is embarrassingly parallel. The solver
splits the pattern-code range into worker chunks for the real `1..9` run. Each
worker keeps a local list of [positive integer](https://ourbigbook.com/codex/positive-integer) hits, sorts and deduplicates that
list, and the parent process performs the final union. For smaller [digit](https://ourbigbook.com/codex/numerical-digit) prefixes
or restricted environments it falls back to the same single-process loop.
