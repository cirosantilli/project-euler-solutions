## Even Fibonacci Numbers (≤ 4,000,000)

We generate [Fibonacci numbers](https://ourbigbook.com/codex/fibonacci-number) starting from `1, 2` using the [recurrence relation](https://ourbigbook.com/codex/recurrence-relation):
- `F(n+2) = F(n+1) + F(n)`

While generating terms up to the limit (4,000,000), we accumulate only the even-valued terms into a running [sum](https://ourbigbook.com/codex/sum).

This runs in [linear time](https://ourbigbook.com/codex/linear-time) in the number of [Fibonacci numbers](https://ourbigbook.com/codex/fibonacci-number) up to the limit (very small: only a few dozen terms), and [constant memory](https://ourbigbook.com/codex/constant-space).
