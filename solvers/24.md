# Project Euler 24 Solution - Lexicographic Permutations

<https://projecteuler.net/problem=24>:

* [24.py](24.py)
* [24.lean](24.lean)

To find the millionth [lexicographic](https://ourbigbook.com/codex/lexicographic-order) [permutation](https://ourbigbook.com/codex/permutation) of [digits](https://ourbigbook.com/codex/numerical-digit) `0..9` efficiently, we avoid generating all `10! = 3,628,800` [permutations](https://ourbigbook.com/codex/permutation).

## Key idea: Factorial Number System (ranking/unranking permutations)

In [lexicographic order](https://ourbigbook.com/codex/lexicographic-order), [permutations](https://ourbigbook.com/codex/permutation) are grouped in blocks:

- With `k` remaining [digits](https://ourbigbook.com/codex/numerical-digit), each fixed first [digit](https://ourbigbook.com/codex/numerical-digit) accounts for `(k-1)!` [permutations](https://ourbigbook.com/codex/permutation).
- The index of the next [digit](https://ourbigbook.com/codex/numerical-digit) is determined by [integer division](https://ourbigbook.com/codex/integer-division):
  - `idx = rank // (k-1)!`
  - Update `rank = rank % (k-1)!`
- Remove the chosen [digit](https://ourbigbook.com/codex/numerical-digit) from the available list and continue.

We treat the target as 1-indexed (`1,000,000`), convert to 0-indexed rank (`999,999`), and build the [permutation](https://ourbigbook.com/codex/permutation) [digit](https://ourbigbook.com/codex/numerical-digit) by [digit](https://ourbigbook.com/codex/numerical-digit).

## Complexity

- Time: `O(k^2)` due to list removals (`k=10`, trivial).
- Space: `O(k)`.

## Result

The millionth [lexicographic](https://ourbigbook.com/codex/lexicographic-order) [permutation](https://ourbigbook.com/codex/permutation) of `0..9` is:

`2783915460`
