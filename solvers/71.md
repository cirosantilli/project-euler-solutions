# Project Euler 71 Solution - Ordered Fractions

<https://projecteuler.net/problem=71>:

* [71.py](71.py)
* [71.lean](71.lean)

We want the proper [reduced fraction](https://ourbigbook.com/codex/reduced-fraction) `n/d` with `d ≤ 1,000,000` that is **immediately to the left** of `3/7`, i.e. the largest [fraction](https://ourbigbook.com/codex/fraction) `< 3/7`.

## Key idea
For each [denominator](https://ourbigbook.com/codex/denominator) `d`, the best [numerator](https://ourbigbook.com/codex/numerator) `n` that stays strictly below `3/7` is:
- `n = floor((3*d - 1)/7)`

This guarantees `n/d < 3/7` and is the closest such [fraction](https://ourbigbook.com/codex/fraction) for that fixed `d`.

We then:
1. Check the [fraction](https://ourbigbook.com/codex/fraction) is reduced (`gcd(n, d) = 1`).
2. Keep the maximum `n/d` using [cross-multiplication](https://ourbigbook.com/codex/cross-multiplication) (`n1/d1 > n2/d2` iff `n1*d2 > n2*d1`).

## Complexity
We scan `d = 1..1,000,000`. Each step uses a `gcd`, so runtime is about `O(N log N)` and runs quickly in PyPy.

The resulting [numerator](https://ourbigbook.com/codex/numerator) is `428570`.
