# Project Euler 91 Solution - Right Triangles with Integer Coordinates

<https://projecteuler.net/problem=91>:

* [91.py](91.py)
* [91.lean](91.lean)
* [91.py.lean](91.py.lean)

We count [right triangles](https://ourbigbook.com/codex/right-triangle) `OPQ` where `O = (0,0)` and `P, Q` are distinct [lattice points](https://ourbigbook.com/codex/lattice-point) in the [square](https://ourbigbook.com/codex/square)
`0 ≤ x,y ≤ N`.

### 1) Right angle at the origin
With all coordinates nonnegative, `OP ⟂ OQ` implies `x1*x2 + y1*y2 = 0`, which can only happen if
one [point](https://ourbigbook.com/codex/point) lies on the positive x-axis and the other on the positive y-axis.
So there are `N * N` such [triangles](https://ourbigbook.com/codex/triangle).

### 2) Right angle at a point `P`
Fix `P = (x,y)` (not the [origin](https://ourbigbook.com/codex/origin)) and count [points](https://ourbigbook.com/codex/point) `Q` such that `OP ⟂ PQ`.

- If `P` lies on an axis (but not the [origin](https://ourbigbook.com/codex/origin)), the perpendicular line through `P` is a grid line.
  There are exactly `N` valid choices for `Q` along that line inside the [square](https://ourbigbook.com/codex/square).

- If `x>0` and `y>0`, the direction perpendicular to `OP` is based on the reduced [vector](https://ourbigbook.com/codex/vector)
  `(x,y)/g` where `g = gcd(x,y)`. A primitive perpendicular step is:
  - `(-y/g, x/g)` and the opposite `(y/g, -x/g)`.
  Moving from `P` by [integer multiples](https://ourbigbook.com/codex/integer-multiple) of these steps hits exactly the [lattice points](https://ourbigbook.com/codex/lattice-point) that keep
  `OP ⟂ PQ`.
  We count how many steps fit in-bounds in each direction using simple [integer](https://ourbigbook.com/codex/integer) bounds, and add both.

### Complexity
We iterate over all `P` in the `(N+1)²` grid and do `O(1)` work per [point](https://ourbigbook.com/codex/point), so the runtime is `O(N²)`.
For `N=50` this is instantaneous.

The shared Python argument is the inclusive bound `n`. Nonpositive bounds give
zero triangles. The standalone Lean solver also uses its supplied natural-number
bound and has proved termination for its grid loops.

The [squared-distance lemmas](../ProjectEulerSolutions/Lib/LatticeRightTriangles.lean)
identify the right-angle vertex and prove it is unique for nondegenerate
triangles. The [perpendicular-step proof](../ProjectEulerSolutions/Lib/LatticePerpendicular.lean)
shows that the gcd-reduced direction reaches every integer point on the
perpendicular line; the quotient bounds characterize the steps that fit inside
the grid. The reference's [Python predicate proof](../data/project-euler-statements/data/py/project_euler_statements/p91.py.lean.d/Predicate.lean)
covers arbitrary signed coordinates. The [counting proof](../ProjectEulerSolutions/Lib/LatticeTriangleCount.lean)
establishes the exact partner count for each grid point and accounts for both
orders of every triangle. The existing standalone Lean solver and reference are
[proved equivalent](../ProjectEulerSolutions/Equiv/P91.lean) for every natural
bound, using their original counting loops.

The [Python source equivalence proof](91.py.lean) establishes termination and
agreement for every signed integer bound. It executes the optimized gcd and
quotient arithmetic, both nested loops, and the origin's `continue` branch.
The reference proof executes all four coordinate loops, the degenerate-pair guard,
the right-angle predicate call, and division by two. Nonpositive bounds return
zero in both programs. The proofs use structural loop measures and the counting
lemmas above, without evaluating either complete program.
