# Project Euler 85 Solution - Counting Rectangles

<https://projecteuler.net/problem=85>:

* [85.py](85.py)
* [85.lean](85.lean)

For an `m × n` grid, any [rectangle](https://ourbigbook.com/codex/rectangle) is determined by choosing 2 distinct vertical grid lines and 2 distinct horizontal grid lines.

- Number of ways to choose vertical sides:  
  \[
  \binom{m+1}{2} = \frac{m(m+1)}{2}
  \]
- Number of ways to choose horizontal sides:  
  \[
  \binom{n+1}{2} = \frac{n(n+1)}{2}
  \]

So the number of sub-rectangles is:
\[
R(m,n) = \frac{m(m+1)}{2} \cdot \frac{n(n+1)}{2} = \frac{m(m+1)n(n+1)}{4}
\]

We need `R(m,n)` closest to 2,000,000, and output the corresponding area `m·n`.

## Approach

1. Use [symmetry](https://ourbigbook.com/codex/symmetry) to restrict to `1 <= m <= n`. Start with the positive grid `(1, 1)` as the incumbent.
2. For each `m`, set `A = m(m+1)/2`. Every eligible grid in this row has at least `A*A` rectangles. Stop when that lower bound exceeds `target + best_difference`.
3. Find the greatest integer `n` with `n(n+1)/2 <= target//A` using `isqrt(1 + 8*(target//A))`. Clamp it to at least `m` and test it and its successor. Monotonicity puts the best candidate among these two integers.
4. Keep the first pair when distances tie. Ascending traversal gives the least `(m, n)` in lexicographic order.

The search accepts any integer target and uses no dimension cutoff or floating-point approximation. The reference enumerates complete rows and columns, stopping only when their increasing rectangle counts cannot improve the incumbent.

## Formal verification

[85.py.lean](85.py.lean) proves termination and `Equiv(naive)` for every integer target, including zero and negative values. The proof follows both original Python searches and preserves the least `(m, n)` tie rule; it uses no whole-program computation.

[RectangleApproximation.lean](../ProjectEulerSolutions/Lib/RectangleApproximation.lean) proves exact triangular inversion, completeness of the two candidates, and selection of the least column on ties for every integer target. It also proves that the stopping condition excludes every later row and that the initial incumbent gives a finite bound for both scans.

[RectangleSearch.lean](../ProjectEulerSolutions/Lib/RectangleSearch.lean) proves that the complete reference and optimized search models terminate and select the same uniquely specified grid. Their decreasing measures depend on the current incumbent; neither search has a dimension or iteration cutoff.

[Execution.lean](85.py.lean.d/Execution.lean) connects the optimized loop, temporary tuples, and final area projection to that search model. The [reference proofs](../data/project-euler-statements/data/py/project_euler_statements/p85.py.lean.d/) cover both the scalar model used by the contract checker and the heap model, including temporary tuple allocations. Heap-aware execution proofs preserve the caller's heap and globals.

The separate `85.lean` solver still uses an older bounded model and is not used by the Python equivalence proof.
