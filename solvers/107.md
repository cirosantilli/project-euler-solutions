# Project Euler 107 Solution - Minimal Network

<https://projecteuler.net/problem=107>:

* [107.py](107.py)

We are given an undirected [weighted graph](https://ourbigbook.com/codex/weighted-graph) in [adjacency-matrix](https://ourbigbook.com/codex/adjacency-matrix) form (with `-` meaning “no [edge](https://ourbigbook.com/codex/edge)”).
We want the **maximum saving** obtained by removing redundant [edges](https://ourbigbook.com/codex/edge) while keeping the [graph](https://ourbigbook.com/codex/graph) connected.

Key observation:
- Keeping the [graph](https://ourbigbook.com/codex/graph) connected with minimum total [edge](https://ourbigbook.com/codex/edge) weight is exactly the **[Minimum Spanning Tree](https://ourbigbook.com/codex/minimum-spanning-tree) (MST)** problem.
- If `W_total` is the [sum](https://ourbigbook.com/codex/sum) of all existing [edges](https://ourbigbook.com/codex/edge) (count each undirected [edge](https://ourbigbook.com/codex/edge) once) and `W_mst` is the MST weight, then:
  - **maximum saving** = `W_total - W_mst`.

[Algorithm](https://ourbigbook.com/codex/algorithm):
1. Parse the [matrix](https://ourbigbook.com/codex/matrix) and collect all [edges](https://ourbigbook.com/codex/edge) `(weight, u, v)` for `u < v`.
2. Compute `W_total` as the [sum](https://ourbigbook.com/codex/sum) of these [edges](https://ourbigbook.com/codex/edge)’ weights.
3. Compute `W_mst` using **[Kruskal's algorithm](https://ourbigbook.com/codex/kruskal-s-algorithm)** with a [Disjoint Set Union](https://ourbigbook.com/codex/union-find) ([Union-Find](https://ourbigbook.com/codex/union-find)).
4. Output `W_total - W_mst`.

The provided example (7 [vertices](https://ourbigbook.com/codex/graph-vertex)) is asserted in code:
- total = 243, MST = 93, saving = 150.

The final program reads `0107_network.txt` (or falls back to `network.txt`) and prints the saving.
