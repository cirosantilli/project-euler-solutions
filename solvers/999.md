# Sequence solution summary

## Main idea

The original [recurrence relation](https://ourbigbook.com/codex/recurrence-relation) has an alternating [coefficient](https://ourbigbook.com/codex/coefficient), which makes direct modular iteration awkward and far too slow for an index near `10**18`.

Introduce a rescaled [sequence](https://ourbigbook.com/codex/sequence)

```text
W_n = sign(n) * 2^floor(n^2 / 4) * a_n
```

where `sign(n)` repeats with period four:

```text
+1, +1, -1, -1
```

After substitution, the alternating [recurrence relation](https://ourbigbook.com/codex/recurrence-relation) becomes the constant-coefficient [elliptic divisibility sequence](https://ourbigbook.com/codex/elliptic-divisibility-sequence) [recurrence relation](https://ourbigbook.com/codex/recurrence-relation)

```text
W_{n+2} * W_{n-2} = 4 * W_{n+1} * W_{n-1} + 4 * W_n^2
```

with seeds

```text
W_0 = 0
W_1 = 1
W_2 = 2
W_3 = -4
W_4 = -32
```

## Fast doubling

[Elliptic divisibility sequences](https://ourbigbook.com/codex/elliptic-divisibility-sequence) have doubling identities analogous to [Fibonacci fast doubling](https://ourbigbook.com/codex/fibonacci-fast-doubling):

```text
W_{2m-1} = W_{m+1} * W_{m-1}^3 - W_{m-2} * W_m^3

W_{2m} = (W_m / W_2) *
         (W_{m+2} * W_{m-1}^2 - W_{m-2} * W_{m+1}^2)
```

Since `W_2 = 2` and the requested modulus is odd, division is always [multiplication](https://ourbigbook.com/codex/multiplication) by the fixed [modular inverse](https://ourbigbook.com/codex/modular-inverse) of `2`. No division by a potentially zero [sequence term](https://ourbigbook.com/codex/sequence-term) is needed.

The implementation recursively keeps the eight consecutive values

```text
W_{n-3}, ..., W_{n+4}
```

so each halving step can rebuild the next block with constant work.

## Recovering the requested sequence

Once `W_n` is known, recover the original value [modulo](https://ourbigbook.com/codex/modulo-operation) the requested modulus with

```text
a_n = sign(n) * W_n * 2^(-floor(n^2 / 4))
```

## Complexity

The index is halved at every recursive step:

```text
Time:  O(log n)
Space: O(log n)
```

The program uses only built-in Python operations and includes assertions for the values supplied in the problem statement.
