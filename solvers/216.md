# Project Euler 216 Solution - The Primality of $2n^2 - 1$

<https://projecteuler.net/problem=216>:

* [216.py](216.py)

Instead of testing every value `2n² - 1` for [primality](https://ourbigbook.com/codex/primality), the solver applies a [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) to the
indices `n`.

## Key ideas

If an [odd prime](https://ourbigbook.com/codex/odd-prime) `p` divides `2n² - 1`, then

\[
n^2 \equiv 2^{-1} \pmod p.
\]

This [integer congruence](https://ourbigbook.com/codex/integer-congruence) has solutions only for [primes](https://ourbigbook.com/codex/prime) `p == 1` or `7 (mod 8)`. For each
such [prime](https://ourbigbook.com/codex/prime) up to `sqrt(2N² - 1)`, the code computes the two roots [modulo](https://ourbigbook.com/codex/modulo-operation) `p` and
marks the corresponding [arithmetic progressions](https://ourbigbook.com/codex/arithmetic-progression) of `n`.

There is one exception: if `2n² - 1` equals the sieving [prime](https://ourbigbook.com/codex/prime) `p` itself, that
index must not be marked [composite](https://ourbigbook.com/codex/composite-number). This happens exactly when `(p + 1) / 2` is a
[perfect square](https://ourbigbook.com/codex/perfect-square).

After all progressions are marked, every unmarked `n >= 2` has no [prime](https://ourbigbook.com/codex/prime) [divisor](https://ourbigbook.com/codex/divisor)
up to the [square root](https://ourbigbook.com/codex/square-root) of `2n² - 1`, so its value is [prime](https://ourbigbook.com/codex/prime).
