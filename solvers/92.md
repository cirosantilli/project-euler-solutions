# Project Euler 92 Solution - Square Digit Chains

<https://projecteuler.net/problem=92>:

* [92.py](92.py)
* [92.lean](92.lean)

We repeatedly replace a number by the [sum of squares](https://ourbigbook.com/codex/sum-of-squares) of its [digits](https://ourbigbook.com/codex/numerical-digit). Every starting number eventually enters the fixed loop at `1` or the loop at `89`. We must count how many starting numbers `< 10,000,000` end at `89`.

### Key insights

- For a number with at most `d` [digits](https://ourbigbook.com/codex/numerical-digit), the first digit-square sum is at most `81*d`.
- Starting values with the same digit-square sum have the same chain endpoint. Count these groups instead of walking every starting value.
- Read the digits of `limit_exclusive - 1` from left to right. For each prefix, track its digit-square sum, whether it still equals the bound's prefix, and how many prefixes share that state.
- Extend each state by every permitted next digit. Leading zeros preserve sums and allow shorter numbers to use the same traversal.
- Memoize whether each resulting sum reaches `1`, `89`, or another repeated value. Sum the group sizes whose endpoint is `89`; the all-zero number contributes nothing.

### Complexity

There are at most `2*(81*d + 1)` prefix states at each digit position, each with at most ten successors. Prefix counting therefore takes `O(d^2)` state transitions and `O(d)` stored states, apart from integer arithmetic and the small memoized chain walks. The supplied bound can have any number of decimal digits; the default is ten million. The reference walks each positive starting value until an endpoint or repeated value, without an iteration cutoff.
