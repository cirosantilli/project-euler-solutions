# Project Euler 45 Solution - Triangular, Pentagonal, and Hexagonal

<https://projecteuler.net/problem=45>:

* [45.py](45.py)
* [45.lean](45.lean)

Key observations:

- [Hexagonal numbers](https://ourbigbook.com/codex/hexagonal-number) satisfy `H_n = n(2n−1)`.
- Every [hexagonal number](https://ourbigbook.com/codex/hexagonal-number) is also triangular because `H_n = T_{2n−1}`.
  Therefore, we only need to search [hexagonal numbers](https://ourbigbook.com/codex/hexagonal-number) and test whether they are also pentagonal.

Pentagonal test:

- [Pentagonal numbers](https://ourbigbook.com/codex/pentagonal-number) satisfy `x = n(3n−1)/2`.
- Solving for `n` gives: `n = (1 + sqrt(1 + 24x)) / 6`.
- So `x` is pentagonal iff `1 + 24x` is a [perfect square](https://ourbigbook.com/codex/perfect-square) and `(1 + sqrt(1 + 24x))` is divisible by 6.

[Algorithm](https://ourbigbook.com/codex/algorithm):

- Start at hexagonal index `n = 1`.
- For each `H_n`, check that it is strictly greater than `after` and pentagonal using the integer-square test above.
- The first match is the answer.

This runs very quickly because it only performs a simple loop with [integer arithmetic](https://ourbigbook.com/codex/integer-arithmetic) and `isqrt`.

[45.py.lean](45.py.lean) proves termination and equivalence to the three-way merge reference for every integer `after`. Existence follows from the recurrence `(p, h) -> (97p + 112h - 44, 84p + 97h - 38)`, starting at `(1, 1)`: it preserves `P_p = H_h` and strictly increases the indices. Both source loops reach the least common value above the threshold. The default threshold is `40755`.
