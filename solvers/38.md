# Project Euler 38 Solution - Pandigital Multiples

<https://projecteuler.net/problem=38>:

* [38.py](38.py)
* [38.lean](38.lean)
* [38.py.lean](38.py.lean)

`solve(width=9)` finds the largest [concatenation](https://ourbigbook.com/codex/string-concatenation) of the products `x*1, x*2, ..., x*k`, with positive `x` and `k > 1`, using each decimal digit from 1 through `width` exactly once. It returns zero if no solution exists. Widths below two cannot hold two positive products; widths above nine require digits outside the decimal alphabet, so they also return zero.

If `x` has `d` digits, each positive multiple has at least `d` digits. Two products therefore require at least `2*d` digits, so every possible seed satisfies `x < 10**(width//2)`. Each product contributes at least one digit, so at most `width` products need consideration. Both bounds follow from the requested width.

The optimized solver visits every seed in that range and appends successive products until their total length reaches the target width. Length increases strictly, so a seed has at most one product count that can match. A [bit mask](https://ourbigbook.com/codex/bit-mask) rejects repeated digits, while explicit bounds reject digits outside 1 through `width`. Exactly `width` distinct permitted digits must contain every target digit. The reference enumerates each permitted product count independently and takes the maximum successful value.

The default width nine gives `932718654`; width eight gives `78156234`.

Lean source proofs establish termination and equivalence to the reference for every signed width. They connect both source searches to the same complete mathematical candidate set, including the string and integer concatenation helpers, mask predicate, reference collector, and optimized running maximum. The default call has a separate termination theorem obtained from the general proof.
