# Project Euler 39 Solution - Integer Right Triangles

<https://projecteuler.net/problem=39>:

* [39.py](39.py)
* [39.lean](39.lean)

We want the [perimeter](https://ourbigbook.com/codex/perimeter) `p ≤ 1000` that yields the most [integer](https://ourbigbook.com/codex/integer) [right-triangle](https://ourbigbook.com/codex/right-triangle) solutions `(a, b, c)` with
`a² + b² = c²` and `a + b + c = p`.

## Key idea (avoid brute force)
All integer right triangles come from **[Euclid's formula](https://ourbigbook.com/codex/euclid-s-formula-for-pythagorean-triples)**:

For [integers](https://ourbigbook.com/codex/integer) `m > n`:
- `a = m² - n²`
- `b = 2mn`
- `c = m² + n²`

This generates a **primitive** triple exactly when:
- `gcd(m, n) = 1` ([coprime](https://ourbigbook.com/codex/coprime))
- `m` and `n` have [opposite parity](https://ourbigbook.com/codex/opposite-parity)

The [perimeter](https://ourbigbook.com/codex/perimeter) of the [primitive Pythagorean triple](https://ourbigbook.com/codex/primitive-pythagorean-triple) is:
- `p0 = a + b + c = 2m(m + n)`

All non-primitive solutions are [multiples](https://ourbigbook.com/codex/integer-multiple) of a [primitive Pythagorean triple](https://ourbigbook.com/codex/primitive-pythagorean-triple):
- [perimeter](https://ourbigbook.com/codex/perimeter) `p = k * p0` for [integer](https://ourbigbook.com/codex/integer) `k ≥ 1`

## Algorithm
1. For each valid `(m, n)` producing a [primitive Pythagorean triple](https://ourbigbook.com/codex/primitive-pythagorean-triple), compute `p0 = 2m(m+n)`.
2. For each multiple `k*p0 ≤ 1000`, increment a counter for that [perimeter](https://ourbigbook.com/codex/perimeter).
3. Pick the [perimeter](https://ourbigbook.com/codex/perimeter) with the maximum count.

`m` only needs to go up to where the smallest possible `p0 = 2m(m+1)` exceeds 1000, so the loop is tiny.

## Result
The [perimeter](https://ourbigbook.com/codex/perimeter) `p ≤ 1000` with the maximum number of solutions is:
- **840**
