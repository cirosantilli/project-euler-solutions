# Project Euler 60 Solution - Prime Pair Sets

<https://projecteuler.net/problem=60>:

* [60.py](60.py)
* [60.lean](60.lean)

We need five [primes](https://ourbigbook.com/codex/prime-number) such that for any two [primes](https://ourbigbook.com/codex/prime-number) `p` and `q`, both concatenations `pq` and `qp` are [prime](https://ourbigbook.com/codex/prime-number). The goal is to minimize the [sum](https://ourbigbook.com/codex/sum) of the five [primes](https://ourbigbook.com/codex/prime-number).

### Key ideas

- **Ignore 2 and 5**: any concatenation ending in an even digit or 5 is composite, so [sets](https://ourbigbook.com/codex/set) cannot include 2 or 5.
- **Fast [primality test](https://ourbigbook.com/codex/primality-test)**: concatenations can reach ~8 [digits](https://ourbigbook.com/codex/numerical-digit) (and a bit more in search). A deterministic **Miller–Rabin** [primality test](https://ourbigbook.com/codex/primality-test) for 64-bit [integers](https://ourbigbook.com/codex/integer) is used.
- **Strong modular [pruning](https://ourbigbook.com/codex/search-pruning) (mod 3)**:
  - Since `10^k ≡ 1 (mod 3)`, we have `concat(p,q) ≡ p + q (mod 3)`.
  - If `(p + q) % 3 == 0`, then both concatenations are divisible by 3 and (being > 3) are composite.
  - This rejects many pairs cheaply.

### Search strategy

- Use **[backtracking](https://ourbigbook.com/codex/backtracking)** to build a [clique](https://ourbigbook.com/codex/clique) (size 5) in the implicit compatibility [graph](https://ourbigbook.com/codex/graph):
  - Two [primes](https://ourbigbook.com/codex/prime-number) are connected if both concatenations are [prime](https://ourbigbook.com/codex/prime-number).
- Maintain a candidate list that is always compatible with the current partial [clique](https://ourbigbook.com/codex/clique).
- Use **[sum](https://ourbigbook.com/codex/sum) lower-bound [pruning](https://ourbigbook.com/codex/search-pruning)**:
  - If the current [sum](https://ourbigbook.com/codex/sum) plus the smallest possible remaining picks cannot beat the best found [sum](https://ourbigbook.com/codex/sum), stop exploring that branch.
- Cache results of the pair compatibility checks to avoid repeated [primality](https://ourbigbook.com/codex/primality) work.

This finds the minimal-sum 5-prime [set](https://ourbigbook.com/codex/set) efficiently and outputs the minimal [sum](https://ourbigbook.com/codex/sum): `26033`.
