# Project Euler 720 Solution - Unpredictable Permutations

<https://projecteuler.net/problem=720>:

* [720.py](720.py)

### Main idea
- For `N = 2^k`, the lexicographically first 3-term-AP-free [permutation](https://ourbigbook.com/codex/permutation) has a recursive structure: start from `N=4`, then for each doubling build odds and evens ordered by the previous [permutation](https://ourbigbook.com/codex/permutation), with the last odd and first even swapped.
- This gives explicit formulas for the [Lehmer code](https://ourbigbook.com/codex/lehmer-code) of the [permutation](https://ourbigbook.com/codex/permutation) at size `2N` in terms of the values and [Lehmer code](https://ourbigbook.com/codex/lehmer-code) at size `N`.
- The [lexicographic rank](https://ourbigbook.com/codex/lexicographic-rank) is computed from the [Lehmer code](https://ourbigbook.com/codex/lehmer-code) as a weighted [factorial](https://ourbigbook.com/codex/factorial) sum, processed from the end to avoid [modular inverses](https://ourbigbook.com/codex/modular-inverse).

### Algorithm outline
- Build arrays of [permutation](https://ourbigbook.com/codex/permutation) values and [Lehmer codes](https://ourbigbook.com/codex/lehmer-code) up to size `2^24` using the [recurrence relation](https://ourbigbook.com/codex/recurrence-relation).
- Use the size `2^24` arrays to compute the [matrix rank](https://ourbigbook.com/codex/matrix-rank) for size `2^25` in one reverse pass, updating a running [factorial](https://ourbigbook.com/codex/factorial) multiplier.
- Add asserts for the provided test cases and print the final result [modulo](https://ourbigbook.com/codex/modulo) `1_000_000_007`.
