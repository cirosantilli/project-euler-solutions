# Square Root Convergents (√2)

√2 has the [continued fraction](https://ourbigbook.com/codex/continued-fraction) expansion:

\[
\sqrt{2} = [1; 2, 2, 2, \dots]
\]

The problem asks: among the first 1000 [convergents](https://ourbigbook.com/codex/continued-fraction-convergent) (“expansions” as shown), how many [fractions](https://ourbigbook.com/codex/fraction) have a [numerator](https://ourbigbook.com/codex/numerator) with more [digits](https://ourbigbook.com/codex/numerical-digit) than the [denominator](https://ourbigbook.com/codex/denominator)?

## Key Insight

If a [convergent](https://ourbigbook.com/codex/continued-fraction-convergent) is \( \frac{p}{q} \), then for √2 with repeating [partial quotients](https://ourbigbook.com/codex/partial-quotient-of-a-continued-fraction) 2, the next [convergent](https://ourbigbook.com/codex/continued-fraction-convergent) can be obtained by a simple [recurrence relation](https://ourbigbook.com/codex/recurrence-relation):

- \( p' = p + 2q \)
- \( q' = p + q \)

Starting from the first expansion \( \frac{3}{2} \), we iterate this [recurrence relation](https://ourbigbook.com/codex/recurrence-relation) 1000 times and count when `len(str(p)) > len(str(q))`.

## Complexity

- 1000 iterations with [big integers](https://ourbigbook.com/codex/arbitrary-precision-integer) of a few hundred [digits](https://ourbigbook.com/codex/numerical-digit).
- Time and memory are easily within limits in PyPy3.

The final count for the first 1000 expansions is **153**.
