# Project Euler 687 Solution - Shuffling Cards

<https://projecteuler.net/problem=687>:

* [687.py](687.py)

## Core idea

A shuffle of 52 distinct cards induces a **[matrix rank](https://ourbigbook.com/codex/matrix-rank) string** of length 52 with 13 symbols, each appearing 4 times.
Because suit [permutations](https://ourbigbook.com/codex/permutation) only reorder cards *within* a [matrix rank](https://ourbigbook.com/codex/matrix-rank), every [matrix rank](https://ourbigbook.com/codex/matrix-rank) string corresponds to exactly \((4!)^{13}\)
distinct shuffles. Therefore, [probabilities](https://ourbigbook.com/codex/probability) can be computed by counting [matrix rank](https://ourbigbook.com/codex/matrix-rank) strings.

A [matrix rank](https://ourbigbook.com/codex/matrix-rank) is **perfect** if none of its four occurrences are adjacent in the [matrix rank](https://ourbigbook.com/codex/matrix-rank) string.

## Inclusion–exclusion via “glued” adjacencies

For a single [matrix rank](https://ourbigbook.com/codex/matrix-rank) with 4 occurrences, look at the 3 gaps between consecutive occurrences (left-to-right).
If a chosen gap is “glued”, the two occurrences must be adjacent, which reduces the number of blocks for that [matrix rank](https://ourbigbook.com/codex/matrix-rank) by 1.

For one [matrix rank](https://ourbigbook.com/codex/matrix-rank), the [inclusion–exclusion](https://ourbigbook.com/codex/inclusion-exclusion-principle) weight for choosing `t` glued gaps is:

- sign: \((-1)^t\)
- choices: \(\binom{3}{t}\)
- resulting number of blocks for that [matrix rank](https://ourbigbook.com/codex/matrix-rank): \(4-t\)

When several ranks are forced to be perfect, [inclusion–exclusion](https://ourbigbook.com/codex/inclusion-exclusion-principle) is applied independently to each of those ranks.
After gluing, we count interleavings of rank-block sequences; the number of merged block-strings is a [multinomial coefficient](https://ourbigbook.com/codex/multinomial-coefficient):

\[
\frac{(52-B)!}{\prod_i b_i!},
\]
where \(B\) is the total number of glued gaps, and \(b_i\) is the resulting block count for [matrix rank](https://ourbigbook.com/codex/matrix-rank) \(i\).

## Polynomial compression

All ranks are symmetric. For one “constrained” [matrix rank](https://ourbigbook.com/codex/matrix-rank), the contribution can be encoded as a small [polynomial](https://ourbigbook.com/codex/polynomial) in \(x\),
where the exponent tracks how many gaps were glued:

\[
P(x)=\sum_{t=0}^3 (-1)^t \binom{3}{t}\frac{x^t}{(4-t)!}.
\]

To avoid fractions, the implementation scales by \(24=4!\) and uses

\[
Q(x)=24P(x)=1-12x+36x^2-24x^3.
\]

Then \(Q(x)^m\) compactly represents all [inclusion–exclusion](https://ourbigbook.com/codex/inclusion-exclusion-principle) combinations for a fixed set of \(m\) ranks.

## Getting “exactly k perfect ranks” (binomial inversion)

Let \(n[m]\) be the number of [matrix rank](https://ourbigbook.com/codex/matrix-rank) strings where a *fixed* set of \(m\) ranks are perfect.
From [symmetry](https://ourbigbook.com/codex/symmetry), \(n[m]\) is a binomial transform of the counts for “exactly \(k\)” perfect ranks.
A standard **[binomial inversion](https://ourbigbook.com/codex/binomial-inversion)** recovers the distribution \(x[k]\) (for \(k=0..13\)).

## Exact arithmetic and rounding

All combinatorial quantities are computed with Python big [integers](https://ourbigbook.com/codex/integer).
Only at the end, the required [probability](https://ourbigbook.com/codex/probability) is converted to `Decimal` and rounded to **10 [digits](https://ourbigbook.com/codex/numerical-digit) after the decimal point**.

The code also checks the statement’s test value for the expected number of perfect ranks (as an exact [reduced fraction](https://ourbigbook.com/codex/reduced-fraction)).
