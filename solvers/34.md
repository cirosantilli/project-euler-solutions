# Project Euler 34 Solution - Digit Factorials

<https://projecteuler.net/problem=34>:

* [34.py](34.py)
* [34.lean](34.lean)

We need all [integers](https://ourbigbook.com/codex/integer) equal to the [sum](https://ourbigbook.com/codex/sum) of the [factorials](https://ourbigbook.com/codex/factorial) of their [decimal digits](https://ourbigbook.com/codex/decimal-digit), excluding 1 and 2, and then [sum](https://ourbigbook.com/codex/sum) them.

### Key insights
- Precompute `0!` through `9!` once.
- For an `n`-[digit](https://ourbigbook.com/codex/numerical-digit) number, the maximum possible digit-factorial [sum](https://ourbigbook.com/codex/sum) is `n * 9!`.
- Once `n * 9! < 10^(n-1)`, no `n`-[digit](https://ourbigbook.com/codex/numerical-digit) number can be reached by any digit-factorial [sum](https://ourbigbook.com/codex/sum), so we have a finite search bound.
- This bound yields a maximum of 7 [digits](https://ourbigbook.com/codex/numerical-digit), so the search only needs to go up to `7 * 9! = 2,540,160`.

### Approach
1. Precompute [digit](https://ourbigbook.com/codex/numerical-digit) [factorials](https://ourbigbook.com/codex/factorial) in an [array](https://ourbigbook.com/codex/array) `facts[0..9]`.
2. Compute the [upper bound](https://ourbigbook.com/codex/upper-bound) using the inequality above.
3. For each number `x` from 3 to `upper`, compute the [sum](https://ourbigbook.com/codex/sum) of [factorials](https://ourbigbook.com/codex/factorial) of its [digits](https://ourbigbook.com/codex/numerical-digit) and check if it equals `x`.
4. Accumulate the [sum](https://ourbigbook.com/codex/sum) of all such numbers and print it.

The resulting [sum](https://ourbigbook.com/codex/sum) is `40730`.
