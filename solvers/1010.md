# Project Euler 1010 Solution - March of the Penguins

<https://projecteuler.net/problem=1010>:

* [1010.py](1010.py)

After reversing the penguin order, their displacement vector is a partition
`lambda` of `n` with at most `m` parts. A legal march adds one cell to its
Young diagram at each step. Thus the number of marches to that endpoint is
the number of standard Young tableaux:

`f(lambda) = n! / product of its hook lengths`.

We need the product of these counts over all such partitions. Let `P_m(n)`
count these partitions, and let `H_h(n)` count all occurrences of hook length
`h` across them. Then

`F(m,n) = (n!)^P_m(n) / product_h h^H_h(n)`.

This avoids enumerating the partitions individually.

## Counting hooks with beta sets

Pad a partition with zero parts to length `m` and represent it by the occupied
nonnegative positions `lambda_i + m - i`. Their sum is
`n + B_m`, where `B_m = m(m-1)/2`. A hook of length `h` corresponds to moving
an occupied position down by `h` to an unoccupied position.

For a beta set, the number of possible upward moves of length `h` minus the
number of downward moves is the number of occupied positions below `h`.
This follows by telescoping the occupation indicators on each residue class
modulo `h`.

Let `C_h(k)` be the total number of these low occupied positions over all
partitions of size `k`. Reversing a hook removal is a bijection, so

`H_h(n) = H_h(n-h) + C_h(n-h)`.

Consequently `H_h(n) = sum_{a>=1} C_h(n-a*h)`.

The generating function for beta sets containing a particular position `x`
is obtained from `product_{j>=0}(1 + z*q^j)` by marking that factor. Expand
`z*q^x / (1 + z*q^x)` as an alternating geometric series. Since the
coefficient of `z^j` in the unmarked product is
`q^B_j / product_{i=1}^j (1-q^i)`, coefficient extraction gives

`C_h(k) = sum_{r=1}^m (-1)^(r-1) sum_{x=0}^{h-1} P_{m-r}(k+B_m-B_{m-r}-r*x)`.

Terms with negative arguments are zero. The solver substitutes this directly
into the formula for `H_h(n)`.

## Computation

The usual partition recurrence builds all needed `P_j(k)` values. The modulus
is prime and larger than every hook length, so all exponents can be computed
modulo `modulus - 1`. Compact arrays keep the partition table at about 7 MB
for the target. The hook summation takes `O(m*n^2)` operations; the partition
table takes `O(m*(n+m^2))` operations and storage.

The solver asserts the three example endpoint counts and all three supplied
values of `F` before computing the target.
