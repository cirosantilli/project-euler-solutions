# Project Euler 46 Solution - Goldbach's Other Conjecture

<https://projecteuler.net/problem=46>:

* [46.py](46.py)
* [46.lean](46.lean)

The solver returns the smallest odd composite `n` strictly greater than `after` that **cannot** be expressed as:

`n = p + 2*s^2` where `p` is [prime](https://ourbigbook.com/codex/prime-number) and `s` is a positive [integer](https://ourbigbook.com/codex/integer). The default threshold is zero.

### Approach
1. Iterate through [odd numbers](https://ourbigbook.com/codex/odd-number) starting from 9.
2. Skip values at or below `after` and skip [primes](https://ourbigbook.com/codex/prime-number).
3. For each odd composite `n`, try all [primes](https://ourbigbook.com/codex/prime-number) `p < n`:
   - Let `rem = n - p`. If `rem` is even, check whether `rem/2` is a [perfect square](https://ourbigbook.com/codex/perfect-square) using [integer square root](https://ourbigbook.com/codex/integer-square-root).
4. The first `n` that fails for all [primes](https://ourbigbook.com/codex/prime-number) is the answer.

### Efficiency
This is fast because:
- The default answer is small (5777).
- [Prime](https://ourbigbook.com/codex/prime-number) checks use [trial division](https://ourbigbook.com/codex/trial-division) by already-known [primes](https://ourbigbook.com/codex/prime-number).
- Perfect-square checks use exact integer arithmetic through `math.isqrt`.

The program also includes asserts verifying the examples provided in the statement.

### Formal proof

[46.py.lean](46.py.lean) proves equivalence for every integer `after`. Both functions return the least qualifying counterexample when one exists, and both execute supported infinite searches otherwise. The prime cache grows as needed, and the reference square loop stops when `2*s*s >= n`. A separate proof establishes termination of the default call using the explicit counterexample 5777.
