# Project Euler 37 Solution - Truncatable Primes

## Key idea
A [prime](https://ourbigbook.com/codex/prime-number) is *truncatable* if repeatedly removing [digits](https://ourbigbook.com/codex/numerical-digit) from:
- left to right **and**
- right to left

always produces [primes](https://ourbigbook.com/codex/prime-number) at every intermediate step. Single-digit [primes](https://ourbigbook.com/codex/prime-number) (2, 3, 5, 7) are excluded.

## Approach
`solve(base=10)` accepts any numeral base at least two. Start with its single-digit primes and repeatedly append a nonzero digit, retaining prime children. Every retained child is right-truncatable because its parent and all earlier prefixes are prime. A zero final digit would make a child divisible by the base, so excluding it loses no candidate.

For each child, test its proper left truncations as remainders modulo successive powers of the base. Add the child when every suffix is prime. Single-digit roots are excluded from the sum.

Stop when the next frontier is empty. There is no prescribed depth, numeric search bound, or expected number of accepted primes. The decimal tree exhausts after eight-digit primes, and the result is 748317. For an arbitrary base, termination depends on exhaustion of its right-truncatable-prime tree.

The reference constructs both sets of proper truncations from digit lists. The optimized solver uses arithmetic suffix checks and inherits the prefix checks from tree construction.

## Complexity
If the tree is finite, let `T` be its node count, `D` its maximum digit width, and `M` the largest integer tested. With trial division, a conservative time bound is `O(T * (base + D) * sqrt(M))`, and working memory is proportional to the largest frontier. Integer arithmetic costs are omitted.

The program prints the final [sum](https://ourbigbook.com/codex/sum).
