# Project Euler 63 Solution - Powerful Digit Counts

<https://projecteuler.net/problem=63>:

* [63.py](63.py)
* [63.py.lean](63.py.lean)
* [63.lean](63.lean)

We want to count [positive integers](https://ourbigbook.com/codex/positive-integer) that have exactly `n` [decimal digits](https://ourbigbook.com/codex/decimal-digit) and are also an `n`th power, i.e. numbers of the form `a^n` whose digit count equals `n`.

The Python solver accepts any numeral base `b >= 2`, with decimal as the default. A positive power has exactly `n` digits when `b^(n-1) <= a^n < b^n`. If `a >= b`, the upper inequality fails. It therefore suffices to consider seeds `1 <= a < b`.

For a fixed seed, start with `power = a` and `lower = 1`, corresponding to exponent one. While `power >= lower`, count the power, multiply `power` by `a`, and multiply `lower` by `b`. Once the lower inequality fails, it stays false: the candidate grows by the smaller factor `a`, whereas its required place value grows by `b`.

The reference traverses exponents instead. It converts each candidate to a digit list and counts those whose width equals the exponent. It stops when even the maximal seed, `b - 1`, has too few digits.

Both stopping rules terminate for every supported base. Set `c = b - 1`. The first two binomial terms give `b^c >= 2*c^c`. Raising to the power `b` and using `2^b > b` gives `c^(bc) < b^(bc-1)`. Thus all seeds have failed by exponent `bc`. This bound proves termination; neither source loop uses it as an execution cutoff.
