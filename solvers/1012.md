# Project Euler 1012 Solution - Rock Paper Scissors

<https://projecteuler.net/problem=1012>:

* [1012.py](1012.py)

Write `w_i = 2*i-1`. The payoff matrix is antisymmetric: for `i < j`, its
entry is `w_i` when `j-i` is odd, and `-w_j` otherwise. An equilibrium
probability vector `x` therefore has zero payoff on every supported option
and nonpositive payoff on every excluded option.

## A short recurrence for an interval of options

Consider an odd interval `[l,r]`, put `k = r-l+1`, `w = 2*l-1`, and index its
probabilities by `t = 0,...,k-1`. Set `d = sum_t 2*t*x_t`.

Combining three consecutive indifference equations gives

`(w+2*t+4)*x_{t+2} = (w+2*t)*x_t + 2*x_{t+1} + 2*d - 4*(t+1)`.

Thus every probability is an affine expression in only three unknowns:
`a = x_0`, `b = x_1`, and `d`. Propagate the four coefficient sequences of
this affine expression. Normalization, the definition of `d`, and the first
payoff equation give a three-by-three linear system, solved with determinants.
The endpoint payoff equations are also checked numerically.

To see why this reconstructs the whole kernel, let `R_t` denote the payoff
of supported row `t`. The recurrence implies
`R_{t+2} + 2*R_{t+1} + R_t = 0`. Hence
`R_t = (-1)^t*(A+B*t)`. Zero payoffs at both endpoints make every supported
payoff zero.

## Verifying excluded options

Let `E` and `O` be the probability masses on even and odd offsets in the
interval. The first and last indifference equations imply that the payoff
of the closest earlier option, `l-1`, is

`w_r*x_{k-1} - 2*k*E`.

Every other earlier row is also nonpositive if this expression is nonpositive
and all supported probabilities are nonnegative: rows of the other parity
have payoff `(w_i-w_l)*O - w_l*x_0`, and rows of this parity decrease as `i`
decreases. Thus only one excluded payoff needs testing.

When adding option `r+1` to a previously valid strategy, its payoff against
that strategy is

`2*k*O - w_l*x_0`.

If it is nonpositive, retain the strategy and assign probability zero to the
new option. This case occurs in the supplied small range and must be handled.
Option `r+2`, if reached, has positive payoff against that same strategy and
requires recomputation.

Otherwise the solver searches odd intervals ending at the new option,
starting with the previous interval length and extending it by two until
the probabilities and excluded payoff pass the equilibrium conditions.
Every accepted strategy is verified by these conditions; failure to find
one raises an exception. The intervals stay short for the requested range,
so each update needs only a short recurrence and a constant-size linear solve.

## Precision

Probabilities and recurrence coefficients use integer fixed-point arithmetic
with 60 decimal places. Intermediate divisions lose only these very small
units, and the sums accumulate in integers. The program checks normalization
and both endpoint payoffs with ample extra precision before rounding the sum
to ten decimal places. This avoids cumulative floating-point error.

The assertions cover both exact example probabilities, the approximate
probability for ten options, and both supplied sums.
