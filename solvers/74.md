# Project Euler 74 Solution - Digit Factorial Chains

<https://projecteuler.net/problem=74>:

* [74.py](74.py)
* [74.lean](74.lean)

We iterate the function:

`next(n) = sum( factorial(d) for each digit d of n )`

Every sequence eventually enters a loop, so the “chain length” for a start value is the number of distinct terms before the first repeat.

## Key insights

- For a number with `d` [digits](https://ourbigbook.com/codex/numerical-digit), `next(n) <= d * 9!`.
- This growth is slower than the growth of the represented integer for sufficiently many digits, so each chain eventually repeats.
- Different starting values often share a tail or cycle. Their lengths can share a memo table.

## Approach

1. Compute each next term from its decimal digits, using the ten digit factorials.
2. Compute chain lengths with [memoization](https://ourbigbook.com/codex/memoization):
   - While building a chain, track positions of numbers seen in the current walk to detect loops.
   - When a loop is found, assign loop nodes length = loop size, and prefix nodes length = remaining unique terms.
   - When reaching a number with known length, propagate lengths back through the current sequence.
3. Count how many positive starts below the supplied `limit` have chain length exactly `target`. The defaults are one million and 60.

The implementation uses dictionaries for completed lengths and positions in the current chain. It needs no fixed maximum term, chain-length storage width, or iteration cutoff. The reference records each complete chain independently until its first repeated value.
