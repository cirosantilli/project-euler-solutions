For every [prime index](https://ourbigbook.com/codex/prime-index) and remaining sum, the solver counts how many increasing
[prime](https://ourbigbook.com/codex/prime) lists can be formed using only later [primes](https://ourbigbook.com/codex/prime).  This is the usual
distinct-subset sum [dynamic program](https://ourbigbook.com/codex/dynamic-program), but with arbitrary-size [integer](https://ourbigbook.com/codex/integer) counts
because only the rank is needed.

The problem's [median](https://ourbigbook.com/codex/median) rule is the lower [median](https://ourbigbook.com/codex/median), so the required zero-based rank
is `(count - 1) // 2`.  To unrank it in [lexicographic order](https://ourbigbook.com/codex/lexicographic-order), try the next [prime](https://ourbigbook.com/codex/prime)
candidates in increasing order.  All lists with a fixed next [prime](https://ourbigbook.com/codex/prime) form one
contiguous block, whose size is already available in the suffix [DP](https://ourbigbook.com/codex/dynamic-programming) table; skip
whole blocks until the rank falls inside one of them.
