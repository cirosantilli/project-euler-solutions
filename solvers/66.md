# Project Euler 66 Solution - Diophantine Equation

<https://projecteuler.net/problem=66>:

* [66.py](66.py)
* [66.lean](66.lean)

We need, for each non-square \(D \le 1000\), the minimal [positive integer](https://ourbigbook.com/codex/positive-integer) solution \((x,y)\) to:

\[
x^2 - Dy^2 = 1
\]

This is the classical [Pell equation](https://ourbigbook.com/codex/pell-equation). The minimal solution in \(x\) can be found via the [continued fraction](https://ourbigbook.com/codex/continued-fraction) expansion of \(\sqrt{D}\):

- Compute the periodic continued fraction of \(\sqrt{D}\) using the standard [recurrence relation](https://ourbigbook.com/codex/recurrence-relation) with \((m,d,a)\).
- Generate [convergents](https://ourbigbook.com/codex/continued-fraction-convergent) \(h/k\) ([numerator](https://ourbigbook.com/codex/numerator)/[denominator](https://ourbigbook.com/codex/denominator)) iteratively.
- The first [convergent](https://ourbigbook.com/codex/continued-fraction-convergent) satisfying \(h^2 - Dk^2 = 1\) gives the minimal \(x = h\).

[Algorithm](https://ourbigbook.com/codex/algorithm):
1. For each \(D = 2..1000\):
   - Skip [perfect squares](https://ourbigbook.com/codex/perfect-square) (no [positive integer](https://ourbigbook.com/codex/positive-integer) solutions).
   - Iterate [convergents](https://ourbigbook.com/codex/continued-fraction-convergent) of \(\sqrt{D}\) until \(x^2 - Dy^2 = 1\).
   - Track the \(D\) that yields the largest minimal \(x\).
2. Output that \(D\).

This runs quickly for \(D \le 1000\) and uses only [integer arithmetic](https://ourbigbook.com/codex/integer-arithmetic) (Python [big integers](https://ourbigbook.com/codex/arbitrary-precision-integer) handle large \(x\) values safely).

Included assertions:
- \(D=13\) has minimal \(x=649\) (given example).
