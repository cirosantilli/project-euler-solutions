# Project Euler 1014 Solution - Steiner Club

<https://projecteuler.net/problem=1014>:

* [1014.py](1014.py)

The nights form a [Steiner system](https://ourbigbook.com/codex/steiner-system)
`S(t,k,v)`: every [subset](https://ourbigbook.com/codex/subset) of `t` members
belongs to exactly one block of `k` members. The target uses `(t,k,v)=(5,8,24)`;
the introductory example uses `(2,3,7)`.

## Derive the allowed intersections

Fix a block `B`. Distinct blocks intersect in fewer than `t` members, since
otherwise one `t`-subset would occur twice. Let `a_i` count the other blocks
whose [intersection](https://ourbigbook.com/codex/intersection) with `B` has
size `i`.

For any fixed `j`-subset, the number of blocks containing it is

`lambda_j = binom(v-j,t-j) / binom(k-j,t-j)`.

This follows by [double counting](https://ourbigbook.com/codex/double-counting)
the `t`-subsets containing that `j`-subset. Now count pairs consisting of a
`j`-subset of `B` and a different block containing it:

`sum_{i=j}^{t-1} binom(i,j)*a_i = binom(k,j)*(lambda_j-1)`.

These [linear equations](https://ourbigbook.com/codex/linear-equation) form a
[triangular system](https://ourbigbook.com/codex/triangular-matrix), with
diagonal entries one. Solve them from `j=t-1` down to zero using exact
[integer arithmetic](https://ourbigbook.com/codex/integer-arithmetic).

For `(5,8,24)`, this derives `(a_0,...,a_4)=(30,0,448,0,280)`. Thus two
distinct nights intersect in zero, two, or four members. Equality of nights
allows intersection size eight. For `(2,3,7)`, distinct nights always
intersect in exactly one member.

## Search only supersets of the requested group

`solve(v, k, t, nights, target)` enumerates the
[combinations](https://ourbigbook.com/codex/combination) of `k-t` additional
members outside `target`. At the target size this means just
`binom(19,3)=969` candidates. Represent each candidate and supplied night as
a [bit set](https://ourbigbook.com/codex/bit-array); the
[population count](https://ourbigbook.com/codex/population-count) of their
bitwise AND gives the intersection size.

Reject any candidate with a forbidden intersection. Exactly one remains.
The statement guarantees that the club exists, so its actual night must be
among the surviving candidates. Uniqueness therefore proves the answer
without reconstructing all 759 nights or assuming a classification theorem
about Steiner systems. If these constraints leave zero or multiple candidates,
the function raises `ValueError`; it does not guess or claim to solve arbitrary
incomplete designs. The precise domain is recorded in the specification.

The naive `solve()` has the same signature and intersection predicate, but
[brute forces](https://ourbigbook.com/codex/brute-force-search) all
`binom(v,k)` blocks before checking whether they contain `target`. This makes
the equivalence a direct restriction of the search space. It shares the
proved intersection lemma, but does not share optimized solver code.

The search takes `O(b*binom(v-t,k-t))` small bit operations for `b` known
nights, after `O(t^2)` work to derive the spectrum. It streams candidates
and uses `O(b+v+t)` working storage.

The introductory example is asserted in the executable. Verification also
compares both implementations on the target and on all 21 member pairs of
a complete seven-member example. The target PyPy run used less than 70 MiB
of resident memory, with a 1 GiB virtual-memory limit.
