# Project Euler 674 Solution - Solving $\mathcal{I}$-equations

## Core observation: ℐ behaves like an injective constructor

The operator is:

\[
\mathcal{I}(x,y) = (1+x+y)^2 + y - x
\]

Two key properties for [non-negative integers](https://ourbigbook.com/codex/nonnegative-integer):

1. **[Injective](https://ourbigbook.com/codex/injective)**:  
   \[
   \mathcal{I}(a,b)=\mathcal{I}(c,d) \implies (a,b)=(c,d)
   \]
   (There is a unique way to “decode” an output back into its input pair — so equality forces equal components.)

2. **[Strictly increasing](https://ourbigbook.com/codex/strictly-increasing)** in each argument (for \(x,y\ge 0\)):  
   \[
   \mathcal{I}(x+1,y)-\mathcal{I}(x,y)=2(1+x+y)>0
   \]
   \[
   \mathcal{I}(x,y+1)-\mathcal{I}(x,y)=2(2+x+y)>0
   \]

## Turning `e1 = e2` into unification

Because ℐ is [injective](https://ourbigbook.com/codex/injective), it behaves like a *constructor symbol* in term algebra:

- To satisfy `I(A,B) = I(C,D)` you must satisfy **both** `A = C` and `B = D`.
- This is exactly the rule used in **[first-order unification](https://ourbigbook.com/codex/first-order-unification)** ([Robinson unification](https://ourbigbook.com/codex/robinson-unification-algorithm)).

So for each pair of expressions:

1. Parse both expressions into trees:
   - `Var(name)`
   - `I(left, right)`
2. Run a standard unifier (with an [occurs check](https://ourbigbook.com/codex/occurs-check) to prevent cyclic substitutions).
   - If not unifiable ⇒ no nonnegative solution ⇒ least simultaneous value = `0`.
   - If unifiable ⇒ we obtain a **[most-general unifier](https://ourbigbook.com/codex/most-general-unifier)** ([MGU](https://ourbigbook.com/codex/most-general-unifier)).

## Why the minimum is “all free variables = 0”

After [unification](https://ourbigbook.com/codex/unification), the two expressions become the same term `T` (up to substitution), and *any* assignment to remaining [free variables](https://ourbigbook.com/codex/free-variable) produces a valid solution.

Because ℐ is [strictly increasing](https://ourbigbook.com/codex/strictly-increasing) in each argument and variables are constrained to be nonnegative, the minimum value of `T` over all solutions is achieved by setting every remaining [free variable](https://ourbigbook.com/codex/free-variable) to **0**.

That is exactly how `least simultaneous value` is computed in the code:
- unify ⇒ get substitution
- evaluate with all free vars = 0

## Modulo arithmetic

The final answer only needs the **last 9 [digits](https://ourbigbook.com/codex/numerical-digit)**, so evaluation is done [modulo](https://ourbigbook.com/codex/modulo):

\[
10^9
\]

This avoids enormous [integers](https://ourbigbook.com/codex/integer) during the full computation.
