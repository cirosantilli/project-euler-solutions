# Project Euler 49 Solution - Prime Permutations

<https://projecteuler.net/problem=49>:

* [49.py](49.py)
* [49.lean](49.lean)

## Idea
We need the unique other 4-digit increasing [arithmetic sequence](https://ourbigbook.com/codex/arithmetic-sequence) of three [primes](https://ourbigbook.com/codex/prime-number) where all three terms are [permutations](https://ourbigbook.com/codex/permutation) of each other (besides `1487, 4817, 8147`), then output the 12-digit number formed by concatenation.

## Approach
1. **Generate all 4-digit [primes](https://ourbigbook.com/codex/prime-number)** using a [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) up to 9999.
2. **Group [primes](https://ourbigbook.com/codex/prime-number) by [digit](https://ourbigbook.com/codex/numerical-digit) signature**: [sort](https://ourbigbook.com/codex/sorting) the [digits](https://ourbigbook.com/codex/numerical-digit) of each [prime](https://ourbigbook.com/codex/prime-number) (e.g., `2969 -> "2699"`). [Primes](https://ourbigbook.com/codex/prime-number) with the same signature are [permutations](https://ourbigbook.com/codex/permutation) of each other.
3. For each group with at least 3 [primes](https://ourbigbook.com/codex/prime-number):
   - [Sort](https://ourbigbook.com/codex/sorting) the group.
   - Check all pairs `(a, b)` and compute `d = b - a`.
   - If `c = b + d` is also in the group, then `(a, b, c)` is an [arithmetic sequence](https://ourbigbook.com/codex/arithmetic-sequence) within the [permutation](https://ourbigbook.com/codex/permutation) group.
4. Ignore the known example sequence and return the other one.
5. Concatenate the three terms into a 12-digit number.

## Complexity
- [Number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve): `O(n log log n)` for `n = 9999`.
- Group scanning is small (only 4-digit [primes](https://ourbigbook.com/codex/prime-number)) and easily runs in milliseconds.

## Output
The program prints the required 12-digit concatenation.
