# Project Euler 673 Solution - Beds and Desks

<https://projecteuler.net/problem=673>:

* [673.py](673.py)

`main.py` is a standalone solution for Project Euler problem 673.

It reads the pairing lists from the **current working directory**:

- `0673_beds.txt`
- `0673_desks.txt`

and prints the required count [modulo](https://ourbigbook.com/codex/modulo) **999,999,937**.

You can also run:

```bash
python3 main.py [beds_file] [desks_file] [n]
```

If `n` is omitted, it defaults to 500.

## Main techniques

### 1) Encode beds and desks as involutions
Each pairing list defines an [involution](https://ourbigbook.com/codex/involution) (a [permutation](https://ourbigbook.com/codex/permutation) of order 2) on `{1..n}`:

- if a line `a,b` exists, then `a ↔ b` (a transposition),
- any student not listed is unpaired and is a [fixed point](https://ourbigbook.com/codex/fixed-point).

Let `B` be the bed [involution](https://ourbigbook.com/codex/involution) and `D` the desk [involution](https://ourbigbook.com/codex/involution).

### 2) The constraints become commutation
After choosing a [permutation](https://ourbigbook.com/codex/permutation) `σ`, student `k` receives the bed that used to belong to
`σ(k)`. The roommate relation after the change is `σ⁻¹ B σ`; demanding that roommates
stay the same means `σ⁻¹ B σ = B`, i.e. `σB = Bσ`. Similarly, desk partners staying the
same gives `σD = Dσ`.

So we must count [permutations](https://ourbigbook.com/codex/permutation) `σ` that commute with both [involutions](https://ourbigbook.com/codex/involution).

### 3) Decompose into simple connected components
Build a [graph](https://ourbigbook.com/codex/graph) whose [graph vertices](https://ourbigbook.com/codex/vertex-of-a-graph) are students; add one undirected [edge of a graph](https://ourbigbook.com/codex/edge-of-a-graph) of color `B` from
`v` to `B(v)` and one [edge of a graph](https://ourbigbook.com/codex/edge-of-a-graph) of color `D` from `v` to `D(v)` ([graph loops](https://ourbigbook.com/codex/loop-graph-theory) when fixed). Every
[graph vertex](https://ourbigbook.com/codex/vertex-of-a-graph) has exactly one `B` [edge of a graph](https://ourbigbook.com/codex/edge-of-a-graph) and one `D` [edge of a graph](https://ourbigbook.com/codex/edge-of-a-graph), so every [connected component](https://ourbigbook.com/codex/connected-component) is
one of:

- an even alternating cycle (no [graph loops](https://ourbigbook.com/codex/loop-graph-theory) at all),
- an alternating path whose endpoints have [graph loops](https://ourbigbook.com/codex/loop-graph-theory),
- a single isolated [graph vertex](https://ourbigbook.com/codex/vertex-of-a-graph) ([graph loops](https://ourbigbook.com/codex/loop-graph-theory) of both colors).

### 4) Count automorphisms of one component
An allowed `σ` is exactly a color-preserving [graph automorphism](https://ourbigbook.com/codex/graph-automorphism) of this [disjoint union](https://ourbigbook.com/codex/disjoint-union).

For a component with `s` [graph vertices](https://ourbigbook.com/codex/vertex-of-a-graph):

- **Cycle (no [graph loops](https://ourbigbook.com/codex/loop-graph-theory)):** `s` is even and the colored cycle has exactly `s` [graph automorphisms](https://ourbigbook.com/codex/graph-automorphism)
  (`s/2` rotations by two steps, and `s/2` reflections that preserve colors).
- **Path (has [graph loops](https://ourbigbook.com/codex/loop-graph-theory)):** there are 2 [graph automorphisms](https://ourbigbook.com/codex/graph-automorphism) iff the component is symmetric,
  which happens exactly when `s` is even (the two endpoint [graph loops](https://ourbigbook.com/codex/loop-graph-theory) have the same
  color); otherwise only the identity.

Even-sized paths come in two non-isomorphic types: endpoints having `B`-loops versus
endpoints having `D`-loops, so they are counted separately.

### 5) Combine identical components
If a component type `t` occurs `c` times, then:

- each copy can be acted on independently: `aut(t)^c`,
- the `c` copies can be permuted among themselves: `c!`.

Thus the total answer is:

`∏_t aut(t)^{c_t} · c_t!  (mod M)`.

## Complexity
With `n = 500`, we do a single [DFS](https://ourbigbook.com/codex/depth-first-search) over at most 500 [graph vertices](https://ourbigbook.com/codex/vertex-of-a-graph).

- Time: `O(n)`
- Memory: `O(n)`

The code includes `assert` checks for the sample values in the problem statement.
