# Project Euler 68 Solution - Magic 5-gon Ring

<https://projecteuler.net/problem=68>:

* [68.py](68.py)
* [68.lean](68.lean)

We need the maximum 16-digit concatenation describing a “magic” 5‑gon ring using numbers 1..10.

### Key insights

- The ring consists of 5 lines: `(outer[i], inner[i], inner[i+1])` (cyclic indices), all summing to the same value `S`.
- The concatenated [string](https://ourbigbook.com/codex/string) is defined by starting at the line with the **smallest outer [polygon vertex](https://ourbigbook.com/codex/vertex-of-a-polygon)** and reading **clockwise**.
- To get a **16-digit** [string](https://ourbigbook.com/codex/string) (not 17), the number **10 must be on the outer ring**, because inner [polygon vertices](https://ourbigbook.com/codex/vertex-of-a-polygon) are used twice in the concatenation.

### Deriving the line sum `S`

Let `sum(inner) = I`. Then `sum(outer) = 55 - I`.

Across the 5 lines:
- Total of all line [sums](https://ourbigbook.com/codex/sum) = `5*S`
- This equals `sum(outer) + 2*sum(inner)` because each inner [polygon vertex](https://ourbigbook.com/codex/vertex-of-a-polygon) appears in two lines.

So:
`5*S = (55 - I) + 2I = 55 + I`, hence  
`S = (55 + I) / 5`.

This means `S` is determined solely by the chosen inner [set](https://ourbigbook.com/codex/set), and it must be an [integer](https://ourbigbook.com/codex/integer).

### Algorithm

1. Choose 5 inner numbers from `{1..9}` (so 10 is forced outer).
2. Compute `S = (55 + sum(inner)) / 5`; skip if non-integer.
3. For each of the `5!` cyclic orders ([permutations](https://ourbigbook.com/codex/permutation)) of the inner [polygon vertices](https://ourbigbook.com/codex/vertex-of-a-polygon):
   - Compute each outer [polygon vertex](https://ourbigbook.com/codex/vertex-of-a-polygon) as `outer[i] = S - inner[i] - inner[i+1]`.
   - Check that the resulting 5 outer [polygon vertices](https://ourbigbook.com/codex/vertex-of-a-polygon) are exactly the remaining numbers and all distinct.
   - Rotate the representation to start at the smallest outer [polygon vertex](https://ourbigbook.com/codex/vertex-of-a-polygon).
   - Concatenate into a [string](https://ourbigbook.com/codex/string) and track the maximum among 16-digit [strings](https://ourbigbook.com/codex/string).

The search space is small: `C(9,5) * 5! = 126 * 120 = 15120` cases.

### Result

The program prints (and asserts) the known maximum 16-digit [string](https://ourbigbook.com/codex/string):

`6531031914842725`
