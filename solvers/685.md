# Project Euler 685 Solution - Inverse Digit Sum II

<https://projecteuler.net/problem=685>:

* [685.py](685.py)

This repository contains a pure-Python solution for Project Euler 685.

## Core ideas

### 1) Order by length then lexicographic
All [positive integers](https://ourbigbook.com/codex/positive-integer) with a fixed [digit sum](https://ourbigbook.com/codex/digit-sum) are naturally ordered by numeric value.
For a fixed [digit](https://ourbigbook.com/codex/numerical-digit) length `L`, numeric order matches [lexicographic order](https://ourbigbook.com/codex/lexicographic-order) on the [digit](https://ourbigbook.com/codex/numerical-digit) strings,
and all shorter lengths come first.  
So to find the *m-th* number with [digit sum](https://ourbigbook.com/codex/digit-sum) `s`:

1. Find the first length `L` where the cumulative count of valid `L`-[digit](https://ourbigbook.com/codex/numerical-digit) numbers reaches `m`.
2. “Unrank” the `k`-th string among the `L`-[digit](https://ourbigbook.com/codex/numerical-digit) strings whose [digits](https://ourbigbook.com/codex/numerical-digit) sum to `s`.

### 2) Switch to a small “deficit” sum
Let a [digit](https://ourbigbook.com/codex/numerical-digit) be `a` and define its *deficit* as `x = 9 - a` (so `x` is in `0..9`).

For an `L`-[digit](https://ourbigbook.com/codex/numerical-digit) number with [digit sum](https://ourbigbook.com/codex/digit-sum) `s`:

```
sum(a_i) = s
sum(9 - x_i) = s
9L - sum(x_i) = s
sum(x_i) = 9L - s = deficit
```

In this problem the required length is close to `s/9`, so `deficit = 9L - s` stays relatively small.
Counting and [unranking](https://ourbigbook.com/codex/unranking) becomes much easier in terms of this small deficit.

### 3) Counting with inclusion–exclusion
We need the number of sequences `(x_1..x_L)` such that:

- `0 <= x_i <= 9`
- `x_1 + ... + x_L = deficit`

This is the coefficient of `z^deficit` in `(1 + z + ... + z^9)^L`, computed with a standard
bounded-composition [inclusion–exclusion](https://ourbigbook.com/codex/inclusion-exclusion-principle) formula:

```
Σ (-1)^j * C(L, j) * C(deficit - 10j + L - 1, deficit - 10j)
```

Leading-zero handling is done by subtracting the sequences where the first [digit](https://ourbigbook.com/codex/numerical-digit) is `0`
(which corresponds to first deficit [digit](https://ourbigbook.com/codex/numerical-digit) being `9`).

### 4) Unranking without building the full integer
Once the correct length `L` is known, [digits](https://ourbigbook.com/codex/numerical-digit) are chosen from most significant to least.
At each step, a [digit](https://ourbigbook.com/codex/numerical-digit) choice is accepted if the number of completions for the suffix
covers the remaining [matrix rank](https://ourbigbook.com/codex/matrix-rank) `k`.

Sometimes the next [digit](https://ourbigbook.com/codex/numerical-digit) is forced to be `9` for a very long stretch; instead of appending
those `9`s one-by-one, the code jumps over runs using a small [binary search](https://ourbigbook.com/codex/binary-search) on the suffix length.

### 5) Modular construction for huge numbers
The answer only requires values [modulo](https://ourbigbook.com/codex/modulo) `1_000_000_007`.
When appending a block of repeated [digits](https://ourbigbook.com/codex/numerical-digit), [modular arithmetic](https://ourbigbook.com/codex/modular-arithmetic) avoids materializing the
full number:

- Appending `t` [digits](https://ourbigbook.com/codex/numerical-digit) multiplies the prefix by `10^t`.
- The value of the repeated-digit block `ddd...d` is:

```
d * (10^t - 1) / 9
```

(using the [modular inverse](https://ourbigbook.com/codex/modular-inverse) of `9`).

## Complexity notes
For each `n`:

- Only a few [digit](https://ourbigbook.com/codex/numerical-digit) lengths are tested to locate the correct length.
- The deficit is small, so counting uses short [inclusion–exclusion](https://ourbigbook.com/codex/inclusion-exclusion-principle) sums.
- [Unranking](https://ourbigbook.com/codex/unranking) consumes deficit quickly and only uses occasional [binary searches](https://ourbigbook.com/codex/binary-search) to skip runs.

Overall runtime is practical in pure Python.
