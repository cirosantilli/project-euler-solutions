# Project Euler 904 Solution - Pythagorean Angle

<https://projecteuler.net/problem=904>:

* [904.py](904.py)

This program computes

\[
F(N,L)=\sum_{n=1}^{N} f(\sqrt[3]{n},L)
\]

where `f(α, L)` selects an [integer](https://ourbigbook.com/codex/integer) [right triangle](https://ourbigbook.com/codex/right-triangle) with [hypotenuse](https://ourbigbook.com/codex/hypotenuse) `≤ L` whose **median [angle](https://ourbigbook.com/codex/angle)** `θ`
(the smaller [angle](https://ourbigbook.com/codex/angle) between the [triangle medians](https://ourbigbook.com/codex/triangle-median) to the two legs) is closest to `α` (degrees). If several
[triangles](https://ourbigbook.com/codex/triangle) have the same minimum deviation, the one with the **largest [area](https://ourbigbook.com/codex/area)** is chosen.

The implementation avoids brute-force enumeration of all [right triangles](https://ourbigbook.com/codex/right-triangle) up to `L=10^{10}`.

## Main ideas

### 1) A direct expression for the median angle

For a [right triangle](https://ourbigbook.com/codex/right-triangle) with legs `a,b`, the [tangent](https://ourbigbook.com/codex/tangent) of the median [angle](https://ourbigbook.com/codex/angle) `θ` satisfies:

\[
\tan(\theta)=\frac{3ab}{2(a^2+b^2)}.
\]

This means we can evaluate `θ` using only [integer arithmetic](https://ourbigbook.com/codex/integer-arithmetic) plus one `atan`.

### 2) Euclid parameterization + a one-variable function

Every [integer](https://ourbigbook.com/codex/integer) [right triangle](https://ourbigbook.com/codex/right-triangle) is a scale multiple of a Euclid triple:

\[
(a,b,c)=k\,(m^2-n^2,\;2mn,\;m^2+n^2),\quad m>n>0.
\]

Scaling by `k` does not change `θ`. Therefore, for any primitive shape with [hypotenuse](https://ourbigbook.com/codex/hypotenuse) `c₀`,
the best (largest-area) representative under `c ≤ L` is obtained by taking
`k = ⌊L / c₀⌋`.

Using `t = n/m`, the median-angle [tangent](https://ourbigbook.com/codex/tangent) becomes a one-variable function

\[
g(t)=\tan(\theta)=\frac{3t(1-t^2)}{(1+t^2)^2}.
\]

It increases on `[0, \sqrt2-1]` and decreases on `[\sqrt2-1, 1]`, so each target value in-range
has two real solutions.

### 3) Two real target ratios via binary search

For each `α`, compute `y = tan(α)`. Then find `t₁` and `t₂` solving `g(t)=y` on the increasing and
decreasing branches using [binary search](https://ourbigbook.com/codex/binary-search). The optimal [rational](https://ourbigbook.com/codex/rational) `n/m` must lie very close to one of
these real roots.

### 4) Continued fractions with the *circle* constraint

The [hypotenuse](https://ourbigbook.com/codex/hypotenuse) of the primitive Euclid triple is `m^2 + n^2`, so the constraint is

\[
m^2+n^2 \le L.
\]

For each real root `t`, we approximate it by [rationals](https://ourbigbook.com/codex/rational) `n/m` using [continued fractions](https://ourbigbook.com/codex/continued-fraction), but we stop
when the next convergent would violate `n^2+m^2 ≤ L`. At that final step, the best admissible
fractions are among the **semiconvergents** between the last two convergents. Their [numerator](https://ourbigbook.com/codex/numerator) and
[denominator](https://ourbigbook.com/codex/denominator) are linear in an [integer](https://ourbigbook.com/codex/integer) parameter `k`, so the [circle](https://ourbigbook.com/codex/circle) constraint becomes a [quadratic
inequality](https://ourbigbook.com/codex/quadratic-inequality), letting us jump straight to the largest feasible `k` (and check a tiny neighborhood).

This yields only a small handful of candidates per `α`.

### 5) Exact tie-breaking by maximum area

For each candidate primitive shape `(a,b,c)`, we scale it by `k = ⌊L/c⌋`. If multiple candidates
achieve the same minimum `|θ-α|`, we compare their scaled areas, which are proportional to
`k^2 * a * b`.

The Python implementation also keeps two small constant-factor details explicit: the branch roots
are refined with a fixed [bisection](https://ourbigbook.com/codex/bisection) count that is already beyond the precision needed for the
[rational](https://ourbigbook.com/codex/rational) search, and Euclid pairs with the same [integer parity](https://ourbigbook.com/codex/integer-parity) are reduced by the known factor `2` instead
of running a full `gcd` on every candidate triple.
