# Project Euler 35 Solution - Circular Primes

<https://projecteuler.net/problem=35>:

* [35.py](35.py)
* [35.lean](35.lean)

A number is a **[circular prime](https://ourbigbook.com/codex/circular-prime)** if every rotation of its [digits](https://ourbigbook.com/codex/numerical-digit) is [prime](https://ourbigbook.com/codex/prime-number) (e.g., 197 → 197, 971, 719).

## Key ideas

1. **[Prime](https://ourbigbook.com/codex/prime-number) lookup via [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve)**
   - Build a fast [primality](https://ourbigbook.com/codex/primality) table using the [Sieve of Eratosthenes](https://ourbigbook.com/codex/sieve-of-eratosthenes).
   - For safety with arbitrary limits, [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) up to `10^d` where `d = number of digits of (limit-1)`, because rotating [digits](https://ourbigbook.com/codex/numerical-digit) preserves digit count and stays below `10^d`.

2. **[Digit](https://ourbigbook.com/codex/numerical-digit) [pruning](https://ourbigbook.com/codex/search-pruning)**
   - For any multi-digit [circular prime](https://ourbigbook.com/codex/circular-prime), all [digits](https://ourbigbook.com/codex/numerical-digit) must be from `{1,3,7,9}`.
   - If a number contains `0,2,4,5,6,8`, some rotation ends with an even digit or 5 ⇒ composite.
   - Single-digit [primes](https://ourbigbook.com/codex/prime-number) `{2,3,5,7}` are handled separately.

3. **Rotation checking**
   - Generate all rotations (implemented with arithmetic shifting) and check each rotation in O(1) using the [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) table.

4. **Avoid double work**
   - Maintain a `processed` [array](https://ourbigbook.com/codex/array) for numbers `< limit` to avoid re-checking different rotations of the same digit-cycle.

## Result
The program computes the number of [circular primes](https://ourbigbook.com/codex/circular-prime) below one million and prints:

- **55**
