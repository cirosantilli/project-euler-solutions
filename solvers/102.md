# Project Euler 102 Solution - Triangle Containment

<https://projecteuler.net/problem=102>:

* [102.py](102.py)

## Idea
A [point](https://ourbigbook.com/codex/point) is inside a [triangle](https://ourbigbook.com/codex/triangle) iff it lies on the same side of all three directed [polygon sides](https://ourbigbook.com/codex/side-of-a-polygon).

For a [triangle](https://ourbigbook.com/codex/triangle) with [polygon vertices](https://ourbigbook.com/codex/vertex-of-a-polygon) `A, B, C` and [point](https://ourbigbook.com/codex/point) `P` (here `P = (0,0)`), compute the [signed areas](https://ourbigbook.com/codex/signed-area) / [two-dimensional cross products](https://ourbigbook.com/codex/two-dimensional-cross-product):

- `s1 = cross(B-A, P-A)`
- `s2 = cross(C-B, P-B)`
- `s3 = cross(A-C, P-C)`

If `s1, s2, s3` are all positive or all negative, then `P` is inside the [triangle](https://ourbigbook.com/codex/triangle).
To enforce **strictly inside**, any zero [two-dimensional cross product](https://ourbigbook.com/codex/two-dimensional-cross-product) ([point](https://ourbigbook.com/codex/point) on a [polygon side](https://ourbigbook.com/codex/side-of-a-polygon)) is rejected.

## Implementation
- Read `0102_triangles.txt` (each line has 6 comma-separated [integers](https://ourbigbook.com/codex/integer): `x1,y1,x2,y2,x3,y3`)
- For each [triangle](https://ourbigbook.com/codex/triangle), apply the [two-dimensional cross product](https://ourbigbook.com/codex/two-dimensional-cross-product) [planar orientation test](https://ourbigbook.com/codex/planar-orientation-test) against the [origin](https://ourbigbook.com/codex/origin)
- Count how many [triangles](https://ourbigbook.com/codex/triangle) contain the [origin](https://ourbigbook.com/codex/origin) and print the count

The two example [triangles](https://ourbigbook.com/codex/triangle) from the statement are included as `assert` tests.
