# Project Euler 58 Solution - Spiral Primes

<https://projecteuler.net/problem=58>:

* [58.py](58.py)
* [Python source equivalence proof](58.py.lean)
* [58.lean](58.lean)

In the square spiral of odd side length `s`, the only new diagonal values introduced when expanding from side `s-2` to `s` are the four corner values:

- `s²`
- `s² - (s-1)`
- `s² - 2(s-1)`
- `s² - 3(s-1)`

For `s > 1`, `s²` is an odd [square number](https://ourbigbook.com/codex/square-number) and therefore not [prime](https://ourbigbook.com/codex/prime-number), so only the other three corners need [primality testing](https://ourbigbook.com/codex/primality-testing).

We maintain:
- `total_diag`: total count of numbers on both diagonals (`1`, then `+4` per layer)
- `prime_count`: number of [primes](https://ourbigbook.com/codex/prime-number) on both diagonals (`+0..3` per layer)

After each layer, the ratio is `prime_count / total_diag`. We need the first side length where this ratio falls below `10%`, which can be checked exactly using [integers](https://ourbigbook.com/codex/integer):
`prime_count * 10 < total_diag`.

[Primality testing](https://ourbigbook.com/codex/primality-testing) is done with a fast deterministic Miller–Rabin test (safe for 64-bit [integers](https://ourbigbook.com/codex/integer)), which is more than sufficient since the maximum values here are about `(26241)² ≈ 6.9e8`.

The Python source proof checks the actual Miller–Rabin routine and both source loops. A shared collection of 6,487 [Pratt certificates](https://ourbigbook.com/codex/primality-testing) supplies prime proofs, while proper factors supply composite proofs. These establish all diagonal counts through layer 13,120, including every earlier ratio. At that layer there are 5,248 primes among 52,481 diagonal entries, giving the first ratio below one tenth and side length 26,241. The proof checks agreement of the source algorithm’s counts on this finite range; it does not assume general Miller–Rabin correctness.

From the repository root, `python3 generate_spiral_certificates.py --check` reproduces and compares all 156 generated Lean modules using [the certificate data](../data/p58-certificates.json). The generator is outside the trusted proof: Lean independently checks the generated arithmetic and the source equivalence. Run `data/project-euler-statements/formalsw/formalsw solvers/58.py` to check the source proof after building the dependencies.
