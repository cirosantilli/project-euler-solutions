# Project Euler 878 Solution - XOR-Equation B

<https://projecteuler.net/problem=878>:

* [878.py](878.py)

## Main ideas

Read each [integer](https://ourbigbook.com/codex/integer) as a [polynomial](https://ourbigbook.com/codex/polynomial) over `GF(2)`, with [XOR](https://ourbigbook.com/codex/xor) as addition and
[carryless multiplication](https://ourbigbook.com/codex/carryless-multiplication) as [polynomial multiplication](https://ourbigbook.com/codex/polynomial-multiplication).  With `A` and `B` for
the [polynomials](https://ourbigbook.com/codex/polynomial) of `a` and `b`, the expression in the problem is

```text
A^2 + tAB + B^2.
```

The transformation

```text
(a, b) -> (b, a ^ (b << 1))
```

preserves that [quadratic form](https://ourbigbook.com/codex/quadratic-form).  Its inverse is

```text
(a, b) -> (b ^ (a << 1), a).
```

So valid pairs are grouped into orbits with a fixed [mathematical invariant](https://ourbigbook.com/codex/invariant-mathematics) value.

For a nonzero [ordered pair](https://ourbigbook.com/codex/ordered-pair), the pair is the first ordered point on its orbit
exactly when its inverse step is not ordered:

```text
b ^ (a << 1) > a
```

This gives a direct canonical-seed test.  The special pair `(0, 0)` is a fixed
orbit and is counted once.

If `m` has `d` bits, every seed with [mathematical invariant](https://ourbigbook.com/codex/invariant-mathematics) at most `m` lies in the finite
box

```text
0 <= a <= b < 2^ceil((d + 1) / 2).
```

The solver scans only this seed box.  For each candidate it computes the
carryless [quadratic form](https://ourbigbook.com/codex/quadratic-form), keeps only canonical seeds with value at most `m`,
and then walks the orbit forward until `b > N`.  Along that walk the [mathematical invariant](https://ourbigbook.com/codex/invariant-mathematics)
does not need to be checked again.

## Checks

The code keeps the statement checks:

- `7 XOR-product 3 = 9`
- `(a, b) = (3, 6)` has [mathematical invariant](https://ourbigbook.com/codex/invariant-mathematics) `5`
- `G(1000, 100) = 398`

It also checks the small orbit example `G(5, 1) = 4`.

## Complexity

Let `S = 2^ceil((bit_length(m) + 1) / 2)`.  The seed scan costs `O(S^2)`, and
the forward walks add one step per counted orbit point up to `N`.  The
implementation keeps only the square table for the seed box and otherwise uses
constant working state.
