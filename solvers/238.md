# Project Euler 238 Solution - Infinite String Tour

<https://projecteuler.net/problem=238>:

* [238.py](238.py)

This solution relies on two key ideas:

## 1) Periodicity

The sequence is

* `s0 = 14025256`
* `s(n+1) = s(n)^2 mod 20300713`
* `w` is the infinite decimal [digit](https://ourbigbook.com/codex/numerical-digit) string formed by concatenating `s0, s1, s2, ...`.

Because the modulus is finite, the `s(n)` sequence is purely periodic (after the start) and therefore the [digit](https://ourbigbook.com/codex/numerical-digit) stream `w` is also periodic. Let

* `L` = number of [digits](https://ourbigbook.com/codex/numerical-digit) in one full period of `w`
* `T` = sum of those `L` [digits](https://ourbigbook.com/codex/numerical-digit)

Every time you extend a substring by exactly `L` [digits](https://ourbigbook.com/codex/numerical-digit), you add exactly `T` to its [digit sum](https://ourbigbook.com/codex/digit-sum).

### Consequence: `p(k)` is periodic in `k` with period `T`

Represent sums `k` by their [remainder](https://ourbigbook.com/codex/remainder) `k mod T` (with [remainder](https://ourbigbook.com/codex/remainder) `0` meaning `k = T`).

For a starting position whose prefix [digit sum](https://ourbigbook.com/codex/digit-sum) is `S`, the possible [digit sums](https://ourbigbook.com/codex/digit-sum) you can obtain by ending at some later position are exactly the [remainders](https://ourbigbook.com/codex/remainder)

`(U - S) mod T`

where `U` ranges over all [prefix sums](https://ourbigbook.com/codex/prefix-sum) that occur in the period.

If a [remainder](https://ourbigbook.com/codex/remainder) is achievable from a start position, then the **smallest** achievable sum with that [remainder](https://ourbigbook.com/codex/remainder) lies in `[1..T]`; adding whole periods generates all larger sums with the same [remainder](https://ourbigbook.com/codex/remainder). That means the earliest start for sums with [remainder](https://ourbigbook.com/codex/remainder) `r` is the same for `r`, `r+T`, `r+2T`, ...

So:

*Compute `p(k)` only for `k = 1..T` and repeat it for all larger `k`.*

## 2) Bitset covering with circular shifts

Let `V` be the set of [remainders](https://ourbigbook.com/codex/remainder) ([mod](https://ourbigbook.com/codex/modulo-operation) `T`) that appear as [prefix sums](https://ourbigbook.com/codex/prefix-sum) during one period. Build a [bitset](https://ourbigbook.com/codex/bitset) `present` of length `T`:

* bit `u` is `1` iff `u ∈ V`

If the [prefix sum](https://ourbigbook.com/codex/prefix-sum) at a start position is `S`, then the set of achievable sums from that start (within one period) is exactly the **circular right shift** of `present` by `S`.

Now compute `p(k)` for all `k=1..T` by scanning starts in increasing order:

1. Maintain a [bitset](https://ourbigbook.com/codex/bitset) `unknown` of sums not yet assigned their `p(k)`.
2. For each start position `z`:
   * `new = unknown & rotated_present`
   * Every `1` bit in `new` has `p(k) = z` (this is the first time it becomes reachable).
   * Add `z * popcount(new)` to the running total and clear those bits from `unknown`.

Because `p(k)` is very small on average for this problem, `unknown` becomes empty after only a few dozen start positions, so the expensive [bitset](https://ourbigbook.com/codex/bitset) operations are performed only a small number of times.

## Implementation notes

* The solution stores the period [digit](https://ourbigbook.com/codex/numerical-digit) stream as ASCII bytes (≈ 19 MB).
* `present` and `unknown` are Python `int` values used as big [bitsets](https://ourbigbook.com/codex/bitset), taking advantage of fast C-level `&`, shifts, and `.bit_count()`.
* The problem’s check value is asserted:

  `sum_{k=1}^{1000} p(k) = 4742`.
