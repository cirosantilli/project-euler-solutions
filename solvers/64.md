# Project Euler 64 Solution - Odd Period Square Roots

<https://projecteuler.net/problem=64>:

* [64.py](64.py)
* [64.py.lean](64.py.lean)
* [64.lean](64.lean)

For each non-square [integer](https://ourbigbook.com/codex/integer) `N`, the [continued fraction](https://ourbigbook.com/codex/continued-fraction) of `sqrt(N)` is periodic.  
To find the period length efficiently, use the standard [recurrence relation](https://ourbigbook.com/codex/recurrence-relation):

- `a0 = floor(sqrt(N))`
- Initialize `m = 0`, `d = 1`, `a = a0`
- Repeat:
  - `m = d*a - m`
  - `d = (N - m*m) / d`
  - `a = floor((a0 + m) / d)`
  - count steps as the period length

For [square roots](https://ourbigbook.com/codex/square-root), the period completes when `a` becomes `2*a0`.  
We compute this period length for each `N <= 10000`, assigning period zero to [perfect squares](https://ourbigbook.com/codex/perfect-square), and count how many periods are odd.

The program includes the given check: for `N <= 13`, the number of odd periods is `4`.

The reference records the first position of each complete `(m, d, a)` state. When a state repeats, the difference of its positions gives the repeating part's length. It has no iteration cutoff. The optimized solver instead recognizes the terminal coefficient `2*a0`.

Both Python entry points accept a signed upper bound and return zero for bounds below two.

The reduced-state model has `0 <= m <= a0`, `d > 0`, `a0 - m < d <= a0 + m`, and `d` dividing `N - m*m`. One recurrence step preserves these properties and has an explicit inverse. It therefore permutes a finite set of states: the orbit returns to its first reduced state without acquiring a tail. Its predecessor at the first return is exactly `(a0, 1)`, the unique reduced state with coefficient `2*a0`.

The Lean statement uses this proved least return time without an iteration budget. The reference source proof tracks the saved first index for every tuple key, proving the first repeat yields the same period.
