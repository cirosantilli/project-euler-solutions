# Project Euler 690 Solution - Tom and Jerry

<https://projecteuler.net/problem=690>:

* [690.py](690.py)

This solver counts **Tom [graphs](https://ourbigbook.com/codex/graph)** ([graphs](https://ourbigbook.com/codex/graph) on which Tom can guarantee catching Jerry) up to [graph isomorphism](https://ourbigbook.com/codex/graph-isomorphism) and outputs `T(2019) mod 1_000_000_007`.

## Main ideas

### 1) Structural reduction: Tom graphs are restricted forests
A Tom [graph](https://ourbigbook.com/codex/graph) must be acyclic (a [forest](https://ourbigbook.com/codex/forest)). Moreover, not every [forest](https://ourbigbook.com/codex/forest) works: the [connected components](https://ourbigbook.com/codex/connected-component) must be a special class of [trees](https://ourbigbook.com/codex/tree-graph-theory) called **[lobsters](https://ourbigbook.com/codex/lobster-tree)** ([trees](https://ourbigbook.com/codex/tree-graph-theory) whose “leaf-pruned” core is a caterpillar).

So:

- **Connected Tom [graphs](https://ourbigbook.com/codex/graph)** ⇔ **lobster [trees](https://ourbigbook.com/codex/tree-graph-theory)**
- **All Tom [graphs](https://ourbigbook.com/codex/graph)** ⇔ **[forests](https://ourbigbook.com/codex/forest) ([multisets](https://ourbigbook.com/codex/multiset)) of lobster [trees](https://ourbigbook.com/codex/tree-graph-theory)**

### 2) Count lobster trees via an explicit generating function
Let

- `P(x) = ∏_{k≥1} 1/(1 - x^k)` be the [generating function](https://ourbigbook.com/codex/generating-function) for [integer partitions](https://ourbigbook.com/codex/integer-partition).
  Its coefficients are the partition numbers `p(n)`.

There is a closed-form [ordinary generating function](https://ourbigbook.com/codex/ordinary-generating-function) `A(x)` for the number of unlabeled [lobsters](https://ourbigbook.com/codex/lobster-tree) on `n` [graph vertices](https://ourbigbook.com/codex/vertex-of-a-graph), expressed using `P(x)`, `P(x^2)`, and a few [rational](https://ourbigbook.com/codex/rational-number) factors. The code expands this series up to [polynomial degree](https://ourbigbook.com/codex/degree-of-a-polynomial) `2019` using basic [formal power series](https://ourbigbook.com/codex/formal-power-series) operations (addition, multiplication, series inversion).

### 3) Build forests from trees using the Euler transform
If `b(n)` counts [connected components](https://ourbigbook.com/codex/connected-component) of size `n` (here, lobster [trees](https://ourbigbook.com/codex/tree-graph-theory)), then the [ordinary generating function](https://ourbigbook.com/codex/ordinary-generating-function) for unlabeled forests is

`F(x) = ∏_{k≥1} (1 - x^k)^(-b(k))`.

The coefficient sequence of `F(x)` is the **[Euler transform](https://ourbigbook.com/codex/euler-transform-of-a-sequence)** of `b(n)`. A standard `O(n^2)` [recurrence relation](https://ourbigbook.com/codex/recurrence-relation) computes it efficiently [modulo](https://ourbigbook.com/codex/modulo) `1_000_000_007`.

### 4) Mod arithmetic throughout
All coefficients are computed **[modulo](https://ourbigbook.com/codex/modulo) 1_000_000_007**, including divisions handled via [modular inverses](https://ourbigbook.com/codex/modular-inverse) (the modulus is [prime](https://ourbigbook.com/codex/prime)).

## Complexity
With `n = 2019`:

- Partition [DP](https://ourbigbook.com/codex/dynamic-programming): `O(n^2)`
- A handful of truncated [polynomial multiplications](https://ourbigbook.com/codex/polynomial-multiplication) / inversions: `O(n^2)`
- [Euler transform](https://ourbigbook.com/codex/euler-transform-of-a-sequence): `O(n^2)`

This fits comfortably in time in pure Python.
