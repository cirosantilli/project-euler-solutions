# Self Powers (last 10 digits)

We need the last 10 [digits](https://ourbigbook.com/codex/numerical-digit) of:

\[
\sum_{i=1}^{1000} i^i
\]

Only the last 10 [digits](https://ourbigbook.com/codex/numerical-digit) matter, so we compute everything [modulo](https://ourbigbook.com/codex/modulo-operation) \(10^{10}\).

## Key idea
Use [modular exponentiation](https://ourbigbook.com/codex/modular-exponentiation):

- Compute each term as `pow(i, i, 10**10)` (fast [exponentiation](https://ourbigbook.com/codex/exponentiation) [modulo](https://ourbigbook.com/codex/modulo-operation)).
- Accumulate the [sum](https://ourbigbook.com/codex/sum) [modulo](https://ourbigbook.com/codex/modulo-operation) \(10^{10}\) to keep numbers small.

This runs quickly because it performs only 1000 [modular exponentiations](https://ourbigbook.com/codex/modular-exponentiation).

## Output formatting
The answer may have leading zeros, so the final value is printed as exactly 10 [digits](https://ourbigbook.com/codex/numerical-digit) using `zfill(10)`.

## Included assertion
The statement provides the check:

\[
1^1 + 2^2 + \dots + 10^{10} = 10405071317
\]

The program asserts this exact value and also checks its last 10 [digits](https://ourbigbook.com/codex/numerical-digit) (`0405071317`).
