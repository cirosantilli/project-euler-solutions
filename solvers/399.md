# Project Euler 399 Solution - Squarefree Fibonacci Numbers

<https://projecteuler.net/problem=399>:

* [399.py](399.py)

This repository contains a standalone `main.py` solution (standard library only).

## Main techniques used

### 1) Rank of apparition (entry point)
For a [prime](https://ourbigbook.com/codex/prime) `p`, define `z(p)` as the smallest positive index such that:

- `p | F_{z(p)}`

A key [Fibonacci](https://ourbigbook.com/codex/fibonacci-number) property is:

- `p | F_n` **iff** `z(p) | n`

For [primes](https://ourbigbook.com/codex/prime) `p ≠ 5`, `z(p)` is known to divide `p − (5/p)`, where `(5/p)` is the [Legendre symbol](https://ourbigbook.com/codex/legendre-symbol).
So `z(p)` always divides either `p − 1` or `p + 1`.

### 2) Using the problem’s assumption (Wall’s conjecture instance)
The statement asks us to assume that for every [prime](https://ourbigbook.com/codex/prime) `p`, the first [Fibonacci number](https://ourbigbook.com/codex/fibonacci-number) divisible by `p`
(i.e. `F_{z(p)}`) is **not** divisible by `p²`.

Under this assumption, the first index where `p²` divides a [Fibonacci number](https://ourbigbook.com/codex/fibonacci-number) is:

- `z(p²) = p · z(p)`

So:

- `p² | F_n` **iff** `(p · z(p)) | n`

This converts “[squarefree](https://ourbigbook.com/codex/squarefree-integer) [Fibonacci](https://ourbigbook.com/codex/fibonacci-number) values” into a condition purely about **indices**.

### 3) Turning squarefreeness into “avoid these moduli”
Define a “bad modulus” for each [prime](https://ourbigbook.com/codex/prime):

- `m(p) = p · z(p)`

Then `F_n` is [squarefree](https://ourbigbook.com/codex/squarefree-integer) exactly when `n` is **not** a multiple of any `m(p)`.

So the problem becomes: find the `k`-th index `n` that is not divisible by any `m(p)`.

### 4) Inclusion–exclusion over LCMs
Let `mods = { m(p) }` with `m(p) ≤ N` (larger moduli cannot divide indices `≤ N`).

The count of “good” indices `≤ N` can be computed by [inclusion–exclusion](https://ourbigbook.com/codex/inclusion-exclusion-principle):

- `count(N) = Σ (-1)^{|S|} · ⌊ N / lcm(S) ⌋`

where `S` ranges over all [subsets](https://ourbigbook.com/codex/subset) of `mods` (the empty [subset](https://ourbigbook.com/codex/subset) contributes `lcm=1`).

To make this fast, the program enumerates only those [subsets](https://ourbigbook.com/codex/subset) whose [LCM](https://ourbigbook.com/codex/least-common-multiple) stays `≤ Nmax`,
and groups identical [LCMs](https://ourbigbook.com/codex/least-common-multiple) by summing their [coefficients](https://ourbigbook.com/codex/coefficient).

### 5) Binary search for the target index
`count(N)` is monotone in `N`, so we [binary search](https://ourbigbook.com/codex/binary-search) the smallest `n` with:

- `count(n) ≥ 100,000,000`

That `n` is the index of the `100,000,000`-th [squarefree](https://ourbigbook.com/codex/squarefree-integer) [Fibonacci number](https://ourbigbook.com/codex/fibonacci-number).

### 6) Output formatting
- **Last 16 [digits](https://ourbigbook.com/codex/numerical-digit)**: computed with [Fibonacci](https://ourbigbook.com/codex/fibonacci-number) [Fibonacci fast doubling](https://ourbigbook.com/codex/fibonacci-fast-doubling) [modulo](https://ourbigbook.com/codex/modulo-operation) `10^16`.
- **[Scientific notation](https://ourbigbook.com/codex/scientific-notation)**: uses `log10(F_n) ≈ n·log10(φ) − log10(√5)` and rounds the mantissa to 1 decimal.

- The 200th [squarefree](https://ourbigbook.com/codex/squarefree-integer) [Fibonacci number](https://ourbigbook.com/codex/fibonacci-number) example, including the exact value and the formatted output
