# Project Euler 98 Solution - Anagramic Squares

<https://projecteuler.net/problem=98>:

* [98.py](98.py)
* [98.lean](98.lean)

## Key idea
Two [anagram](https://ourbigbook.com/codex/anagram) words can map to two [square numbers](https://ourbigbook.com/codex/square-number) if there exists a **[bijection](https://ourbigbook.com/codex/bijection)** between letters and [digits](https://ourbigbook.com/codex/numerical-digit) such that:
- the same letter always maps to the same [digit](https://ourbigbook.com/codex/numerical-digit),
- different letters map to different [digits](https://ourbigbook.com/codex/numerical-digit),
- no mapped number has a leading zero.

## Approach
1. **Load all words** and group them by their sorted letters ([anagram](https://ourbigbook.com/codex/anagram) classes).
2. For every word length `L` that occurs in an [anagram](https://ourbigbook.com/codex/anagram) group:
   - generate all `L`-[digit](https://ourbigbook.com/codex/numerical-digit) [square numbers](https://ourbigbook.com/codex/square-number),
   - store them in a [set](https://ourbigbook.com/codex/set) for fast membership tests,
   - additionally group these [square numbers](https://ourbigbook.com/codex/square-number) by a **pattern signature**.
3. The **pattern signature** encodes the equality structure of a [string](https://ourbigbook.com/codex/string), e.g.:
   - `CARE -> (0,1,2,3)`
   - `NOON -> (0,1,1,0)`
   A word can only map to [square numbers](https://ourbigbook.com/codex/square-number) with the same signature.
4. For each [anagram](https://ourbigbook.com/codex/anagram) group and each word `w1` in it:
   - iterate over [square number](https://ourbigbook.com/codex/square-number) candidates matching `w1`’s signature,
   - build the letter→[digit](https://ourbigbook.com/codex/numerical-digit) mapping from `w1` to the [square number](https://ourbigbook.com/codex/square-number),
   - apply the same mapping to other [anagrams](https://ourbigbook.com/codex/anagram) `w2` and check if the resulting number is also in the [square number](https://ourbigbook.com/codex/square-number) [set](https://ourbigbook.com/codex/set).
5. Track the maximum [square number](https://ourbigbook.com/codex/square-number) found.

This avoids brute-forcing all [digit](https://ourbigbook.com/codex/numerical-digit) assignments by heavily [pruning](https://ourbigbook.com/codex/search-pruning) using length constraints and signature matching.
