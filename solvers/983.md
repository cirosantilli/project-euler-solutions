# Project Euler 983 Solution - Consonant Circle Crossing

<https://projecteuler.net/problem=983>:

* [983.py](983.py)

The solver uses the same constructive family that was validated in the previous rollout:

- Pick `k` [vectors](https://ourbigbook.com/codex/vector) from opposite lattice-point pairs on the [circle](https://ourbigbook.com/codex/circle) `x^2 + y^2 = m`.
- Build [circle](https://ourbigbook.com/codex/circle) centers as all even [subset sums](https://ourbigbook.com/codex/subset-sum) of those [vectors](https://ourbigbook.com/codex/vector).
- This gives exactly `2^(k-1)` [circles](https://ourbigbook.com/codex/circle).
- For the target (`n >= 500`), we use `k = 10`, so we search for a perfect `512`-[circle](https://ourbigbook.com/codex/circle) set.

For each candidate radius-square `m`, the code:

1. Uses the two-squares factorization rule to count antipodal lattice-vector
   pairs before enumerating the [circle](https://ourbigbook.com/codex/circle).
2. Enumerates opposite pairs of [lattice vectors](https://ourbigbook.com/codex/lattice-vector) on the [circle](https://ourbigbook.com/codex/circle).
3. Searches `k` chosen pairs and orientations by DFS, with one global-sign
   [symmetry](https://ourbigbook.com/codex/symmetry) removed.
4. Prunes a branch as soon as a signed sum of four chosen directions is already
   a displacement between two [radius](https://ourbigbook.com/codex/radius) [vectors](https://ourbigbook.com/codex/vector).
5. Builds the `512` centers only for surviving complete branches.
6. Runs a fast harmony-point count with early exit.
7. If the fast count matches `512`, runs strict validation:
   - no tangencies,
   - exactly `512` unique harmony points,
   - [graph](https://ourbigbook.com/codex/graph) connectivity.

The two statement checks are asserted directly by search:

- `R(2)^2 = 1` via `k = 2`
- `R(4)^2 = 5` via `k = 3`

To keep runtime practical in Python/PyPy for `k = 10`, the search uses the same
narrowed candidate family from the rollout (`p in {k, k+2}` and unit-coordinate
presence among [circle](https://ourbigbook.com/codex/circle) [lattice points](https://ourbigbook.com/codex/lattice-point)), then applies the displacement [pruning](https://ourbigbook.com/codex/pruning)
above and validates any hit strictly.
