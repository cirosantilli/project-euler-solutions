# Project Euler 482 Solution - The Incenter of a Triangle

<https://projecteuler.net/problem=482>:

* [482.py](482.py)

We want all **integer-sided** [triangles](https://ourbigbook.com/codex/triangle) `ABC` whose [incenter](https://ourbigbook.com/codex/incenter) is `I` and for which the three vertex distances `IA`, `IB`, `IC` are [integers](https://ourbigbook.com/codex/integer).  
For each such [triangle](https://ourbigbook.com/codex/triangle) define:

- `p` = [perimeter](https://ourbigbook.com/codex/perimeter)
- `L = p + IA + IB + IC`
- `S(P) = sum(L)` over all such [triangles](https://ourbigbook.com/codex/triangle) with `p ≤ P`

The problem asks for `S(10^7)` (and gives `S(10^3) = 3619`).

---

## 1) Tangency lengths and a right-triangle identity

Let `s = p/2` be the [semiperimeter](https://ourbigbook.com/codex/semiperimeter) and define the standard [tangency](https://ourbigbook.com/codex/tangency) lengths

- `x = s - a`, `y = s - b`, `z = s - c`

where `a = BC`, `b = CA`, `c = AB`.  
Then the sides are:

- `a = y + z`
- `b = z + x`
- `c = x + y`

Drop perpendiculars from the [incenter](https://ourbigbook.com/codex/incenter) `I` to the sides. Each perpendicular has length equal to the [inradius](https://ourbigbook.com/codex/inradius) `r`. On side `AB`, the [tangency](https://ourbigbook.com/codex/tangency) point is at distance `x` from `A`. This creates a [right triangle](https://ourbigbook.com/codex/right-triangle) with legs `x` and `r`, hence:

- `IA^2 = x^2 + r^2`
- `IB^2 = y^2 + r^2`
- `IC^2 = z^2 + r^2`

So each `(r, x, IA)` is a (possibly non‑primitive) **[Pythagorean triple](https://ourbigbook.com/codex/pythagorean-triple)**, and similarly for `y` and `z`.

---

## 2) The inradius is an integer

A key fact (and the reason the search becomes feasible) is:

> If the sides and `IA, IB, IC` are [integers](https://ourbigbook.com/codex/integer), then the [inradius](https://ourbigbook.com/codex/inradius) `r` is an [integer](https://ourbigbook.com/codex/integer).

A standard proof uses:
- the right-triangle equations above to show `4r^2` is an [integer](https://ourbigbook.com/codex/integer),
- a trigonometric/[sine-rule](https://ourbigbook.com/codex/law-of-sines) argument to show `r` is [rational](https://ourbigbook.com/codex/rational-number),
- and an [integer parity](https://ourbigbook.com/codex/integer-parity) contradiction to rule out half-integers, forcing `r ∈ ℤ`.

So we only need to consider **[integer](https://ourbigbook.com/codex/integer)** `r`.

---

## 3) Eliminating `r` using Heron’s formula

[Heron's formula](https://ourbigbook.com/codex/heron-s-formula) gives [area](https://ourbigbook.com/codex/area) `K` by:

`K^2 = s(s-a)(s-b)(s-c) = sxyz`

but also `K = r s`. Therefore:

`(rs)^2 = sxyz  =>  r^2 = xyz / (x + y + z)`

Equivalently:

`xyz = r^2 (x + y + z)`.

This is the central [diophantine condition](https://ourbigbook.com/codex/diophantine-condition) connecting the three [tangency](https://ourbigbook.com/codex/tangency) lengths.

---

## 4) Solving for `z` from `x, y, r`

From `xyz = r^2(x + y + z)` we can isolate `z`:

`z(xy - r^2) = r^2(x + y)`

so

`z = r^2(x + y) / (xy - r^2)`.

Thus for a fixed [inradius](https://ourbigbook.com/codex/inradius) `r` and a chosen pair `(x, y)`, there is **at most one** candidate `z`.

---

## 5) Efficient enumeration

### Step A — generate all `(r, x, u)` Pythagorean pairs under bounds
For `P`, we have:

- `s = x + y + z ≤ P/2`
- thus `x, y, z ≤ s - 2`

We also bound `r` using the fact that for fixed `s`, `r` is maximized by an [equilateral triangle](https://ourbigbook.com/codex/equilateral-triangle):

`r ≤ s * sqrt(3) / 9`.

We generate all [Pythagorean triples](https://ourbigbook.com/codex/pythagorean-triple) via [Euclid's formula](https://ourbigbook.com/codex/euclid-s-formula-for-pythagorean-triples):

- `a = m^2 - n^2`, `b = 2mn`, `c = m^2 + n^2` (primitive when `gcd(m,n)=1` and opposite [integer parity](https://ourbigbook.com/codex/integer-parity))
- scale by `k`

We keep all scaled pairs where one leg is `r` (bounded) and the other leg is `x` (bounded).  
This produces, for each `r`, a small list of valid `x` values and their corresponding [hypotenuse](https://ourbigbook.com/codex/hypotenuse) `u = sqrt(r^2 + x^2)`.

To avoid huge per-`r` Python structures, the implementation stores all pairs in flat arrays grouped by `r` using a [CSR](https://ourbigbook.com/codex/compressed-sparse-row-format)/[prefix-sum](https://ourbigbook.com/codex/prefix-sum) layout.

### Step B — for each `r`, try all pairs `(x, y)`
For each `r`, we:

1. take its list of `x` values,
2. loop over `x ≤ y`,
3. compute `z` using the formula above,
4. check `z` exists in the same `r`-bucket,
5. check `x + y + z ≤ P/2`,
6. add `L = 2(x+y+z) + u(x) + u(y) + u(z)`.

We enforce `x ≤ y ≤ z` to count each [triangle](https://ourbigbook.com/codex/triangle) once.

---
