# Project Euler 80 Solution - Square Root Digital Expansion

<https://projecteuler.net/problem=80>:

* [80.py](80.py)
* [80.lean](80.lean)

For each `n` from 1 to 100 that is **not** a [perfect square](https://ourbigbook.com/codex/perfect-square), we need the [sum](https://ourbigbook.com/codex/sum) of the first 100 [digits](https://ourbigbook.com/codex/numerical-digit) of `√n` (written as a [digit](https://ourbigbook.com/codex/numerical-digit) [string](https://ourbigbook.com/codex/string) with the [decimal](https://ourbigbook.com/codex/decimal) point removed).

Key idea: avoid floating point entirely by using [integer arithmetic](https://ourbigbook.com/codex/integer-arithmetic).

## Integer scaling trick

For `1 ≤ n ≤ 99`, we have `√n < 10`, so the first 100 [digits](https://ourbigbook.com/codex/numerical-digit) are:
- 1 [digit](https://ourbigbook.com/codex/numerical-digit) from the [integer](https://ourbigbook.com/codex/integer) part, plus
- the next 99 [digits](https://ourbigbook.com/codex/numerical-digit) after the [decimal](https://ourbigbook.com/codex/decimal) point.

That is exactly the [digits](https://ourbigbook.com/codex/numerical-digit) of:

`floor( √n * 10^99 )`

Compute this with an [integer square root](https://ourbigbook.com/codex/integer-square-root):

`floor( √n * 10^99 ) = isqrt( n * 10^(2*99) ) = isqrt( n * 10^198 )`

Python's `math.isqrt` computes the [integer square root](https://ourbigbook.com/codex/integer-square-root) efficiently for [big integers](https://ourbigbook.com/codex/arbitrary-precision-integer).

## Procedure

1. Skip [perfect squares](https://ourbigbook.com/codex/perfect-square) (1, 4, 9, ..., 100).
2. For each remaining `n`:
   - Compute `isqrt(n * 10^198)`, which is a 100-digit [integer](https://ourbigbook.com/codex/integer).
   - Sum its digits.
3. [Sum](https://ourbigbook.com/codex/sum) these [digit sums](https://ourbigbook.com/codex/digit-sum) over all irrational [square roots](https://ourbigbook.com/codex/square-root).

Includes assertions for:
- the provided example (`n=2` gives 475),
- the known final total (40886).
