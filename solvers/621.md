# Project Euler 621 Solution - Expressing an Integer as the Sum of Triangular Numbers

<https://projecteuler.net/problem=621>:

* [621.py](621.py)

## Key transformation: triangular numbers → odd squares

A [triangular number](https://ourbigbook.com/codex/triangular-number) is:

- \(T_k = \frac{k(k+1)}{2}\)

It satisfies the identity:

- \(8T_k + 1 = (2k+1)^2\)

So a representation

- \(n = T_a + T_b + T_c\)

is equivalent to

- \((2a+1)^2 + (2b+1)^2 + (2c+1)^2 = 8n + 3\)

Let \(N = 8n+3\). Because \(N \equiv 3 \pmod 8\), every representation of \(N\) as a sum of three squares has *all three squares \(\equiv 1 \pmod 8\)*, hence all three [integers](https://ourbigbook.com/codex/integer) are odd automatically.

If we count **ordered [integer](https://ourbigbook.com/codex/integer) triples with signs** \((x,y,z)\in\mathbb{Z}^3\) such that:

- \(x^2 + y^2 + z^2 = N\)

then each positive-odd triple corresponds to exactly \(2^3=8\) signed versions, so:

- \(G(n) = \dfrac{r_3(N)}{8}\)

where \(r_3(N)\) is the “sum of three squares” representation count that includes order and signs.

## Gauss/Cohen formula for \(r_3(N)\) (the only case we need)

Write:

- \(N = n_0 \, f^2\) where \(n_0\) is [squarefree](https://ourbigbook.com/codex/squarefree-integer) (the [squarefree part](https://ourbigbook.com/codex/squarefree-part) of \(N\))

For \(N \equiv 3 \pmod 8\), one has \(n_0 \equiv 3 \pmod 4\), and the corresponding negative **[fundamental discriminant](https://ourbigbook.com/codex/fundamental-discriminant)** is:

- \(D = -n_0\)

A classical formula (Gauss; modern presentation by Cohen) gives:

- \(r_3(N) = 12 \, L(\chi_D,0)\, \bigl(1-(D/2)\bigr)\, \sum_{d\mid f} \mu(d)\, (D/d)\, \sigma(f/d)\)

For our [congruence class](https://ourbigbook.com/codex/congruence-class) \(D\equiv 5 \pmod 8\), \((D/2)=-1\), so the factor becomes \(2\), and therefore:

- \(G(n) = \dfrac{r_3(N)}{8} = 3 \, L(\chi_D,0)\, \sum_{d\mid f} \mu(d)\, (D/d)\, \sigma(f/d)\)

Also:

- \(L(\chi_D,0) = \dfrac{h(D)}{w(D)/2}\)

where \(h(D)\) is the imaginary quadratic **[class number](https://ourbigbook.com/codex/class-number)**, and \(w(D)\in\{2,4,6\}\) counts [roots of unity](https://ourbigbook.com/codex/roots-of-unity) (only \(D=-3\) and \(D=-4\) are special).

Since \(\mu(d)=0\) whenever \(d\) is not [squarefree](https://ourbigbook.com/codex/squarefree-integer), the [divisor sum](https://ourbigbook.com/codex/divisor-sum) only needs [squarefree](https://ourbigbook.com/codex/squarefree-integer) \(d\), so it can be done by iterating over [subsets](https://ourbigbook.com/codex/subset) of [primes](https://ourbigbook.com/codex/prime) dividing \(f\).

## Computing the class number \(h(D)\) exactly

For negative discriminants, \(h(D)\) equals the number of **reduced** primitive positive definite [binary quadratic forms](https://ourbigbook.com/codex/binary-quadratic-form) \((a,b,c)\) with:

- \(b^2 - 4ac = D\)

Reduced forms satisfy:

- \(|b|\le a \le c\), and if \(|b|=a\) or \(a=c\) then \(b\ge 0\)

A standard bound gives \(a \le \sqrt{|D|/3}\), so we can enumerate all reduced forms by looping over \(a\) up to that limit. For each \(a\), instead of scanning all \(b\in[-a,a]\) (which is too slow), we solve the [integer congruence](https://ourbigbook.com/codex/integer-congruence):

- \(b^2 \equiv D \pmod{4a}\)

In this problem’s discriminant class (\(D\equiv 5 \pmod 8\)), it turns out that **only odd** \(a\) contribute, and the [integer congruence](https://ourbigbook.com/codex/integer-congruence) can be handled efficiently by:

- factoring \(a\) via a smallest-prime-factor [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve)
- finding [modular square roots](https://ourbigbook.com/codex/modular-square-root) for each [prime power](https://ourbigbook.com/codex/prime-power) using **[Tonelli-Shanks algorithm](https://ourbigbook.com/codex/tonelli-shanks-algorithm)** + **[Hensel lifting](https://ourbigbook.com/codex/hensel-lifting)**
- combining them with **[CRT](https://ourbigbook.com/codex/chinese-remainder-theorem)**

Each valid [residue class](https://ourbigbook.com/codex/residue-class) produces at most one candidate \(b\) in \([-a,a]\) with the required [integer parity](https://ourbigbook.com/codex/integer-parity), and then \(c\) follows from \(c=(b^2-D)/(4a)\).

## Implementation techniques used

- Deterministic [Miller-Rabin primality test](https://ourbigbook.com/codex/miller-rabin-primality-test) (64-bit) + Pollard–Rho for integer factorization
- Tonelli–Shanks modular square root ([odd primes](https://ourbigbook.com/codex/odd-prime))
- [Hensel lifting](https://ourbigbook.com/codex/hensel-lifting) to [prime powers](https://ourbigbook.com/codex/prime-power)
- [Chinese Remainder Theorem](https://ourbigbook.com/codex/chinese-remainder-theorem) to combine modular roots
- Reduced [binary quadratic form](https://ourbigbook.com/codex/binary-quadratic-form) enumeration to compute [class numbers](https://ourbigbook.com/codex/class-number)
- [Subset](https://ourbigbook.com/codex/subset) enumeration over [prime](https://ourbigbook.com/codex/prime) [divisors](https://ourbigbook.com/codex/divisor) for the Möbius-weighted [divisor sum](https://ourbigbook.com/codex/divisor-sum)

The included `main.py` asserts the sample values from the problem statement and prints the required answer.
