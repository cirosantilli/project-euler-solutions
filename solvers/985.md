# Project Euler 985 Solution - Telescoping Triangles

<https://projecteuler.net/problem=985>:

* [985.py](985.py)

This repository contains a simple pure-Python solution for the “Telescoping [Triangles](https://ourbigbook.com/codex/triangle)” problem.

We are given a starting [triangle](https://ourbigbook.com/codex/triangle) \(T_0\) with [integer](https://ourbigbook.com/codex/integer) side lengths. Under certain geometric conditions, we can inscribe a new [triangle](https://ourbigbook.com/codex/triangle) \(T_{k+1}\) inside \(T_k\). The construction is:

- Each vertex of \(T_{k+1}\) lies on a different side of \(T_k\).
- For each side of \(T_k\), the two sides of \(T_{k+1}\) that meet that side form equal [angles](https://ourbigbook.com/codex/angle) with it.

The question asks for the smallest possible perimeter of an integer-sided [triangle](https://ourbigbook.com/codex/triangle) \(T_0\) such that:

- \(T_{20}\) exists, but
- \(T_{21}\) does **not** exist.

The final numeric answer is printed by `main.py` when executed; it is **not** hard-coded anywhere.

## 1. Geometry and angle recurrence

The key observation is how the **[angles](https://ourbigbook.com/codex/angle)** of the [triangles](https://ourbigbook.com/codex/triangle) transform.

Let the [angles](https://ourbigbook.com/codex/angle) of [triangle](https://ourbigbook.com/codex/triangle) \(T_k\) be \((A_k, B_k, C_k)\) (in radians, summing to \(\pi\)). For the inscribed [triangle](https://ourbigbook.com/codex/triangle) \(T_{k+1}\) defined by the problem’s “equal [angle](https://ourbigbook.com/codex/angle)” condition, one can show that:

- Each **side** of \(T_k\) is an **external [angle bisector](https://ourbigbook.com/codex/angle-bisector)** of the corresponding vertex [angle](https://ourbigbook.com/codex/angle) of \(T_{k+1}\).

If the [angles](https://ourbigbook.com/codex/angle) of \(T_{k+1}\) are \((\alpha, \beta, \gamma)\), and the [angles](https://ourbigbook.com/codex/angle) of \(T_k\) are \((A, B, C)\), then standard angle-bisector [geometry](https://ourbigbook.com/codex/geometry) leads to the relations

\[
A = \frac{\pi}{2} - \frac{\gamma}{2},\quad
B = \frac{\pi}{2} - \frac{\alpha}{2},\quad
C = \frac{\pi}{2} - \frac{\beta}{2}.
\]

Solving these for \((\alpha, \beta, \gamma)\) in terms of \((A, B, C)\) yields the **forward [recurrence relation](https://ourbigbook.com/codex/recurrence-relation)**

\[
\alpha = \pi - 2B,\quad
\beta  = \pi - 2C,\quad
\gamma = \pi - 2A.
\]

Thus, if \(T_k\) has [angles](https://ourbigbook.com/codex/angle) \((A_k,B_k,C_k)\), then \(T_{k+1}\) has [angles](https://ourbigbook.com/codex/angle)

\[
(A_{k+1}, B_{k+1}, C_{k+1}) =
(\pi - 2B_k,\ \pi - 2C_k,\ \pi - 2A_k).
\]

This is exactly the formula implemented in `next_angles`.

### Existence condition

For a [triangle](https://ourbigbook.com/codex/triangle) to exist, all its [angles](https://ourbigbook.com/codex/angle) must be strictly between \(0\) and \(\pi\). From the [recurrence relation](https://ourbigbook.com/codex/recurrence-relation), we see that:

- \(T_{k+1}\) exists **iff** all three of \(A_{k+1},B_{k+1},C_{k+1}\) are positive.
- Using the formula above, this is equivalent to \(A_k,B_k,C_k < \frac{\pi}{2}\), i.e. \(T_k\) must be **acute**.

So the process stops when at least one [angle](https://ourbigbook.com/codex/angle) at some stage becomes non-acute and the next iteration would yield a non-positive [angle](https://ourbigbook.com/codex/angle).

\[
\cos A = \frac{b^2 + c^2 - a^2}{2bc},\quad
\cos B = \frac{a^2 + c^2 - b^2}{2ac},\quad
\cos C = \frac{a^2 + b^2 - c^2}{2ab}.
