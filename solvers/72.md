# Project Euler 72 Solution - Counting Fractions

<https://projecteuler.net/problem=72>:

* [72.py](72.py)
* [72.lean](72.lean)

A proper [reduced fraction](https://ourbigbook.com/codex/reduced-fraction) `n/d` (with `n < d` and `gcd(n, d) = 1`) is counted by its [denominator](https://ourbigbook.com/codex/denominator) `d`.

For a fixed [denominator](https://ourbigbook.com/codex/denominator) `d`, the number of [integers](https://ourbigbook.com/codex/integer) `n` with `1 <= n < d` and `gcd(n, d) = 1` is exactly **[Euler totient function](https://ourbigbook.com/codex/euler-totient-function)** `φ(d)`.

Therefore, the total number of proper [reduced fractions](https://ourbigbook.com/codex/reduced-fraction) with `d <= N` is:

\[
\sum_{d=2}^{N} \varphi(d)
\]

## Approach

1. Compute `φ(d)` for all `d <= 1,000,000` efficiently using a **[linear sieve](https://ourbigbook.com/codex/linear-sieve)** (O(N)).
2. [Sum](https://ourbigbook.com/codex/sum) `φ(d)` for `d = 2..N`.

This avoids generating or [sorting](https://ourbigbook.com/codex/sorting) any [fractions](https://ourbigbook.com/codex/fraction) and runs quickly within limits.
