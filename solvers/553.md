# Project Euler 553 Solution - Power Sets of Power Sets

<https://projecteuler.net/problem=553>:

* [553.py](553.py)

This solution computes:

- `C(10^4, 10) mod 1_000_000_007`

and includes assertions for all test values given in the problem statement.

## Key ideas used

### 1) Interpret `X ⊆ Q(n)` as a hypergraph
An element `X ∈ R(n)` is a **set of non-empty [subsets](https://ourbigbook.com/codex/subset)** of `{1..n}`.

Treat:

- [hypergraph vertices](https://ourbigbook.com/codex/vertex-of-a-hypergraph) = `{1..n}`
- [hyperedges](https://ourbigbook.com/codex/hyperedge) = the [subsets](https://ourbigbook.com/codex/subset) in `X`

Two [hyperedges](https://ourbigbook.com/codex/hyperedge) are adjacent in the [intersection graph](https://ourbigbook.com/codex/intersection-graph) iff they share a [hypergraph vertex](https://ourbigbook.com/codex/vertex-of-a-hypergraph).  
So [connected components](https://ourbigbook.com/codex/connected-component) of the [intersection graph](https://ourbigbook.com/codex/intersection-graph) are exactly the **[connected components](https://ourbigbook.com/codex/connected-component) of the [hypergraph](https://ourbigbook.com/codex/hypergraph) in the “edges share a [hypergraph vertex](https://ourbigbook.com/codex/vertex-of-a-hypergraph)” sense**.

### 2) Inclusion–exclusion for “no isolated vertices”
Let `G(n)` be the number of [hypergraphs](https://ourbigbook.com/codex/hypergraph) on `n` labeled [hypergraph vertices](https://ourbigbook.com/codex/vertex-of-a-hypergraph) where **every [hypergraph vertex](https://ourbigbook.com/codex/vertex-of-a-hypergraph) is used by at least one [hyperedge](https://ourbigbook.com/codex/hyperedge)**.

All [hyperedges](https://ourbigbook.com/codex/hyperedge) are chosen from the `2^n - 1` non-empty [subsets](https://ourbigbook.com/codex/subset), so the number of [hypergraphs](https://ourbigbook.com/codex/hypergraph) on `m` [hypergraph vertices](https://ourbigbook.com/codex/vertex-of-a-hypergraph) is `2^(2^m - 1)`.

Using inclusion–exclusion over [isolated vertices](https://ourbigbook.com/codex/isolated-vertex):

\[
G(n)=\sum_{t=0}^{n}(-1)^t \binom{n}{t} 2^{2^{n-t}-1}.
\]

This is computed efficiently as a [binomial transform](https://ourbigbook.com/codex/binomial-transform) in **[exponential generating function](https://ourbigbook.com/codex/exponential-generating-function)** (EGF) form.

### 3) Exponential formula (EGFs): connected vs. arbitrary
Let `F(n)` be the number of **connected** [hypergraphs](https://ourbigbook.com/codex/hypergraph) on `n` labeled [hypergraph vertices](https://ourbigbook.com/codex/vertex-of-a-hypergraph) with no [isolated vertices](https://ourbigbook.com/codex/isolated-vertex).

Then in [exponential generating function](https://ourbigbook.com/codex/exponential-generating-function) form:

- `H(x) = sum_{n≥0} G(n) x^n / n!`
- `A(x) = sum_{n≥1} F(n) x^n / n!`

The “set of [connected components](https://ourbigbook.com/codex/connected-component)” construction implies:

\[
H(x)=\exp(A(x)) \quad \Rightarrow \quad A(x)=\log(H(x)).
\]

So we get the connected-component building block by taking a **[formal power series logarithm](https://ourbigbook.com/codex/logarithm-of-a-formal-power-series)**.

### 4) Put back unused vertices and force exactly `k` components
[Hypergraph Vertices](https://ourbigbook.com/codex/vertex-of-a-hypergraph) not used by any [hyperedge](https://ourbigbook.com/codex/hyperedge) correspond to an independent factor `exp(x)` (each unused [hypergraph vertex](https://ourbigbook.com/codex/vertex-of-a-hypergraph) contributes one labeled atom).

Exactly `k` [connected components](https://ourbigbook.com/codex/connected-component) gives the [exponential generating function](https://ourbigbook.com/codex/exponential-generating-function):

\[
\exp(x)\cdot \frac{A(x)^k}{k!}.
\]

Therefore:

\[
C(n,k)=n!\,[x^n]\left(\exp(x)\cdot \frac{A(x)^k}{k!}\right).
\]

### 5) Fast polynomial arithmetic
The main cost is multiplying [power series](https://ourbigbook.com/codex/power-series) up to degree `10^4`.

- [Polynomial](https://ourbigbook.com/codex/polynomial) multiplications are done with **[NTT](https://ourbigbook.com/codex/number-theoretic-transform)** under three friendly [primes](https://ourbigbook.com/codex/prime) and then combined with **[CRT](https://ourbigbook.com/codex/chinese-remainder-theorem)** to get results [modulo](https://ourbigbook.com/codex/modulo-operation) `1_000_000_007`.
- The [formal power series logarithm](https://ourbigbook.com/codex/logarithm-of-a-formal-power-series) uses [Newton series inversion](https://ourbigbook.com/codex/newton-inversion-of-a-formal-power-series) plus multiplication.

This keeps the whole computation fast enough in pure Python.

```bash
python3 main.py
```
