# Project Euler 947 Solution - Fibonacci Residues

<https://projecteuler.net/problem=947>:

* [947.py](947.py)

This repository contains a standalone `main.py` that computes

\[ S(10^6) = \sum_{m=1}^{10^6} s(m) \pmod{999\,999\,893} \]

where

- `p(a,b,m)` is the period of the [recurrence relation](https://ourbigbook.com/codex/recurrence-relation)
  \(g(n)=g(n-1)+g(n-2)\; (\bmod\; m)\) with \(g(0)=a\), \(g(1)=b\),
- \(s(m)=\sum_{a=0}^{m-1}\sum_{b=0}^{m-1} p(a,b,m)^2\).

The code includes brute-force asserts for the small values given in the problem statement.

---

## Main techniques used

### 1) Linear algebra view of the recurrence
The state \((g(n), g(n+1))\) evolves by multiplying with the *[Fibonacci Q-matrix](https://ourbigbook.com/codex/fibonacci-matrix)*

\[
A = \begin{pmatrix}0 & 1\\ 1 & 1\end{pmatrix}\; (\bmod\; m).
\]

So the period `p(a,b,m)` is the cycle length of the [vector](https://ourbigbook.com/codex/vector) \((a,b)\) under the [permutation](https://ourbigbook.com/codex/permutation)
induced by repeated [multiplication](https://ourbigbook.com/codex/multiplication) by `A` [modulo](https://ourbigbook.com/codex/modulo-operation) `m`.

A crucial identity used for fast checks is

\[
A^n = \begin{pmatrix}F_{n-1} & F_n\\ F_n & F_{n+1}\end{pmatrix},
\]

which means `A^n = I (mod p)` iff \(F_n\equiv 0\) and \(F_{n+1}\equiv 1\) [modulo](https://ourbigbook.com/codex/modulo-operation) `p`.

### 2) Primitive-pair decomposition (gcd scaling)
If \(d\mid m\) divides both \(a\) and \(b\), then scaling out that factor reduces the modulus:

- write \(a=d a'\), \(b=d b'\), \(m=d m'\)
- the period [modulo](https://ourbigbook.com/codex/modulo-operation) `m` equals the period of \((a',b')\) [modulo](https://ourbigbook.com/codex/modulo-operation) `m'`.

This lets us rewrite the full sum in terms of *primitive pairs*
\(\gcd(a,b,m)=1\) and yields

\[
S(M)=\sum_{n\le M} P(n)\,\Big\lfloor \frac{M}{n}\Big\rfloor
\]

where `P(n)` is the sum of squared periods over primitive pairs [modulo](https://ourbigbook.com/codex/modulo-operation) `n`.

### 3) Chinese Remainder Theorem (CRT)
For \(n=\prod p_i^{e_i}\), the module \((\mathbb{Z}/n\mathbb{Z})^2\) splits into a product of
prime-power components.

- primitive-ness also splits (for each [prime](https://ourbigbook.com/codex/prime), not both coordinates are divisible by it)
- the period [modulo](https://ourbigbook.com/codex/modulo-operation) `n` is the **[lcm](https://ourbigbook.com/codex/least-common-multiple)** of the periods in each prime-power component

So `P(n)` can be computed by combining small per-prime-power distributions.

### 4) Prime-power period distributions are tiny
For each [prime power](https://ourbigbook.com/codex/prime-power) \(q=p^e\), primitive pairs take only **one or two** possible periods:

- most [primes](https://ourbigbook.com/codex/prime): all primitive pairs have full [Pisano period](https://ourbigbook.com/codex/pisano-period) \(\pi(p^e)\)
- for some [primes](https://ourbigbook.com/codex/prime) with \((5/p)=1\): an extra class has period \(\pi(p^e)/2\)
- for `p=5`: an extra class has period \(\pi(5^e)/5\)

Counts for the short-period class can be written in [closed form](https://ourbigbook.com/codex/closed-form), so for each `p^e` we only
need a distribution of size 1–2.

### 5) Fast Pisano periods for primes
For [primes](https://ourbigbook.com/codex/prime) \(p\ne 2,5\):

- if \((5/p)=1\), then \(\pi(p)\mid (p-1)\)
- otherwise \(\pi(p)\mid 2(p+1)\)

The code factors that candidate value (using a smallest-prime-factor [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve)) and reduces it
by checking [divisors](https://ourbigbook.com/codex/divisor) with fast-doubling Fibonacci computations.
