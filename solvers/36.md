# Project Euler 36 Solution - Double-base Palindromes

<https://projecteuler.net/problem=36>:

* [36.py](36.py)
* [36.lean](36.lean)

`solve(limit)` returns the [sum](https://ourbigbook.com/codex/sum) of all numbers below any nonnegative `limit` that are palindromic in both base 10 and base 2 (no leading zeros allowed). The Euler instance uses one million.

## Key ideas
- We **generate only [decimal palindromes](https://ourbigbook.com/codex/decimal-palindrome)** below the supplied limit by mirroring a positive prefix:
  - **Odd length**: `s + reverse(s[:-1])`
  - **Even length**: `s + reverse(s)`
  where `s = str(prefix)` and `prefix` starts at one and increases.
- Stop when the odd-length mirror reaches the limit. Odd-length mirrors strictly increase with their prefixes, and each even-length mirror is larger than the corresponding odd-length mirror, so no later prefix can contribute.
- A [binary palindrome](https://ourbigbook.com/codex/binary-palindrome) cannot be even (it would end in `0`, and reversing would create a leading zero), so we skip even candidates.
- For each generated [decimal palindrome](https://ourbigbook.com/codex/decimal-palindrome), check if its [binary representation](https://ourbigbook.com/codex/binary-representation) `bin(n)[2:]` is also a [palindrome](https://ourbigbook.com/codex/palindrome).

The [source equivalence proof](36.py.lean) establishes completeness, uniqueness, termination, and agreement with the exhaustive reference for every nonnegative limit. It uses structural proofs without evaluating either whole program.
