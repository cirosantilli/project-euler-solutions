Let

`P_j(x) = product_{m=0}^{j-1} (x - m^2)`.

Because `2N < p = 10^9 + 7`, the values `0^2, 1^2, ..., N^2` are distinct modulo `p`. Let `S_N` be the unique polynomial of degree at most `N` with `S_N(n^2) = n`. The required monic polynomial is therefore

`Q(x) = S_N(x) + P_{N+1}(x)`.

In the Newton basis `P_j`, the divided difference for the data `(n^2, n)` is

`c_j = (-1)^(j+1) / ((2j-1) j! (j-1)!)`.

Indeed,

`product_{0 <= m <= j, m != n} (n^2 - m^2) = (-1)^(j-n) (j-n)! (j+n)! / 2`,

and the resulting binomial sum gives the formula above.

Write

`E_r(n) = e_r(1/1^2, 1/2^2, ..., 1/n^2)`.

For `j >= 10`,

`[x^10] P_j = (-1)^(j-10) ((j-1)!)^2 E_9(j-1)`,

so

`[x^10] S_N = -sum_{j=10}^N E_9(j-1) / (j(2j-1))`.

Also, since `N = 10^7` is even,

`[x^10] P_{N+1} = -(N!)^2 E_9(N)`.

The remaining task is to evaluate those quantities without doing a modular inverse at every step. Define

`B_r(n) = (n!)^2 E_r(n)`.

From `E_r(n) = E_r(n-1) + E_{r-1}(n-1)/n^2` we get the inverse-free recurrence

`B_r(n) = n^2 B_r(n-1) + B_{r-1}(n-1)`.

For the sum, let `D_n = (2n-1)!!`, let

`T_n = sum_{j=10}^n E_9(j-1)/(j(2j-1))`,

and scale it as `A_n = (n!)^2 D_n T_n`. Then

`A_n = n^2 (2n-1) A_{n-1} + n D_{n-1} B_9(n-1)`.

Thus the solver keeps only `B_0, ..., B_9`, `D_n`, and `A_n` modulo `p`. At the end,

`T_N = A_N / (B_0(N) D_N)`,

which needs just one Fermat inverse. The algorithm is `O(N)` time and `O(1)` memory.
