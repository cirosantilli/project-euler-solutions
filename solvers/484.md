# Project Euler 484 Solution - Arithmetic Derivative

<https://projecteuler.net/problem=484>:

* [484.py](484.py)

We need

\[
S(N)=\sum_{1<k\le N} \gcd(k,k')
\]

where \(k'\) is the **[arithmetic derivative](https://ourbigbook.com/codex/arithmetic-derivative)** defined by

- \(p' = 1\) for [prime](https://ourbigbook.com/codex/prime) \(p\)
- \((ab)' = a'b + ab'\) ([Product rule](https://ourbigbook.com/codex/product-rule))

## Key ideas used

### 1) Work with \(g(n)=\gcd(n,n')\)

For a [prime power](https://ourbigbook.com/codex/prime-power) \(p^a\):

\[
(p^a)' = a\,p^{a-1}
\]

so

\[
g(p^a)=\gcd(p^a, a\,p^{a-1}) = p^{a-1}\gcd(p,a)
=
\begin{cases}
p^{a-1} & p\nmid a\\
p^{a}   & p\mid a
\end{cases}
\]

A crucial fact for this problem is that \(g(n)\) is **[multiplicative](https://ourbigbook.com/codex/multiplicative-function)**.

### 2) Turn the sum into a divisor-sum (Dirichlet convolution)

Define (on [prime powers](https://ourbigbook.com/codex/prime-power))

\[
f(p^a)=g(p^a)-g(p^{a-1})
\]

Then (by telescoping on each [prime power](https://ourbigbook.com/codex/prime-power) and [multiplicativity](https://ourbigbook.com/codex/multiplicativity))

\[
g(n)=\sum_{d\mid n} f(d)
\]

Therefore

\[
\sum_{n\le N} g(n)=\sum_{d\le N} f(d)\left\lfloor\frac{N}{d}\right\rfloor
\]

Finally, \(\gcd(1,1')=\gcd(1,0)=1\), so

\[
S(N)=\left(\sum_{n\le N} g(n)\right)-1
\]

### 3) Only *powerful* numbers contribute

Because \(g(p)=1\) and \(g(1)=1\), we have \(f(p)=0\).

Since \(f\) is [multiplicative](https://ourbigbook.com/codex/multiplicative-function), any number with a [prime exponent](https://ourbigbook.com/codex/prime-exponent) exactly 1 gets a zero factor.
So **only [powerful numbers](https://ourbigbook.com/codex/powerful-number)** (every [prime exponent](https://ourbigbook.com/codex/prime-exponent) is 0 or \(\ge 2\)) contribute to the sum.

That dramatically reduces the search space.

### 4) DFS over primes and exponents with pruning

We enumerate [powerful numbers](https://ourbigbook.com/codex/powerful-number) implicitly:

- Choose the next [prime](https://ourbigbook.com/codex/prime) \(p\)
- Walk over [exponents](https://ourbigbook.com/codex/exponent) \(a\ge 2\) while \(p^a\le\) current limit
- Add the contribution \(f(p^a)\cdot \left\lfloor N/(d\cdot p^a)\right\rfloor\)
- Recurse to larger [primes](https://ourbigbook.com/codex/prime) to build products of [prime powers](https://ourbigbook.com/codex/prime-power)

The implementation updates \(g(p^a)\) incrementally (and thus \(f(p^a)\)) without recomputing [exponents](https://ourbigbook.com/codex/exponent) from scratch.

### 5) Fast prime generation

We need [primes](https://ourbigbook.com/codex/prime) up to \(\lfloor\sqrt{N}\rfloor\) (because any [prime](https://ourbigbook.com/codex/prime) with [exponent](https://ourbigbook.com/codex/exponent) \(\ge 2\) must satisfy \(p^2\le N\)).

`main.py` uses an **odd-only [sieve of Eratosthenes](https://ourbigbook.com/codex/sieve-of-eratosthenes)** with slice assignment for speed.
