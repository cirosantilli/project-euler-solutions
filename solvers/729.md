# Project Euler 729 Solution - Range of Periodic Sequence

<https://projecteuler.net/problem=729>:

* [729.py](729.py)

The map is `f(x) = x - 1/x`.  Solving `y = f(x)` gives the two inverse
branches

\[
g_\pm(y)=\frac{y\pm\sqrt{y^2+4}}2.
\]

A period can therefore be described by choosing one of these two inverse
branches at each step and finding the [fixed point](https://ourbigbook.com/codex/fixed-point) of the composed [inverse map](https://ourbigbook.com/codex/inverse-map).

## Primitive Branch Words

Rotating a branch word only changes the chosen starting point on the same
cycle.  If the word is a repetition of a shorter word, the orbit has a smaller
true period.  The solver therefore generates only aperiodic binary [necklaces](https://ourbigbook.com/codex/necklace-combinatorics),
using the Fredricksen-Kessler-Maiorana [recursion](https://ourbigbook.com/codex/recursion).

For length `n` it also checks the generated count against

\[
\frac1n\sum_{d\mid n}\mu(d)2^{n/d},
\]

which is the number of primitive binary [necklaces](https://ourbigbook.com/codex/necklace-combinatorics).

## Fixed Point and Range

For one [necklace](https://ourbigbook.com/codex/necklace-combinatorics), the composed [inverse map](https://ourbigbook.com/codex/inverse-map) is a [contraction](https://ourbigbook.com/codex/contraction-mapping), so its [fixed point](https://ourbigbook.com/codex/fixed-point)
is unique.  The code starts [Newton root-finding iteration](https://ourbigbook.com/codex/newton-root-finding-iteration) at `0` for

\[
\Phi(x)=G(x)-x,
\]

where `G` is the branch composition.  While evaluating `G`, it also multiplies
the branch [derivatives](https://ourbigbook.com/codex/derivative) by the [chain rule](https://ourbigbook.com/codex/chain-rule), giving the [Newton root-finding iteration](https://ourbigbook.com/codex/newton-root-finding-iteration) [denominator](https://ourbigbook.com/codex/denominator)
`G'(x) - 1`.  The [square root](https://ourbigbook.com/codex/square-root) in the inverse branch is evaluated directly as
`sqrt(x*x + 4)`.  For these periods the orbit values stay modest, so the
general overflow handling in `hypot` is unnecessary in the hot loop.

Once the [fixed point](https://ourbigbook.com/codex/fixed-point) is known, the orbit is unfolded by applying the same
inverse branches.  The maximum minus the minimum is the range for that [necklace](https://ourbigbook.com/codex/necklace-combinatorics).
The problem counts every cyclic starting point separately, so a length-`n`
[necklace](https://ourbigbook.com/codex/necklace-combinatorics) contributes `n * range`.

The final floating-point sum is accumulated in chunks with `math.fsum`; the
answer is printed rounded to four decimal places.
