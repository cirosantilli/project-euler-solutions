= Python proof-domain audit

This audit covers the Python solver and reference interfaces for problems 1 through 67, their `Requires` annotations, default adapters, and the documented proof claims.

Prefer a meaningful argument shared by both implementations. A reference-only search limit changes an unbounded problem into a bounded one and is not an acceptable substitute. A mathematical bound derived from the inputs or the problem definition is acceptable. For a fixed problem without a useful parameter, retain `Equiv` and prefer structural proofs through shared mathematical models. A completed interpreter observation can establish termination; running out of observation fuel cannot.

Problem 26 has structural termination and equivalence proofs for every signed upper bound. Both searches consider only positive denominators, keep the least denominator on equal cycle lengths, and return zero exactly when the candidate range is empty.

Problem 38 has structural termination and equivalence proofs for every signed target width. The reference collector and optimized running maximum implement the same complete candidate set. Seed and product-count bounds follow from the requested width. Both functions return zero for widths below two or above nine; two positive products need at least two digits, and decimal notation cannot supply digit ten. The default call inherits termination from the general proof.

Problem 37 has structural source equivalence and support proofs for every numeral base at least two. Both searches terminate exactly when the right-truncatable-prime tree exhausts, returning the sum of all primes with at least two digits that remain prime under truncation from either end; otherwise both supported-diverge. The proof establishes complete, duplicate-free frontiers and agreement of arithmetic suffix checks with the reference's digit-list truncations. The decimal certificate proves global completeness and default-call termination without imposing a bound on the arbitrary-base theorem.

Problem 32 has structural source termination and equivalence proofs for every signed target width. The product interval and factor bounds follow from digit lengths. The optimized traversal and every reference permutation split collect the same products, and deduplication makes the sum independent of traversal order. The proofs cover copied slices and their temporary allocations. Widths below three and above nine are impossible and return zero; no supplied search limit or whole-program evaluation is used.

Problem 51 has structural equivalence and support proofs for every signed family threshold. Both unbounded source searches return exactly when a qualifying family exists, returning its least prime; otherwise both diverge. The checked eight-member witness establishes termination for every threshold at most eight and for the default call. Thresholds above ten are impossible because there are only ten replacement digits. For thresholds nine and ten, termination retains the general existence condition. The Lean statement uses zero for absence in its mathematical minimum and makes no universal existence assumption.

Problem 61 has structural source termination and equivalence proofs for every signed maximum polygonal type. Both implementations search types three through that argument and return the greatest cycle sum, or zero if absent. Polygonal growth justifies complete family generation without an index argument. Prefix-map construction, eager default allocation, duplicate rejection, decreasing remaining-type recursion, and maximum selection all preserve the common exhaustive model. Both omitted-argument default calls inherit termination from the general proof. No whole-program evaluation or fixed-instance search certificate is used.

Problem 63 has structural source termination and equivalence proofs for every numeral base at least two. The optimized seed traversal and the reference exponent traversal count the same complete set of positive powers. Digit-list conversion gives the reference width test, while power-growth inequalities bound every successful exponent and justify both early stops. Neither source takes an exponent limit. Both omitted-argument default calls inherit termination from the generalized proof.

Problem 64 has structural source termination and equivalence proofs for every signed upper bound. The period model is the least return time of the finite injective reduced-state orbit. The optimized terminal coefficient and reference dictionary's first repetition identify the same period. Tuple creation, dictionary promotion, saved first indices, lookup, and scalar counting all preserve this model. Squares return zero, and bounds below two return zero without evaluating negative square roots. No fixed iteration budget or whole-program computation is used.

Problem 65 has structural source termination and equivalence proofs for every positive convergent index. Both coefficient generation methods implement the same infinite pattern, and each finite numerator recurrence consumes exactly the requested number of coefficients. The proof tracks the reference's coefficient-list allocation and tuple swaps and connects string-character digit summation to the reference's positional digits. The default index 100 uses the universal termination theorem rather than a whole-program computation.

Problem 66 has structural source termination and equivalence proofs for every signed upper bound. Pell existence justifies the reference's search over positive y, whose first accepted value also minimizes x. Integer continuant invariants and state periodicity prove a norm-one convergent exists within two periods; a decreasing integer remainder sum places every positive Pell solution among the convergents and proves the first such convergent is the reference minimum. The source proof tracks both recurrences, tuple swaps, square skipping, and strict record updates. Empty discriminant ranges return zero, ties retain the least discriminant, and the omitted-argument default inherits termination from the universal theorem. No whole-program computation or supplied search cutoff is used.

Problem 67 has structural source termination and equivalence proofs for every finite triangle with signed integer weights, including the empty triangle. The checked shape predicate requires row i to have i + 1 entries. A prefix invariant proves that ascending in-place updates preserve both unread children; a private copy of the bottom row keeps the input heap unchanged. The active buffer prefix follows the shared bottom-up reference model for every row count. The reference re-exports problem 18's function, and the explicit Python contract resolves to that function's existing source proof. No fixed height or whole-program computation is used.

Other explicit bounds were checked for their role: the quadratic coefficient ranges in problem 27, the fifth power in problem 30, the four-digit progression in problem 49, the fifty reverse-and-add steps in problem 55, and the one-tenth spiral threshold in problem 58 come from their stated problem variants. Problems 32 and 38 accept a shared target width. Problem 60's bound is shared by both implementations and its theorem covers every signed bound; it is not a reference-only cutoff. Such shared parameters still deserve review when a more natural generalization is available.

Further useful shared parameters include coefficient ranges in problem 27, the digit-power exponent in problem 30, arbitrary target digit subsets in problems 32 and 38, the substring divisors in problem 43, and the diagonal-prime ratio in problem 58. Existing fixed-input proofs do not replace these prospective generalized results. Problems 34, 40, 45, and 46 have shared base, position, and threshold parameters.

The default root-partition certificate for problem 62 is numerical evidence toward a termination witness, not an execution cap. Its class batches were checked, but final assembly has not passed and is not a completed proof.
