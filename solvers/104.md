# Project Euler 104 Solution - Pandigital Fibonacci Ends

<https://projecteuler.net/problem=104>:

* [104.py](104.py)

We search for the first [Fibonacci number](https://ourbigbook.com/codex/fibonacci-number) index `k` such that:

- the **first 9 [digits](https://ourbigbook.com/codex/numerical-digit)** of `F_k` are a 1–9 pandigital set, and
- the **last 9 [digits](https://ourbigbook.com/codex/numerical-digit)** of `F_k` are also 1–9 pandigital.

## Key ideas

1. **Last 9 [digits](https://ourbigbook.com/codex/numerical-digit) via modular iteration**
   - We iterate [Fibonacci numbers](https://ourbigbook.com/codex/fibonacci-number) keeping only `F_n mod 10^9`.
   - This is fast and avoids huge [integers](https://ourbigbook.com/codex/integer) during the scan.

2. **First 9 [digits](https://ourbigbook.com/codex/numerical-digit) via [logarithms](https://ourbigbook.com/codex/logarithm)**
   - Using Binet/log approximation:
     \[
     \log_{10}(F_n) \approx n\log_{10}(\varphi) - \log_{10}(\sqrt{5})
     \]
   - If `x = log10(F_n)`, the [fractional part](https://ourbigbook.com/codex/fractional-part) `frac(x)` determines the leading [digits](https://ourbigbook.com/codex/numerical-digit):
     \[
     \text{first9} = \left\lfloor 10^{\text{frac}(x) + 8} \right\rfloor
     \]
   - To make this robust, the program uses Python `Decimal` with high precision to compute `ln`/`exp`.

3. **Pandigital test**
   - A [bitmask](https://ourbigbook.com/codex/bit-mask) checks that [digits](https://ourbigbook.com/codex/numerical-digit) are exactly `{1..9}` with no zeros and no repeats.

4. **Exact verification**
   - When both ends appear pandigital, we compute `F_n` exactly using [Fibonacci fast doubling](https://ourbigbook.com/codex/fibonacci-fast-doubling) (O(log n) [big integer](https://ourbigbook.com/codex/arbitrary-precision-integer) [multiplications](https://ourbigbook.com/codex/multiplication)) and verify first/last 9 [digits](https://ourbigbook.com/codex/numerical-digit) to ensure correctness.

## Included assertions

The program asserts the two facts given in the statement:
- `F_541` has pandigital last 9 [digits](https://ourbigbook.com/codex/numerical-digit).
- `F_2749` has pandigital first 9 [digits](https://ourbigbook.com/codex/numerical-digit).

Finally, it prints the computed `k`.
