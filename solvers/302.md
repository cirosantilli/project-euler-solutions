# Project Euler 302 Solution - Strong Achilles Numbers

<https://projecteuler.net/problem=302>:

* [302.py](302.py)

This repo contains a single-file Python solution (no third‑party libraries) that counts how many **[strong Achilles numbers](https://ourbigbook.com/codex/strong-achilles-number)** are below a given bound.

A number is:

- **[powerful](https://ourbigbook.com/codex/powerful-number)** if every [prime factor](https://ourbigbook.com/codex/prime-factor) appears with [exponent](https://ourbigbook.com/codex/exponent) at least 2,
- a **[perfect power](https://ourbigbook.com/codex/perfect-power)** if it can be written as `a^k` with `k > 1`,
- an **[Achilles number](https://ourbigbook.com/codex/achilles-number)** if it is [powerful](https://ourbigbook.com/codex/powerful-number) but **not** a [perfect power](https://ourbigbook.com/codex/perfect-power),
- **strong [Achilles](https://ourbigbook.com/codex/achilles-number)** if both `n` and `φ(n)` are [Achilles](https://ourbigbook.com/codex/achilles-number).

## Key ideas used

### 1) Work with prime exponents (gcd test)
For a number `n = ∏ p_i^{e_i}`:

- `n` is [powerful](https://ourbigbook.com/codex/powerful-number) ⇔ all `e_i ≥ 2`
- `n` is a [perfect power](https://ourbigbook.com/codex/perfect-power) ⇔ `gcd(e_i) > 1`

So to test “[Achilles](https://ourbigbook.com/codex/achilles-number)”, we only need:
- all [exponents](https://ourbigbook.com/codex/exponent) ≥ 2, and
- [gcd](https://ourbigbook.com/codex/greatest-common-divisor) of all [exponents](https://ourbigbook.com/codex/exponent) equals 1.

The same rule applies to `φ(n)` once we know its [prime factorization](https://ourbigbook.com/codex/prime-factorization).

### 2) Largest prime factor must be cubed (or higher)
If `p` is the largest [prime](https://ourbigbook.com/codex/prime) dividing `n` and `n` contains `p^2`, then `φ(n)` contains `p^1` coming from `p^(2-1)`, and no smaller [prime](https://ourbigbook.com/codex/prime) can contribute an extra `p` through its `(q-1)` factor (because `q-1 < p`).

Therefore, in any [strong Achilles number](https://ourbigbook.com/codex/strong-achilles-number) the **[largest prime factor](https://ourbigbook.com/codex/largest-prime-factor) must have [exponent](https://ourbigbook.com/codex/exponent) ≥ 3**. This limits the search to [primes](https://ourbigbook.com/codex/prime) `p` with `p^3 · 2^2` below the bound.

### 3) Incremental factorization of `φ(n)`
When we multiply `n` by `p^e`, the [totient](https://ourbigbook.com/codex/euler-totient-function) updates by:

`φ(p^e) = p^(e-1) · (p-1)`

So we maintain a dictionary `{prime → exponent}` for `φ(n)` and update it by:
- adding `e-1` to the [exponent](https://ourbigbook.com/codex/exponent) of `p`,
- adding the factorization of `p-1`.

To make this fast, we precompute a smallest‑[prime](https://ourbigbook.com/codex/prime)‑factor ([SPF](https://ourbigbook.com/codex/smallest-prime-factor)) table by [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) and use it to factorize every `p-1` quickly.

### 4) Pruning with “exponent 1” tracking
`φ(n)` must be [powerful](https://ourbigbook.com/codex/powerful-number), so **no [prime](https://ourbigbook.com/codex/prime) may end with [exponent](https://ourbigbook.com/codex/exponent) 1**.

During the [DFS](https://ourbigbook.com/codex/depth-first-search) we track a [set](https://ourbigbook.com/codex/set) `ones` of [primes](https://ourbigbook.com/codex/prime) that currently have [exponent](https://ourbigbook.com/codex/exponent) exactly 1 inside `φ(n)`. A crucial [monotonicity](https://ourbigbook.com/codex/monotonicity):

- once we go below a [prime](https://ourbigbook.com/codex/prime) `q`, no smaller [prime](https://ourbigbook.com/codex/prime) `r` can add a factor of `q` via `(r-1)` because `r-1 < q`.

So the search refuses to descend below `max(ones)` unless that [exponent](https://ourbigbook.com/codex/exponent) 1 has been eliminated.

### 5) DFS over decreasing primes
The search builds `n` by choosing [prime powers](https://ourbigbook.com/codex/prime-power) in [strictly decreasing](https://ourbigbook.com/codex/strictly-decreasing) [prime](https://ourbigbook.com/codex/prime) order. [Exponents](https://ourbigbook.com/codex/exponent) are chosen with a small but important rule:

- if `p` is already present in `φ(n)`, [exponent](https://ourbigbook.com/codex/exponent) 2 is allowed,
- otherwise [exponent](https://ourbigbook.com/codex/exponent) 2 would create a `p^1` factor in `φ(n)`, which can’t be repaired later — so new [primes](https://ourbigbook.com/codex/prime) start at [exponent](https://ourbigbook.com/codex/exponent) 3.

This keeps the tree compact while remaining complete.

## Running

```bash
python3 main.py
```

The script includes assertions for the two sample counts from the statement and then prints the answer for the `10^18` bound.
