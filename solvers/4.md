# Largest Palindrome Product (3-digit factors)

We need the largest [palindromic number](https://ourbigbook.com/codex/palindromic-number) that can be written as a [product](https://ourbigbook.com/codex/product) of two 3-digit [integers](https://ourbigbook.com/codex/integer) (100–999).

## Key ideas
- A number is a [palindrome](https://ourbigbook.com/codex/palindrome) if its [decimal representation](https://ourbigbook.com/codex/decimal-representation) equals its reverse.
- Search [factor pairs](https://ourbigbook.com/codex/factor-pair) in descending order so we find large [products](https://ourbigbook.com/codex/product) first.
- **[Pruning](https://ourbigbook.com/codex/search-pruning)**:
  - For a fixed `a`, if `a * 999` is already below the best [palindrome](https://ourbigbook.com/codex/palindrome) found, no smaller `a` can improve it.
  - For a fixed `a`, as `b` decreases the [product](https://ourbigbook.com/codex/product) decreases; once `a*b <= best`, we stop that inner loop.
- When scanning `b` downward, the first [palindrome](https://ourbigbook.com/codex/palindrome) found for that `a` is the largest for that `a`, so we can break early.

This reduces unnecessary checks and runs quickly in Python/PyPy.
