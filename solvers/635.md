# Project Euler 635 Solution - Subset Sums

<https://projecteuler.net/problem=635>:

* [635.py](635.py)

This repo contains a pure-Python solution (no external libraries) for Project Euler **635**.

## Key ideas

### 1) Reduce the subset condition to residues mod `p`
For `n = p` [prime](https://ourbigbook.com/codex/prime), the set `{1,2,…,q p}` contains each [residue class](https://ourbigbook.com/codex/residue-class) `1..p` **exactly `q` times**.

Because we only care about the [subset sum](https://ourbigbook.com/codex/subset-sum) **mod `p`**, each chosen number contributes just its [residue class](https://ourbigbook.com/codex/residue-class) (multiples of `p` vanish mod `p`). So the problem becomes:

> Choose `p` elements from a [multiset](https://ourbigbook.com/codex/multiset) that has `q` copies of each [residue class](https://ourbigbook.com/codex/residue-class) `1..p`, and count those whose residue-sum is `0 (mod p)`.

### 2) Roots-of-unity filter (character sum)
Use a [generating function](https://ourbigbook.com/codex/generating-function) for choosing items, tracking:
- [subset](https://ourbigbook.com/codex/subset) size by `x`
- residue-sum by `y`

For a fixed [residue class](https://ourbigbook.com/codex/residue-class) `r`, selecting `j` of its `q` copies contributes `C(q,j) x^j y^{jr}`, so the per-residue factor is `(1 + x y^r)^q`.

Then
\[
A_q(p)= [x^p]\frac{1}{p}\sum_{t=0}^{p-1}\prod_{r=1}^p(1+x\omega^{tr})^q,
\]
where \(\omega\) is a primitive `p`-th [root of unity](https://ourbigbook.com/codex/root-of-unity).

For **odd** [prime](https://ourbigbook.com/codex/prime) `p`:
- `t = 0` gives \(\prod_{r=1}^p(1+x)^q=(1+x)^{qp}\), so the coefficient is `C(qp,p)`.
- `t ≠ 0` permutes all `p`-th [roots of unity](https://ourbigbook.com/codex/roots-of-unity), and
  \(\prod_{r=1}^p(1+x\omega^{tr}) = 1 + x^p\),
  so the `x^p` coefficient of `(1+x^p)^q` is just `q`.

Therefore, for [odd primes](https://ourbigbook.com/codex/odd-prime):
\[
A_q(p)=\frac{1}{p}\left(\binom{qp}{p} + q(p-1)\right).
\]

The [prime](https://ourbigbook.com/codex/prime) `p=2` is a small exception handled directly.

### 3) Fast computation of \(\binom{2p}{p}\) and \(\binom{3p}{p}\) for all odd `p ≤ L`
Let
- `C(n) = C(2n, n)`,
- `D(n) = C(3n, n)`.

These are **hypergeometric [sequences](https://ourbigbook.com/codex/sequence)**, so they satisfy simple multiplicative [recurrence relations](https://ourbigbook.com/codex/recurrence-relation). We only need values at odd `n` (since [primes](https://ourbigbook.com/codex/prime) > 2 are odd), and we advance by `2` each step.

After algebraic simplification (and cancelling factors of `2`), the update for odd `n` can be done using a small fixed number of modular multiplications and [modular inverses](https://ourbigbook.com/codex/modular-inverse).

### 4) Batch modular inverses (no per-step `pow`)
We need many inverses [modulo](https://ourbigbook.com/codex/modulo-operation) `MOD = 1_000_000_009` ([prime](https://ourbigbook.com/codex/prime)). Computing `pow(x, MOD-2, MOD)` for each `x` would be far too slow.

Instead we use **[batch inversion](https://ourbigbook.com/codex/batch-modular-inversion)** on blocks:
- Compute prefix products in a block,
- invert the total once with `pow(...)`,
- sweep backwards to recover each individual inverse.

We precompute:
- inverses of all [integers](https://ourbigbook.com/codex/integer) `1..(L+1)/2` (used for `((n+1)/2)^{-1}`), and
- inverses of all [odd numbers](https://ourbigbook.com/codex/odd-number) up to `2L+3` (used for `n^{-1}`, `(n+2)^{-1}`, `(2n+1)^{-1}`, `(2n+3)^{-1}`).

### 5) Prime sieve (odd-only)
A memory-efficient [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) stores only [odd numbers](https://ourbigbook.com/codex/odd-number):
- index `i` corresponds to number `2*i+1`.

This allows fast [prime](https://ourbigbook.com/codex/prime) checks while iterating odd `n`.

## What the program outputs
Running `main.py` prints:
\[
(S_2(10^8) + S_3(10^8)) \bmod 1{,}000{,}000{,}009.
\]

The script also includes `assert`s for all test values stated in the problem statement.
