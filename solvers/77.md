# Project Euler 77 Solution - Prime Summations

<https://projecteuler.net/problem=77>:

* [77.py](77.py)
* [77.lean](77.lean)

We want the smallest `n` that can be written as a [sum](https://ourbigbook.com/codex/sum) of [primes](https://ourbigbook.com/codex/prime-number) in **more than 5000** different ways, where order does **not** matter (so `3+7` is the same as `7+3`).

## Key idea: Coin-change / partition DP
Treat [primes](https://ourbigbook.com/codex/prime-number) as coin denominations, with unlimited usage.  
Let `ways[s]` be the number of ways to form [sum](https://ourbigbook.com/codex/sum) `s`.

Initialize:
- `ways[0] = 1` (one way to make zero: choose nothing)

For each [prime](https://ourbigbook.com/codex/prime-number) `p`, update:
- for `s = p..n`: `ways[s] += ways[s - p]`

Iterating [primes](https://ourbigbook.com/codex/prime-number) in increasing order ensures we count **unordered** [sums](https://ourbigbook.com/codex/sum) ([integer partitions](https://ourbigbook.com/codex/integer-partition)), just like the classic [coin-change counting](https://ourbigbook.com/codex/coin-change-counting) method.

## Algorithm
For `n = 2, 3, 4, ...`:
1. Generate all [primes](https://ourbigbook.com/codex/prime-number) `<= n` ([number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve)).
2. Run the [DP](https://ourbigbook.com/codex/dynamic-programming) to compute `ways[n]`.
3. Stop at the first `n` with `ways[n] > 5000`.

This is fast because the answer is small (`71`), and the [DP](https://ourbigbook.com/codex/dynamic-programming) is only `O(n * #primes<=n)`.

## Result
The first value with more than 5000 prime-sum partitions is **71**.
