# Project Euler 30 Solution - Digit Fifth Powers

<https://projecteuler.net/problem=30>:

* [30.py](30.py)
* [30.lean](30.lean)

We want all [integers](https://ourbigbook.com/codex/integer) that equal the [sum](https://ourbigbook.com/codex/sum) of the **[fifth powers](https://ourbigbook.com/codex/fifth-power)** of their [decimal digits](https://ourbigbook.com/codex/decimal-digit), excluding `1` (since it is not considered a “[sum](https://ourbigbook.com/codex/sum)” in the problem statement).

## Key insight: finite search bound
For a `k`-[digit](https://ourbigbook.com/codex/numerical-digit) number, the largest possible [sum](https://ourbigbook.com/codex/sum) of [fifth powers](https://ourbigbook.com/codex/fifth-power) of its [digits](https://ourbigbook.com/codex/numerical-digit) occurs when all [digits](https://ourbigbook.com/codex/numerical-digit) are `9`:
- max [sum](https://ourbigbook.com/codex/sum) = `k * 9^5`

But any `k`-[digit](https://ourbigbook.com/codex/numerical-digit) number is at least `10^(k-1)`.  
If `k * 9^5 < 10^(k-1)`, then no `k`-[digit](https://ourbigbook.com/codex/numerical-digit) number can equal its digit-fifth-power [sum](https://ourbigbook.com/codex/sum).

Check:
- `6 * 9^5 = 6 * 59049 = 354294` (still a 6-digit range is possible)
- `7 * 9^5 = 413343 < 1,000,000 = 10^6` ⇒ impossible for 7 [digits](https://ourbigbook.com/codex/numerical-digit) or more

So we only need to test `n` from `2` up to `354294`.

## Approach
1. Precompute `d^5` for [digits](https://ourbigbook.com/codex/numerical-digit) `0..9`.
2. For each `n` in `[2, 354294]`, compute the [sum](https://ourbigbook.com/codex/sum) of [digit](https://ourbigbook.com/codex/numerical-digit) [fifth powers](https://ourbigbook.com/codex/fifth-power) and compare to `n`.
3. [Sum](https://ourbigbook.com/codex/sum) all matching numbers.

This runs quickly because the search space is only ~354k numbers.
