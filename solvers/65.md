# Project Euler 65 Solution - Convergents of $e$

<https://projecteuler.net/problem=65>:

* [65.py](65.py)
* [65.lean](65.lean)

The [continued fraction](https://ourbigbook.com/codex/continued-fraction) for [Euler's number](https://ourbigbook.com/codex/euler-s-number) is:

e = [2; 1, 2, 1, 1, 4, 1, 1, 6, 1, ..., 1, 2k, 1, ...]

So after the initial `2`, the coefficients repeat every 3 terms as:
`1, 2k, 1` for k = 1, 2, 3, ...

## Key idea: Convergent recurrence
For [continued fraction coefficients](https://ourbigbook.com/codex/partial-quotient-of-a-continued-fraction) `a0..a_{n-1}`, the [convergent](https://ourbigbook.com/codex/continued-fraction-convergent) [numerator](https://ourbigbook.com/codex/numerator)/[denominator](https://ourbigbook.com/codex/denominator) `(p, q)` can be computed iteratively:

- Initialize: `p[-2]=0, p[-1]=1`, `q[-2]=1, q[-1]=0`
- For each coefficient `a`:
  - `p = a*p_prev + p_prevprev`
  - `q = a*q_prev + q_prevprev`

This runs in O(n) time and uses Python [big integers](https://ourbigbook.com/codex/arbitrary-precision-integer).

## Result
Compute the 100th [convergent](https://ourbigbook.com/codex/continued-fraction-convergent), take the [numerator](https://ourbigbook.com/codex/numerator), and [sum](https://ourbigbook.com/codex/sum) its [decimal digits](https://ourbigbook.com/codex/decimal-digit).
The program prints the required [digit sum](https://ourbigbook.com/codex/digit-sum).
