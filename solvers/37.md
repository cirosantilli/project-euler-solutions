# Project Euler 37 Solution - Truncatable Primes

<https://projecteuler.net/problem=37>:

* [37.py](37.py)
* [37.lean](37.lean)

## Key idea
A [prime](https://ourbigbook.com/codex/prime-number) is *truncatable* if repeatedly removing [digits](https://ourbigbook.com/codex/numerical-digit) from:
- left to right **and**
- right to left

always produces [primes](https://ourbigbook.com/codex/prime-number) at every intermediate step. Single-digit [primes](https://ourbigbook.com/codex/prime-number) (2, 3, 5, 7) are excluded.

## Approach
1. Use a [sieve of Eratosthenes](https://ourbigbook.com/codex/sieve-of-eratosthenes) up to `1_000_000` to get O(1) [primality](https://ourbigbook.com/codex/primality) checks.
   - This bound is sufficient because the largest [truncatable prime](https://ourbigbook.com/codex/truncatable-prime) is below one million.
2. Iterate through [odd numbers](https://ourbigbook.com/codex/odd-number) ≥ 11:
   - If the number is [prime](https://ourbigbook.com/codex/prime-number), test truncatability by converting it to a [string](https://ourbigbook.com/codex/string) and checking all left and right truncations via the [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve).
3. Collect exactly 11 such [primes](https://ourbigbook.com/codex/prime-number) and [sum](https://ourbigbook.com/codex/sum) them.

## Complexity
- [Number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve): `O(N log log N)` with `N = 1,000,000`
- Checking truncations: at most ~6 truncations per candidate in this range
- Runs in well under a second on typical machines (PyPy3).

The program prints the final [sum](https://ourbigbook.com/codex/sum).
