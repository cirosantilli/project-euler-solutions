= Python proof-domain audit

This audit covers the Python solver and reference interfaces for problems 1 through 83, their `Requires` annotations, default adapters, and the documented proof claims.

Prefer a meaningful argument shared by both implementations. A reference-only search limit changes an unbounded problem into a bounded one and is not an acceptable substitute. A mathematical bound derived from the inputs or the problem definition is acceptable. For a fixed problem without a useful parameter, retain `Equiv` and prefer structural proofs through shared mathematical models. A completed interpreter observation can establish termination; running out of observation fuel cannot.
