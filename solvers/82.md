# Project Euler 82 Solution - Path Sum: Three Ways

<https://projecteuler.net/problem=82>:

* [82.py](82.py)
* [Python equivalence proof](82.py.lean)
* [82.lean](82.lean)

We need the minimal cost [graph path](https://ourbigbook.com/codex/graph-path) that starts anywhere in the left column and ends anywhere in the right column, moving only **right**, **up**, and **down**.

### Key idea (dynamic programming by columns)
Process the [matrix](https://ourbigbook.com/codex/matrix) column-by-column while maintaining:

- `dp[i]`: minimal cost to reach row `i` in the current column.

For each new column `j`:

1. **Move right into column `j`**:
   - `temp[i] = dp[i] + mat[i][j]`

2. **Allow vertical moves within column `j`**:
   Once inside the column, we can move up/down any number of times.
   A vertical reversal revisits a cell. With nonnegative costs, removing that cycle cannot increase the sum, so an optimal path can be chosen to move in only one vertical direction in each column. Two linear relaxations cover either direction:
   - Top-down pass to account for [graph paths](https://ourbigbook.com/codex/graph-path) that move down.
   - Bottom-up pass to account for [graph paths](https://ourbigbook.com/codex/graph-path) that move up.

After processing all columns, the answer is `min(dp)` in the last column.

### Complexity
- Time: `O(rows * columns)`
- Memory: `O(rows)`

Includes an assertion for the given 5×5 example (`994`).

The shared input is a rectangular `list[list[int]]` with nonnegative entries. Empty matrices and matrices with no columns return zero. The solvers preserve input rows, including shared row objects.

The Python equivalence proof covers the complete calls on this domain: input validation, column construction, both vertical sweeps, outer traversal, and the final minimum. It retains the reference’s list comprehensions, slices, reversals, and `zip` allocations while proving that both implementations preserve caller objects and return the same integer. The Python and Lean equivalence proofs are structural and use only standard Lean axioms, without whole-program computation.
