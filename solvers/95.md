# Project Euler 95 Solution - Amicable Chains

<https://projecteuler.net/problem=95>:

* [95.py](95.py)
* [95.lean](95.lean)

We model the problem as a [directed graph](https://ourbigbook.com/codex/directed-graph) on numbers `1..N` where each [graph vertex](https://ourbigbook.com/codex/graph-vertex) `n`
points to `s(n)`, the [sum of proper divisors](https://ourbigbook.com/codex/proper-divisor-sum) of `n`. An “amicable chain” is
exactly a [directed cycle](https://ourbigbook.com/codex/directed-cycle) in this [graph](https://ourbigbook.com/codex/graph), with the extra constraint that every
value in the [directed cycle](https://ourbigbook.com/codex/directed-cycle) is `<= 1,000,000`.

## Key ideas

1. **[Number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) to compute `s(n)` for all `n <= N`**
   - Initialize an [array](https://ourbigbook.com/codex/array) `s` of size `N+1` with zeros.
   - For each [divisor](https://ourbigbook.com/codex/divisor) `i` from `1` to `N/2`, add `i` to all [multiples](https://ourbigbook.com/codex/integer-multiple) `2i, 3i, ...`.
   - This computes [sum of proper divisors](https://ourbigbook.com/codex/proper-divisor-sum) in about `O(N log N)` time.

2. **[Directed cycle detection](https://ourbigbook.com/codex/directed-cycle-detection) with linear total work**
   - For each start value not globally processed, follow the chain `n -> s(n)`.
   - Track the current [graph path](https://ourbigbook.com/codex/graph-path) and the first index where each [graph vertex](https://ourbigbook.com/codex/graph-vertex) was seen in this walk.
   - If we revisit a [graph vertex](https://ourbigbook.com/codex/graph-vertex) in the current [graph path](https://ourbigbook.com/codex/graph-path), we found a [directed cycle](https://ourbigbook.com/codex/directed-cycle); its members are a valid amicable chain.
   - If we hit `0`, go above `N`, or reach a globally processed [graph vertex](https://ourbigbook.com/codex/graph-vertex), there is no new [directed cycle](https://ourbigbook.com/codex/directed-cycle) from this start.
   - Mark all [graph vertices](https://ourbigbook.com/codex/graph-vertex) in the traversed [graph path](https://ourbigbook.com/codex/graph-path) as processed so each number is explored at most once overall.

3. **Selecting the answer**
   - Keep the maximum [directed cycle](https://ourbigbook.com/codex/directed-cycle) length found.
   - For ties, choose the chain with the smallest [minimal element](https://ourbigbook.com/codex/minimal-element).
   - Output the smallest member of the longest chain.

The program includes assertions for the examples in the statement ([perfect number](https://ourbigbook.com/codex/perfect-number) 28,
[amicable pair](https://ourbigbook.com/codex/amicable-pair) 220/284, and the 5-cycle starting at 12496), and prints the final result.
