= Python proof-domain audit

This audit covers the Python solver and reference interfaces for problems 1 through 62, their `Requires` annotations, default adapters, and the documented proof claims.

Prefer a meaningful argument shared by both implementations. A reference-only search limit changes an unbounded problem into a bounded one and is not an acceptable substitute. A mathematical bound derived from the inputs or the problem definition is acceptable. For a fixed problem without a useful parameter, retain `Equiv` and prefer structural proofs through shared mathematical models. A completed interpreter observation can establish termination; running out of observation fuel cannot.

== Reference interfaces corrected

[cols="1,3,3"]
|===
| Problem | Former reference restriction | Current reference
| 32 | Supplied factor limits 99 and 9999 | Split every permutation of the actual nine digits into factors and product.
| 34 | Supplied inclusive limit 2540160 | Derive the maximum possible digit count using `d * 9!` and `10**(d-1)`.
| 37 | Scan below a million | Exhaust the right-truncatable-prime tree until its frontier is empty.
| 38 | Supplied base limit 9999 | Derive the maximum base width from fitting at least two products into nine digits.
| 40 | Supplied decimal-stream construction limit | Accept the same requested digit positions as the optimized solver and extend the stream until they exist.
| 45 | Scan 100001 triangular indices | Accept the same `after` threshold as the optimized solver and merge the three increasing polygonal sequences without a cutoff.
| 46 | Scan below 10000 | Search until the first counterexample, without a cutoff.
| 61 | Supplied polygonal index limit 140 | Enumerate each family until its values reach the problem's four-digit boundary.
| 62 | Supplied cube-root limit | Accept only the requested class size and expand complete digit widths until successful. Internal finite counting windows come from those widths.
|===

Source proofs still awaiting replacement are retained as `.py.lean.attempt`; their README proof links are removed, and they are not counted as current proofs. Problem 40 has a structural equivalence and termination proof for every finite tuple of positive positions, with no maximum position. Unchanged zero-argument `Equiv` proofs remain in place; they need not be discarded merely because they have no arguments.

Other explicit bounds were checked for their role: the quadratic coefficient ranges in problem 27, the fifth power in problem 30, the target decimal digits in problems 32 and 38, the four-digit progression in problem 49, the fifty reverse-and-add steps in problem 55, and the one-tenth spiral threshold in problem 58 come from their stated problem variants. Problem 60's bound is shared by both implementations and its theorem covers every signed bound; it is not a reference-only cutoff. Such shared parameters still deserve review when a more natural generalization is available.

Further useful shared parameters include coefficient ranges in problem 27, the digit-power exponent in problem 30, the numeral base in problem 34, the target digit set in problems 32 and 38, the substring divisors in problem 43, and the diagonal-prime ratio in problem 58. Existing fixed-input proofs do not replace these prospective generalized results. Problems 40 and 45 already have shared position and threshold parameters after this cleanup.

The default root-partition certificate for problem 62 is numerical evidence toward a termination witness, not an execution cap. Its class batches were checked, but final assembly has not passed and is not a completed proof.
