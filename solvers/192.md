# Project Euler 192 Solution - Best Approximations

<https://projecteuler.net/problem=192>:

* [192.py](192.py)

## Problem Summary

For every non-square [integer](https://ourbigbook.com/codex/integer) $2 \le n \le 100000$, the task is to find the [reduced fraction](https://ourbigbook.com/codex/reduced-fraction) $\frac{p}{q}$ with $1 \le q \le 10^{12}$ that minimizes the error $\left| \sqrt{n} - \frac{p}{q} \right|$, and then sum all winning [denominators](https://ourbigbook.com/codex/denominator) $q$.

Because $\sqrt{n}$ is irrational whenever $n$ is not a square, there is no tie: exactly one [reduced fraction](https://ourbigbook.com/codex/reduced-fraction) is closest for each such $n$. The difficulty is the [denominator](https://ourbigbook.com/codex/denominator) limit $10^{12}$. A direct search over all [denominators](https://ourbigbook.com/codex/denominator) is impossible, so the solution uses the [continued fraction](https://ourbigbook.com/codex/continued-fraction) of $\sqrt{n}$ and turns the choice into an exact [integer](https://ourbigbook.com/codex/integer) comparison between two final candidates.

## Mathematical Approach

The whole argument rests on one classical fact: once a [denominator](https://ourbigbook.com/codex/denominator) bound is imposed, the [best rational approximation](https://ourbigbook.com/codex/best-rational-approximation) to an [irrational number](https://ourbigbook.com/codex/irrational-number) must come from the [continued fraction](https://ourbigbook.com/codex/continued-fraction) ladder, namely from a [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) or from an [intermediate fraction](https://ourbigbook.com/codex/semiconvergent) between two consecutive [continued fraction convergents](https://ourbigbook.com/codex/continued-fraction-convergent). For $\sqrt{n}$, the code never leaves exact [integer arithmetic](https://ourbigbook.com/codex/integer-arithmetic) while it walks that ladder.

### Continued fractions of $\sqrt{n}$

Let $a_0 = \lfloor \sqrt{n} \rfloor$. For a non-square $n$, the [continued fraction](https://ourbigbook.com/codex/continued-fraction) of $\sqrt{n}$ is periodic after the first term, and the standard quadratic-irrational state can be written as

$$x_k = \frac{\sqrt{n} + m_k}{d_k}, \qquad a_k = \lfloor x_k \rfloor.$$

The next state is obtained entirely with [integers](https://ourbigbook.com/codex/integer):

$$m_{k+1} = d_k a_k - m_k,$$

$$d_{k+1} = \frac{n - m_{k+1}^2}{d_k},$$

$$a_{k+1} = \left\lfloor \frac{a_0 + m_{k+1}}{d_{k+1}} \right\rfloor.$$

This [recurrence relation](https://ourbigbook.com/codex/recurrence-relation) is exactly what the implementations maintain. It generates the partial quotients of $\sqrt{n}$ without ever approximating $\sqrt{n}$ numerically.

### Convergents and the only fractions that matter

If

$$\sqrt{n} = [a_0; a_1, a_2, a_3, \dots],$$

then the [continued fraction convergents](https://ourbigbook.com/codex/continued-fraction-convergent) satisfy

$$p_k = a_k p_{k-1} + p_{k-2}, \qquad q_k = a_k q_{k-1} + q_{k-2},$$

with initial values $p_{-2}=0$, $p_{-1}=1$, $q_{-2}=1$, $q_{-1}=0$. These [continued fraction convergents](https://ourbigbook.com/codex/continued-fraction-convergent) are the principal [best rational approximations](https://ourbigbook.com/codex/best-rational-approximation).

Between two consecutive [continued fraction convergents](https://ourbigbook.com/codex/continued-fraction-convergent) there are also [semiconvergents](https://ourbigbook.com/codex/semiconvergent), sometimes called [intermediate fractions](https://ourbigbook.com/codex/semiconvergent):

$$\frac{p_t}{q_t} = \frac{t p_{k-1} + p_{k-2}}{t q_{k-1} + q_{k-2}}, \qquad 1 \le t < a_k.$$

When a [denominator](https://ourbigbook.com/codex/denominator) cap $D$ is present, the optimum fraction under $q \le D$ must be either the last [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) whose [denominator](https://ourbigbook.com/codex/denominator) still fits, or one of these [semiconvergents](https://ourbigbook.com/codex/semiconvergent) for the next [continued fraction](https://ourbigbook.com/codex/continued-fraction) [digit](https://ourbigbook.com/codex/numerical-digit). Nothing else can beat them.

### Stopping at the first denominator that exceeds the bound

Let $k$ be the first index for which $q_k > D$. Then $q_{k-1} \le D$, so the previous [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) is admissible, while the next full [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) is already too large.

Every admissible [semiconvergent](https://ourbigbook.com/codex/semiconvergent) on that last edge has [denominator](https://ourbigbook.com/codex/denominator)

$$q_t = t q_{k-1} + q_{k-2}.$$

The largest allowed choice is therefore

$$t = \left\lfloor \frac{D - q_{k-2}}{q_{k-1}} \right\rfloor,$$

which gives the boundary [semiconvergent](https://ourbigbook.com/codex/semiconvergent) $q_t \le D < q_{t+1}$. Because $q_k = a_k q_{k-1} + q_{k-2} > D$, this $t$ automatically satisfies $0 \le t < a_k$.

Among [semiconvergents](https://ourbigbook.com/codex/semiconvergent) on the same edge, larger $t$ means a larger [denominator](https://ourbigbook.com/codex/denominator) and also a smaller error. In other words, once the bound has cut the edge, only the boundary [semiconvergent](https://ourbigbook.com/codex/semiconvergent) needs to be compared with the last admissible [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent).

### An exact comparison with no floating point

The key identity is

$$\sqrt{n} = \frac{p_{k-2} + x_k p_{k-1}}{q_{k-2} + x_k q_{k-1}}, \qquad x_k = \frac{\sqrt{n} + m_k}{d_k}.$$

From this one obtains the exact errors

$$\left| \sqrt{n} - \frac{p_{k-1}}{q_{k-1}} \right| = \frac{1}{q_{k-1}(x_k q_{k-1} + q_{k-2})},$$

and for the [semiconvergent](https://ourbigbook.com/codex/semiconvergent) with parameter $t$,

$$\left| \sqrt{n} - \frac{p_t}{q_t} \right| = \frac{x_k - t}{(t q_{k-1} + q_{k-2})(x_k q_{k-1} + q_{k-2})}.$$

So the [semiconvergent](https://ourbigbook.com/codex/semiconvergent) is better exactly when

$$q_{k-1} x_k < 2 t q_{k-1} + q_{k-2}.$$

Substituting $x_k = \frac{\sqrt{n} + m_k}{d_k}$ turns that into

$$q_{k-1} \sqrt{n} < R,$$

where

$$R = d_k (2 t q_{k-1} + q_{k-2}) - q_{k-1} m_k.$$

This is the [integer](https://ourbigbook.com/codex/integer) test used by the implementations. If $R \le 0$, the [semiconvergent](https://ourbigbook.com/codex/semiconvergent) cannot win. If $R > q_{k-1}(a_0+1)$, then it definitely wins because $\sqrt{n} < a_0 + 1$. Otherwise both sides are positive, so the comparison becomes the exact [perfect square test](https://ourbigbook.com/codex/perfect-square-test)

$$R^2 > n q_{k-1}^2.$$

No floating-point approximation is needed at any stage.

### Worked example: $\sqrt{13}$

The [continued fraction](https://ourbigbook.com/codex/continued-fraction) is

$$\sqrt{13} = [3; 1,1,1,1,6,\dots].$$

The [continued fraction convergents](https://ourbigbook.com/codex/continued-fraction-convergent) begin

$$\frac{3}{1}, \frac{4}{1}, \frac{7}{2}, \frac{11}{3}, \frac{18}{5}, \frac{119}{33}, \dots$$

Suppose first that $D=20$. The last admissible [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) is $\frac{18}{5}$, because the next [denominator](https://ourbigbook.com/codex/denominator) $33$ is too large. At this cutoff stage the quadratic-irrational state is $m_k=3$, $d_k=1$, and $q_{k-1}=5$, $q_{k-2}=3$. The boundary parameter is

$$t = \left\lfloor \frac{20-3}{5} \right\rfloor = 3,$$

so the boundary [semiconvergent](https://ourbigbook.com/codex/semiconvergent) has [denominator](https://ourbigbook.com/codex/denominator) $q_t = 3 \cdot 5 + 3 = 18$, namely $\frac{65}{18}$. The comparison value is

$$R = 1 \cdot (2 \cdot 3 \cdot 5 + 3) - 5 \cdot 3 = 18.$$

Since $5 \sqrt{13} \approx 18.0278$, we have $R < 5\sqrt{13}$, so $\frac{65}{18}$ is worse than $\frac{18}{5}$. The winning [denominator](https://ourbigbook.com/codex/denominator) is therefore $5$.

Now change the bound to $D=30$. Then

$$t = \left\lfloor \frac{30-3}{5} \right\rfloor = 5,$$

so the boundary [semiconvergent](https://ourbigbook.com/codex/semiconvergent) is $\frac{101}{28}$. This time

$$R = 1 \cdot (2 \cdot 5 \cdot 5 + 3) - 5 \cdot 3 = 38,$$

and $38 > 5\sqrt{13}$, so $\frac{101}{28}$ beats $\frac{18}{5}$. The winning [denominator](https://ourbigbook.com/codex/denominator) becomes $28$. This is exactly the behavior checked by the implementations.

## How the Code Works

The C++, Python, and Java implementations all follow the same mathematical pipeline: skip [perfect squares](https://ourbigbook.com/codex/perfect-square), generate the [continued fraction](https://ourbigbook.com/codex/continued-fraction) of each $\sqrt{n}$ with the [integer](https://ourbigbook.com/codex/integer) [recurrence relation](https://ourbigbook.com/codex/recurrence-relation) above, stop at the first [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) whose [denominator](https://ourbigbook.com/codex/denominator) exceeds $10^{12}$, and then decide between the previous [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) and the single boundary [semiconvergent](https://ourbigbook.com/codex/semiconvergent).

### Maintaining the continued-fraction state

For each non-square $n$, the implementation starts from $a_0=\lfloor \sqrt{n} \rfloor$ and updates the quadratic-irrational state $(m_k,d_k,a_k)$ together with the [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) [numerators](https://ourbigbook.com/codex/numerator) and [denominators](https://ourbigbook.com/codex/denominator). The [recurrence relation](https://ourbigbook.com/codex/recurrence-relation) for $(p_k,q_k)$ is synchronized with the [recurrence relation](https://ourbigbook.com/codex/recurrence-relation) for $(m_k,d_k,a_k)$, so when the [denominator](https://ourbigbook.com/codex/denominator) first crosses the bound, all data needed for the final comparison is already available.

### Choosing the winning denominator

Once the first oversized [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) appears, the implementation sets the provisional answer to the previous [denominator](https://ourbigbook.com/codex/denominator) $q_{k-1}$. If the [denominator](https://ourbigbook.com/codex/denominator) bound still leaves room beyond $q_{k-1}$, it computes the boundary value $t = \left\lfloor \frac{D-q_{k-2}}{q_{k-1}} \right\rfloor$ and forms the corresponding [semiconvergent](https://ourbigbook.com/codex/semiconvergent) [denominator](https://ourbigbook.com/codex/denominator) $t q_{k-1} + q_{k-2}$.

The final decision is made with the exact criterion above. The C++ and Java implementations use wider [integer arithmetic](https://ourbigbook.com/codex/integer-arithmetic) for intermediate values, while Python relies on arbitrary-precision [integers](https://ourbigbook.com/codex/integer) automatically. The C++ implementation also performs small exact validations against [brute force](https://ourbigbook.com/codex/brute-force-search) before launching the full computation, which confirms the [continued fraction](https://ourbigbook.com/codex/continued-fraction) logic on tiny cases.

### Accumulating the global sum

After the winning [denominator](https://ourbigbook.com/codex/denominator) for one $n$ is known, it is added to the running total. The C++ implementation distributes different $n$-values across several worker threads; the Python and Java implementations execute the same logic serially. The mathematical [decision rule](https://ourbigbook.com/codex/decision-rule) is identical in all three languages.

## Complexity Analysis

For one fixed $n$, the loop continues until a [continued fraction convergent](https://ourbigbook.com/codex/continued-fraction-convergent) [denominator](https://ourbigbook.com/codex/denominator) exceeds $D$. Since every partial quotient satisfies $a_k \ge 1$, the [denominators](https://ourbigbook.com/codex/denominator) obey $q_k \ge q_{k-1} + q_{k-2}$, so they grow at least as fast as [Fibonacci numbers](https://ourbigbook.com/codex/fibonacci-number). Therefore the number of [continued fraction](https://ourbigbook.com/codex/continued-fraction) steps is $O(\log D)$.

Each step performs only a constant amount of [integer arithmetic](https://ourbigbook.com/codex/integer-arithmetic), so over all non-squares $n \le N$ the total work is $O(N \log D)$, with $N=100000$ and $D=10^{12}$ in this problem. [Memory usage](https://ourbigbook.com/codex/memory-usage) is $O(1)$ per worker aside from the running total. The practical speed comes from replacing a hopeless scan over $10^{12}$ [denominators](https://ourbigbook.com/codex/denominator) by a very short [continued fraction](https://ourbigbook.com/codex/continued-fraction) walk for each $n$.
