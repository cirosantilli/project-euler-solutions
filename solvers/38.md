# Project Euler 38 Solution - Pandigital Multiples

<https://projecteuler.net/problem=38>:

* [38.py](38.py)
* [38.lean](38.lean)

We seek the largest 9-digit number that is a concatenation of `x*1, x*2, ..., x*n` for some [integer](https://ourbigbook.com/codex/integer) `x` and `n > 1`, and is 1–9 pandigital (uses each [digit](https://ourbigbook.com/codex/numerical-digit) 1..9 exactly once, no zero).

### Key observations
- The concatenation must be exactly 9 [digits](https://ourbigbook.com/codex/numerical-digit) long.
- If `x` has 5 or more [digits](https://ourbigbook.com/codex/numerical-digit), then `x*1` has at least 5 [digits](https://ourbigbook.com/codex/numerical-digit) and `x*2` has at least 5 [digits](https://ourbigbook.com/codex/numerical-digit), so concatenating two terms already yields 10+ [digits](https://ourbigbook.com/codex/numerical-digit). Therefore `x <= 9999`.
- For each `x` in `1..9999`, we build the concatenated [product](https://ourbigbook.com/codex/product) incrementally until length is at least 9:
  - If length becomes exactly 9 and `n > 1`, test pandigitality.
  - Track the maximum numeric value found.

### Pandigitality check
Use a [bitmask](https://ourbigbook.com/codex/bit-mask) over [digits](https://ourbigbook.com/codex/numerical-digit) 1..9:
- Reject any `0`.
- Reject repeated [digits](https://ourbigbook.com/codex/numerical-digit).
- Accept if the final [bit mask](https://ourbigbook.com/codex/bit-mask) equals the target [bit mask](https://ourbigbook.com/codex/bit-mask) for [digits](https://ourbigbook.com/codex/numerical-digit) 1..9.

This runs very fast (only 9999 candidates, each building a short [string](https://ourbigbook.com/codex/string)).
The resulting maximum is `932718654`.
