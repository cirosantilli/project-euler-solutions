# Project Euler 734 Solution - A Bit of Prime

<https://projecteuler.net/problem=734>:

* [734.py](734.py)

This solution counts **k-tuples of [primes](https://ourbigbook.com/codex/prime)** whose **[bitwise OR](https://ourbigbook.com/codex/bitwise-or)** is also a [prime](https://ourbigbook.com/codex/prime) (all values `≤ n`), [modulo](https://ourbigbook.com/codex/modulo) `1_000_000_007`.

## Key idea: inclusion–exclusion over bits, then swap the sums

For a fixed [prime](https://ourbigbook.com/codex/prime) `y`, let `B(y)` be the set of 1-bits in `y`.

- A [prime](https://ourbigbook.com/codex/prime) `x` is allowed in the tuple if `x` is a **submask** of `y` (i.e. `x | y = y`).
- Let `A(m)` be the number of [primes](https://ourbigbook.com/codex/prime) `x ≤ n` that are submasks of `m`.

Then the number of k-tuples whose OR is **exactly** `y` can be written by [inclusion–exclusion](https://ourbigbook.com/codex/inclusion-exclusion-principle) over missing bits:

\[
\#(\mathrm{OR}=y)=\sum_{m \subseteq y} (-1)^{\mathrm{pop}(y)-\mathrm{pop}(m)} A(m)^k
\]

Summing this over all [prime](https://ourbigbook.com/codex/prime) `y` is still expensive if done per-`y`.  
So we **swap** the order of [summation](https://ourbigbook.com/codex/summation) and collect coefficients per `m`:

\[
T(n,k)=\sum_m A(m)^k \cdot (-1)^{\mathrm{pop}(m)} \cdot S(m)
\]

where

\[
S(m)=\sum_{\substack{y\ \text{prime} \\ y\supseteq m}} (-1)^{\mathrm{pop}(y)}
\]

Now the task is to compute `A(m)` for all masks `m`, and `S(m)` for all masks `m`.

## Technique 1: subset zeta transform for `A(m)`

Let `f[x]=1` if `x` is [prime](https://ourbigbook.com/codex/prime) (and `x ≤ n`), else `0`.  
Then

\[
A(m)=\sum_{x\subseteq m} f[x]
\]

This is exactly a **subset sum over [bitmasks](https://ourbigbook.com/codex/bit-mask)**, computed for all `m` in `O(B·2^B)` using the classic [zeta transform](https://ourbigbook.com/codex/zeta-transform).

## Technique 2: superset zeta transform for `S(m)`

Define `h[y]=(-1)^{popcount(y)}` if `y` is [prime](https://ourbigbook.com/codex/prime) (and `y ≤ n`), else `0`.  
Then

\[
S(m)=\sum_{y\supseteq m} h[y]
\]

This is a **superset sum over [bitmasks](https://ourbigbook.com/codex/bit-mask)**, also computable in `O(B·2^B)` by iterating bits and adding from `m|bit` into `m`.

## Technique 3: fast modular exponentiation

After both transforms, the final sum is:

- one loop over `m = 0..n`
- with a single `pow(A(m), k, MOD)` per `m`

Python’s built-in `pow(base, exp, mod)` performs fast [modular exponentiation](https://ourbigbook.com/codex/modular-exponentiation).

## Complexity

Let `B = bit_length(n)` and `U = 2^B`.

- [Number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve): `O(n log log n)`
- Two [zeta transforms](https://ourbigbook.com/codex/zeta-transform): `O(B·U)`
- Final accumulation: `O(n)` [modular exponentiations](https://ourbigbook.com/codex/modular-exponentiation)

For `n = 10^6`, `B = 20`, `U = 1,048,576`, which is practical in pure Python.
