# Project Euler 634 Solution - Numbers of the Form $a^2b^3$

<https://projecteuler.net/problem=634>:

* [634.py](634.py)

We need to count [integers](https://ourbigbook.com/codex/integer) `x ≤ n` that **can be expressed** as:

\[
x = a^2 b^3 \quad\text{with}\quad a>1,\; b>1
\]

The key is to reason about [prime exponents](https://ourbigbook.com/codex/prime-exponent).

## 1) Exponent decomposition

Write the [prime](https://ourbigbook.com/codex/prime) [integer factorization](https://ourbigbook.com/codex/integer-factorization):

\[
x = \prod p^{e_p}
\]

In any representation `x = a^2 b^3`, each exponent must split as:

\[
e_p = 2i_p + 3j_p \quad (i_p,j_p \ge 0)
\]

Because the nonnegative combinations of `2` and `3` produce every [integer](https://ourbigbook.com/codex/integer) **except 1**, the condition is:

- `e_p` is never `1` for any [prime](https://ourbigbook.com/codex/prime) `p`.

Numbers with all [prime exponents](https://ourbigbook.com/codex/prime-exponent) ≥ 2 are called **[powerful numbers](https://ourbigbook.com/codex/powerful-number)**.

## 2) Counting all powerful numbers using a unique form

Every [powerful number](https://ourbigbook.com/codex/powerful-number) has a **unique** representation:

\[
x = A^2 B^3 \quad \text{where } B \text{ is squarefree and } A \ge 1
\]

(For each [prime exponent](https://ourbigbook.com/codex/prime-exponent) `e`, take `j = e mod 2` so `B` contains each [prime](https://ourbigbook.com/codex/prime) at most once.)

So the number of [powerful numbers](https://ourbigbook.com/codex/powerful-number) `P(n)` is:

\[
P(n) = \sum_{\substack{B \le \sqrt[3]{n} \\ B\ \text{squarefree}}}
\left\lfloor \sqrt{\frac{n}{B^3}} \right\rfloor
\]

We [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) [squarefree](https://ourbigbook.com/codex/squarefree-integer) `B` up to `⌊n^{1/3}⌋` (about 2.1 million for `9×10^18`) and sum [integer square roots](https://ourbigbook.com/codex/integer-square-root).

## 3) Subtract the powerful numbers that *cannot* use both `a>1` and `b>1`

Even if `x` is powerful, it might be impossible to make **both** parts nontrivial.

The only failing cases are:

1. **No cube contribution possible**  
   All exponents are in `{0,2,4}`  
   ⇔ `x = y^2` where `y` is **[cubefree](https://ourbigbook.com/codex/cubefree-integer)** (no [prime](https://ourbigbook.com/codex/prime) cube divides `y`).

2. **No square contribution possible**  
   All exponents are in `{0,3}`  
   ⇔ `x = z^3` where `z` is **[squarefree](https://ourbigbook.com/codex/squarefree-integer)**.

3. **[Prime](https://ourbigbook.com/codex/prime) sixth powers**  
   `x = p^6` for a [prime](https://ourbigbook.com/codex/prime) `p`.  
   (Exponent `6` can be `2·3` or `3·2`, but never with both parts positive for a *single* [prime](https://ourbigbook.com/codex/prime).)

The first two sets overlap only at `x = 1`, and [prime](https://ourbigbook.com/codex/prime) sixth powers are disjoint from both.

So:

\[
F(n) = P(n) - |X_1| - |X_2| - |X_3| + 1
\]

## 4) Efficient counting of the subtracted sets

- `|X2|` is just the count of [squarefree integers](https://ourbigbook.com/codex/squarefree-integer) `≤ ⌊n^{1/3}⌋` (from the same [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve)).
- `|X3|` is `π(⌊n^{1/6}⌋)` (a tiny [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) up to ~1500).

The tricky part is `|X1| =` number of **[cubefree](https://ourbigbook.com/codex/cubefree-integer)** [integers](https://ourbigbook.com/codex/integer) `≤ ⌊√n⌋`, and `√n` is ~3×10⁹ (too big to [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve)).

Use [Möbius inversion](https://ourbigbook.com/codex/mobius-inversion):

\[
\text{cubefree}(R) = \sum_{k=1}^{\lfloor R^{1/3}\rfloor} \mu(k)\left\lfloor \frac{R}{k^3}\right\rfloor
\]

Here `R = ⌊√n⌋`, and `R^{1/3}` is only about 1440, so we can compute `μ(k)` with a small linear [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve).

## Complexity

For `n = 9×10^18`:

- [Squarefree](https://ourbigbook.com/codex/squarefree-integer) [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) up to `n^{1/3}`: ~2.1 million
- [Summation](https://ourbigbook.com/codex/summation) over [squarefree](https://ourbigbook.com/codex/squarefree-integer) `B`: ~1.27 million terms
- [Cubefree](https://ourbigbook.com/codex/cubefree-integer) count uses Möbius up to ~1440

Overall this runs comfortably fast in pure Python.
