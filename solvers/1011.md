# Project Euler 1011 Solution - Modified Euclidean Algorithm

<https://projecteuler.net/problem=1011>:

* [1011.py](1011.py)

The terminal value is symmetric in its two arguments. Sum over the upper
[triangle](https://ourbigbook.com/codex/triangle) `1 <= a <= b < N`, double it, and subtract the diagonal. On the
diagonal, the first operation produces `(1,a)`, so `f(a,a) = a`.

For fixed `a`, group the values of `b` by their quotient `q = floor(b/a)`.
Every member of this group takes the same first step to `(a,q)`. Its size is

`min(a, N-a*q)`.

For `q = 1`, the terminal value is immediately `a`; sum these groups
separately. Only `a <= (N-1)//2` can have a group with `q >= 2`. For those
groups, simulate the modified [algorithm](https://ourbigbook.com/codex/algorithm) on the much smaller pair `(a,q)`.
Each operation replaces the larger argument by its quotient, strictly
reducing it until an argument is one.

There are `O(N log N)` quotient groups rather than `O(N^2)` original pairs.
Each simulation takes at most `O(log N)` divisions. The solver uses constant
auxiliary memory and asserts the given trajectory's terminal value and both
supplied sums.
