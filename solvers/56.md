# Project Euler 56 Solution - Powerful Digit Sum

<https://projecteuler.net/problem=56>:

* [56.py](56.py)
* [56.lean](56.lean)

We need the maximum sum of digits of numbers of the form `a^b` where `a, b < 100`.

## Approach
- Iterate over all pairs `(a, b)` with `0 <= a < 100` and `0 <= b < 100` (only 100×100 = 10,000 cases).
- Compute `a^b` using Python’s [arbitrary-precision integers](https://ourbigbook.com/codex/arbitrary-precision-integer).
- Convert the result to a [string](https://ourbigbook.com/codex/string) and sum its digits.
- Track the maximum [digit sum](https://ourbigbook.com/codex/digit-sum) found.

This is fast enough because the search space is tiny and Python [big integers](https://ourbigbook.com/codex/arbitrary-precision-integer) handle `a^b` efficiently.

## Result
The maximum [digital sum](https://ourbigbook.com/codex/digit-sum) is **972**.
