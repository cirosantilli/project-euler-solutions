# Project Euler 415 Solution - Titanic Sets

<https://projecteuler.net/problem=415>:

* [415.py](415.py)

The solver counts the complement. By [Sylvester-Gallai](https://ourbigbook.com/codex/sylvester-gallai-theorem), a [subset](https://ourbigbook.com/codex/subset) of the grid is
not titanic exactly when it is empty, a [singleton](https://ourbigbook.com/codex/singleton), or all selected points are
[collinear](https://ourbigbook.com/codex/collinearity).

## Key ideas

For a grid line with `k` [lattice points](https://ourbigbook.com/codex/lattice-point), the non-titanic [subsets](https://ourbigbook.com/codex/subset) on that line have
size at least 3. Rewriting the binomial contribution by line length gives a sum
over `l` of:

\[
F_l(N)(2^l-(l+1)),
\]

where `F_l(N)` is the number of grid lines with at least `l + 1` points.

Primitive [direction vectors](https://ourbigbook.com/codex/direction-vector) reduce `F_l(N)` to cumulative totient sums:

\[
\Phi(M)=\sum_{d\le M}\varphi(d),\quad
\Psi_1(M)=\sum_{d\le M}d\varphi(d),\quad
\Psi_2(M)=\sum_{d\le M}d^2\varphi(d).
\]

These [summatory functions](https://ourbigbook.com/codex/summatory-function) are precomputed up to a cutoff and then evaluated for
large arguments with quotient-block [recursion](https://ourbigbook.com/codex/recursion) from the identity
\(\sum_{d\mid n}\varphi(d)=n\).

On an interval where both `N // l` and `N // (l + 1)` are constant, `F_l(N)` is a
[quadratic polynomial](https://ourbigbook.com/codex/quadratic-polynomial) in `l`. The solver sums each whole interval using closed
forms for:

- \(\sum 2^l\), \(\sum l2^l\), \(\sum l^2 2^l\)
- \(\sum l\), \(\sum l^2\), \(\sum l^3\)

Finally it subtracts the [collinear](https://ourbigbook.com/codex/collinearity) complement, the [empty set](https://ourbigbook.com/codex/empty-set), and all [singletons](https://ourbigbook.com/codex/singleton)
from \(2^{(N+1)^2}\) [modulo](https://ourbigbook.com/codex/modulo-operation) \(10^8\).
