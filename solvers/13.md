# Large Sum (first 10 digits)

We are given 100 numbers of 50 [digits](https://ourbigbook.com/codex/numerical-digit) each and need the first 10 [digits](https://ourbigbook.com/codex/numerical-digit) of their [sum](https://ourbigbook.com/codex/sum).

## Key insight
Python [integers](https://ourbigbook.com/codex/integer) have [arbitrary precision](https://ourbigbook.com/codex/arbitrary-precision-arithmetic), so we can:
1. Parse each 50-digit [string](https://ourbigbook.com/codex/string) into an `int`
2. [Sum](https://ourbigbook.com/codex/sum) them exactly using normal [integer](https://ourbigbook.com/codex/integer) [addition](https://ourbigbook.com/codex/addition)
3. Convert the total back to a [string](https://ourbigbook.com/codex/string) and take the first 10 characters

This is efficient because there are only 100 numbers, and [big integer](https://ourbigbook.com/codex/arbitrary-precision-integer) [addition](https://ourbigbook.com/codex/addition) on ~50-digit values is very fast.

The program includes an `assert` for the known correct output for this specific input.
