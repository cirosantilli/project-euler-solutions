# Project Euler 431 Solution - Square Space Silo

<https://projecteuler.net/problem=431>:

* [431.py](431.py)

This solution computes the horizontal offsets `x` (in meters) for which the **wasted [volume](https://ourbigbook.com/codex/volume)** inside a cylindrical silo is an **[integer](https://ourbigbook.com/codex/integer) square**, then prints `sum(x)` to 9 decimal places.

## Key ideas used

### 1) Geometry → an integral of distance
For a [granular material](https://ourbigbook.com/codex/granular-material) with [angle of repose](https://ourbigbook.com/codex/angle-of-repose) `α`, the surface height drop equals:

`height = tan(α) * (horizontal distance from the delivery point)`

So the wasted (empty) [volume](https://ourbigbook.com/codex/volume) above the grain surface is:

`V(x) = tan(α) * ∬_disk dist(P, apex) dA`

where the [disk](https://ourbigbook.com/codex/disk-mathematics) is the silo top ([radius](https://ourbigbook.com/codex/radius) `R`) and the apex is offset by `x` from the [disk](https://ourbigbook.com/codex/disk-mathematics) center.

### 2) Polar coordinates centered at the apex
Switch to [polar coordinates](https://ourbigbook.com/codex/polar-coordinates) around the apex. Along a ray [angle](https://ourbigbook.com/codex/angle) `θ`, the ray intersects the [circle](https://ourbigbook.com/codex/circle) at a [radius](https://ourbigbook.com/codex/radius)

`r_max(θ) = -x cos θ + sqrt(R^2 - x^2 sin^2 θ)`  (for `0 ≤ x ≤ R`)

In these coordinates, `dist = r` and `dA = r dr dθ`, so:

`I(x) = ∬_disk r dA = ∫∫ r * r dr dθ = (1/3) ∫ r_max(θ)^3 dθ`

Using [symmetry](https://ourbigbook.com/codex/symmetry), this becomes:

`I(x) = (2/3) ∫_0^π r_max(θ)^3 dθ`

and therefore:

`V(x) = tan(α) * I(x)`

So the 2D [area](https://ourbigbook.com/codex/area) [integral](https://ourbigbook.com/codex/integral) reduces to a **single 1D [integral](https://ourbigbook.com/codex/integral)** over `θ`.

### 3) High-accuracy numerical integration (Gauss–Legendre)
The remaining [integral](https://ourbigbook.com/codex/integral) is smooth, so fixed-order **[Gauss–Legendre quadrature](https://ourbigbook.com/codex/gauss-legendre-quadrature)** gives high accuracy with a small number of [function evaluations](https://ourbigbook.com/codex/function-evaluation). The code computes nodes/weights on `[-1,1]` using [Newton root-finding iteration](https://ourbigbook.com/codex/newton-root-finding-iteration) on [Legendre polynomial](https://ourbigbook.com/codex/legendre-polynomial) roots, then maps them onto `[0, π]`.

### 4) Monotonic root-finding (bisection)
`V(x)` increases with `x` on `[0, R]`, so for each [integer](https://ourbigbook.com/codex/integer) square `n²` in `[V(0), V(R)]` there is at most one solution. Each `x` is found with **[bisection](https://ourbigbook.com/codex/bisection-method)**, which is robust and easy to implement.

### 5) Built-in statement checks
The example numeric values from the problem statement are asserted:
- For `R=3`, `α=30°`: `V(0) ≈ 32.648388556`
- `V(1.114785284) ≈ 36`
- `V(2.511167869) ≈ 49`

## Running

```bash
python3 main.py
```

It prints the required `sum(x)` for `R=6` and `α=40°` formatted to 9 decimal places.
