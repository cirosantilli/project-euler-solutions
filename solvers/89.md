# Project Euler 89 Solution - Roman Numerals

<https://projecteuler.net/problem=89>:

* [89.py](89.py)
* [89.lean](89.lean)

To measure how many characters can be saved, each given [Roman numeral](https://ourbigbook.com/codex/roman-numeral) is:

1. **Parsed to an [integer](https://ourbigbook.com/codex/integer)**  
   Scan left to right; if a symbol is followed by a larger-valued symbol, treat it as subtractive (e.g. `IV = 5 - 1`), otherwise add it.

2. **Re-encoded in minimal Roman form**  
   Use a greedy decomposition with the standard minimal tokens:
   `M, CM, D, CD, C, XC, L, XL, X, IX, V, IV, I`.

3. **Count saved characters**  
   Add `len(original) - len(minimal)` across all lines.

The generalized input is a list of nonempty strings using `IVXLCDM`, with no limit on length or value. The adjacent-pair parser also gives a value to symbol strings outside the valid Roman grammar. For these strings the character difference can be negative: `IM` parses as 999, whose canonical form `CMXCIX` is longer. An empty input list returns zero.

### Formalization

[RomanNumerals.lean](../ProjectEulerSolutions/Lib/RomanNumerals.lean) proves that the accumulator parser agrees with recursive adjacent-pair parsing, that a nonempty Roman-symbol string has positive value, and that division groups repeated token subtraction without changing the encoding.

The [reference source proof](../data/project-euler-statements/data/py/project_euler_statements/p89.py.lean) establishes termination and the exact signed sum for every list of strings. It follows symbol lookup, recursive parsing, token-table allocation, every encoder loop, joining, length subtraction, and the consumed generator. All pre-existing caller objects are preserved. The encoder proof covers every integer, producing an empty result for nonpositive values. [RomanEncoding.lean](../ProjectEulerSolutions/Lib/RomanEncoding.lean) connects emitted characters to the string representation.

The [optimized parser source proof](89.py.lean.d/ParserExecution.lean) establishes the same exact parsing value for every Roman-symbol string, including the empty string. It follows string indexing, the global symbol dictionary, both index advances, and `continue`, and leaves the caller's heap unchanged. The dictionary premise requires the seven standard symbol values while permitting other entries. [RomanParsing.lean](../ProjectEulerSolutions/Lib/RomanParsing.lean) connects indexed suffixes to recursive parsing.

The [optimized encoder source proof](89.py.lean.d/EncoderExecution.lean) covers every positive integer. It follows the immutable token table, early `break`, `divmod` tuple allocation and unpacking, string repetition, list appends, and final join. [RomanChunks.lean](../ProjectEulerSolutions/Lib/RomanChunks.lean) connects string chunks to the reference character model. The [complete optimized source proof](89.py.lean.d/SolverExecution.lean) establishes the exact signed savings sum for every generalized input, including an empty list, and preserves all caller objects while allocating private intermediates.

Public optimized contracts and complete solver equivalence remain unfinished. The equivalence proof must account for the same global table state on both sides. The older standalone Lean solver is not used by these proofs.
