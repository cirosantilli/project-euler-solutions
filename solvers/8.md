# Project Euler 8 Solution - Largest Product in a Series

<https://projecteuler.net/problem=8>:

* [8.py](8.py)
* [8.lean](8.lean)

## Key idea
A [sliding window](https://ourbigbook.com/codex/sliding-window-algorithm) [product](https://ourbigbook.com/codex/product) works, but zeros break the ability to divide out the outgoing [digit](https://ourbigbook.com/codex/numerical-digit) safely.

## Approach
1. Take the [decimal digits](https://ourbigbook.com/codex/decimal-digit) directly as a list of [integers](https://ourbigbook.com/codex/integer).
2. Split the [digit](https://ourbigbook.com/codex/numerical-digit) list into maximal contiguous segments that contain **no zeros**.
   - Any [sliding window](https://ourbigbook.com/codex/sliding-window-algorithm) containing a zero has [product](https://ourbigbook.com/codex/product) 0, so it can never beat a positive maximum.
3. For each zero-free segment of length `>= k`:
   - Compute the [product](https://ourbigbook.com/codex/product) of the first `k` [digits](https://ourbigbook.com/codex/numerical-digit).
   - Slide the [sliding window](https://ourbigbook.com/codex/sliding-window-algorithm) by one position at a time using:
     - `prod = (prod // outgoing_digit) * incoming_digit`
4. Track the maximum [product](https://ourbigbook.com/codex/product) across all segments.

## Complexity
- Time: `O(n)` where `n = 1000`
- Extra space: `O(1)`; the [digit](https://ourbigbook.com/codex/numerical-digit) list is the input

The code includes the statement's example assertion (`k=4` gives `5832`) and prints the result for `k=13`.
