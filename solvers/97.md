# Project Euler 97 Solution - Large Non-Mersenne Prime

<https://projecteuler.net/problem=97>:

* [97.py](97.py)
* [97.lean](97.lean)

We need the last 10 [digits](https://ourbigbook.com/codex/numerical-digit) of:

\[
28433 \times 2^{7830457} + 1
\]

The last 10 [digits](https://ourbigbook.com/codex/numerical-digit) are the value [modulo](https://ourbigbook.com/codex/modulo-operation) \(10^{10}\). So we compute:

\[
(28433 \cdot 2^{7830457} + 1) \bmod 10^{10}
\]

Key insight: use [modular exponentiation](https://ourbigbook.com/codex/modular-exponentiation) to compute \(2^{7830457} \bmod 10^{10}\) efficiently in \(O(\log n)\) time.  
Python’s built-in `pow(base, exp, mod)` performs fast [modular exponentiation](https://ourbigbook.com/codex/modular-exponentiation) directly.

Finally, multiply by 28433, add 1, take [modulo](https://ourbigbook.com/codex/modulo-operation) \(10^{10}\), and print the result.
