# Project Euler 50 Solution - Consecutive Prime Sum

<https://projecteuler.net/problem=50>:

* [50.py](50.py)
* [50.lean](50.lean)

## Key idea
A [sum](https://ourbigbook.com/codex/sum) of consecutive [primes](https://ourbigbook.com/codex/prime-number) can be written using [prefix sums](https://ourbigbook.com/codex/prefix-sum):

- Let `primes = [p0, p1, ..., p(n-1)]`
- Let `prefix[k] = p0 + p1 + ... + p(k-1)` with `prefix[0] = 0`
- Then the [sum](https://ourbigbook.com/codex/sum) of `length` consecutive [primes](https://ourbigbook.com/codex/prime-number) starting at index `i` is:
  `prefix[i + length] - prefix[i]`

## Algorithm
1. **[Sieve of Eratosthenes](https://ourbigbook.com/codex/sieve-of-eratosthenes)** up to `limit-1` to allow O(1) [primality](https://ourbigbook.com/codex/primality) checks.
2. Build the list of [primes](https://ourbigbook.com/codex/prime-number) and their **[prefix sums](https://ourbigbook.com/codex/prefix-sum)**.
3. Compute the **maximum feasible length** `L` such that the [sum](https://ourbigbook.com/codex/sum) of the first `L` [primes](https://ourbigbook.com/codex/prime-number) is still `< limit`.
4. Try lengths from `L` down to `1`:
   - Slide a [sliding window](https://ourbigbook.com/codex/sliding-window-algorithm) over [prime](https://ourbigbook.com/codex/prime-number) indices `i`
   - Compute the [sliding window](https://ourbigbook.com/codex/sliding-window-algorithm) [sum](https://ourbigbook.com/codex/sum) via [prefix sums](https://ourbigbook.com/codex/prefix-sum)
   - Stop sliding early when the [sum](https://ourbigbook.com/codex/sum) reaches `limit` (for fixed length, [sums](https://ourbigbook.com/codex/sum) grow with `i`)
   - If the [sum](https://ourbigbook.com/codex/sum) is [prime](https://ourbigbook.com/codex/prime-number), this is the best answer (since we're iterating lengths downward)

## Complexity
- [Number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve): `O(limit log log limit)`
- Search: at most about `L * number_of_primes` [sliding window](https://ourbigbook.com/codex/sliding-window-algorithm) checks, but `L` is only ~500 for `limit=1,000,000`,
  making it fast enough in PyPy.

The program prints the [prime](https://ourbigbook.com/codex/prime-number) below one million that can be written as the [sum](https://ourbigbook.com/codex/sum) of the most consecutive [primes](https://ourbigbook.com/codex/prime-number).
