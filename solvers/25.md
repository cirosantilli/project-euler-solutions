# Project Euler 25 Solution - $1000$-digit Fibonacci Number

<https://projecteuler.net/problem=25>:

* [25.py](25.py)
* [25.lean](25.lean)

We need the first index `n` for which the [Fibonacci number](https://ourbigbook.com/codex/fibonacci-number) `F_n` contains 1000 [decimal digits](https://ourbigbook.com/codex/decimal-digit).

### Key idea
The index is small enough (only a few thousand) that we can directly generate [Fibonacci numbers](https://ourbigbook.com/codex/fibonacci-number) using Python's built-in [arbitrary-precision integers](https://ourbigbook.com/codex/arbitrary-precision-integer):

- Start from `F_1 = 1`, `F_2 = 1`
- Repeatedly update `(F_{n-1}, F_n) -> (F_n, F_{n-1} + F_n)`
- Stop when `len(str(F_n)) >= target_digits`

This takes only a few thousand iterations for 1000 [digits](https://ourbigbook.com/codex/numerical-digit).

### Complexity
- Time: `O(n)` [additions](https://ourbigbook.com/codex/addition) of [big integers](https://ourbigbook.com/codex/arbitrary-precision-integer) (here `n ≈ 4782`)
- Space: `O(1)` aside from the size of the [integers](https://ourbigbook.com/codex/integer) themselves

The program includes small asserts (e.g., first 3-digit [Fibonacci number](https://ourbigbook.com/codex/fibonacci-number) is `F_12`) and prints the final answer.
