# Project Euler 820 Solution - $N$<sup>th</sup> Digit of Reciprocals

<https://projecteuler.net/problem=820>:

* [820.py](820.py)

## Problem Summary

For each [integer](https://ourbigbook.com/codex/integer) $k$ from $1$ to $n$, let $d_n\left(\frac{1}{k}\right)$ be the $n$-th [digit](https://ourbigbook.com/codex/numerical-digit) after the decimal point in the [decimal expansion](https://ourbigbook.com/codex/decimal-expansion) of $\frac{1}{k}$. The required quantity is

$$S(n)=\sum_{k=1}^{n} d_n\left(\frac{1}{k}\right).$$

A direct simulation of [long division](https://ourbigbook.com/codex/long-division) would advance through $n$ decimal places for every [denominator](https://ourbigbook.com/codex/denominator), which is far too expensive when $n=10^7$. The implementations avoid that by jumping straight to the needed [digit](https://ourbigbook.com/codex/numerical-digit) through [modular arithmetic](https://ourbigbook.com/codex/modular-arithmetic).

## Mathematical Approach

The entire problem rests on one observation: the $n$-th decimal [digit](https://ourbigbook.com/codex/numerical-digit) of a reciprocal can be recovered from the remainder of $10^{n-1}$ [modulo](https://ourbigbook.com/codex/modulo-operation) the [denominator](https://ourbigbook.com/codex/denominator).

### Step 1: Write the $n$-th digit as a floor difference

If

$$\frac{1}{k}=0.a_1a_2a_3\dots,$$

then shifting the decimal point by $n$ places gives

$$\left\lfloor \frac{10^n}{k} \right\rfloor = 10^{n-1}a_1 + 10^{n-2}a_2 + \cdots + 10a_{n-1} + a_n.$$

So the last [digit](https://ourbigbook.com/codex/numerical-digit) of that [integer](https://ourbigbook.com/codex/integer) is exactly the [digit](https://ourbigbook.com/codex/numerical-digit) we want. Therefore

$$d_n\left(\frac{1}{k}\right)=\left\lfloor \frac{10^n}{k} \right\rfloor - 10\left\lfloor \frac{10^{n-1}}{k} \right\rfloor.$$

This is the standard way to isolate one decimal [digit](https://ourbigbook.com/codex/numerical-digit) after scaling by powers of $10$.

### Step 2: Collapse the formula to one remainder

Write the [Euclidean division](https://ourbigbook.com/codex/euclidean-division) of $10^{n-1}$ by $k$ as

$$10^{n-1}=qk+r,\qquad 0\le r<k.$$

Then

$$\left\lfloor \frac{10^{n-1}}{k} \right\rfloor=q$$

and

$$\frac{10^n}{k}=10q+\frac{10r}{k}.$$

Taking floors yields

$$\left\lfloor \frac{10^n}{k} \right\rfloor=10q+\left\lfloor \frac{10r}{k} \right\rfloor.$$

Substituting into the previous identity gives the compact formula

$$d_n\left(\frac{1}{k}\right)=\left\lfloor \frac{10r}{k} \right\rfloor,$$

where

$$r=10^{n-1}\bmod k.$$

This is exactly the quantity used by the implementation. It also handles [terminating decimals](https://ourbigbook.com/codex/terminating-decimal) automatically: once the remainder is $0$, every later [digit](https://ourbigbook.com/codex/numerical-digit) is $0$.

### Step 3: Compute the remainder with binary exponentiation

For each [denominator](https://ourbigbook.com/codex/denominator) $k$, we need only the residue

$$r \equiv 10^{n-1}\pmod{k}.$$

Computing $10^{n-1}$ itself would be absurdly large, but [repeated squaring](https://ourbigbook.com/codex/repeated-squaring) evaluates the residue in $O(\log n)$ [modular multiplications](https://ourbigbook.com/codex/modular-multiplication). Every intermediate value is reduced [modulo](https://ourbigbook.com/codex/modulo-operation) $k$, so the numbers never grow beyond the modulus.

Once $r$ is known, the [digit](https://ourbigbook.com/codex/numerical-digit) is recovered immediately by the [integer](https://ourbigbook.com/codex/integer) formula $\left\lfloor 10r/k \right\rfloor$.

### Step 4: Sum over all denominators

Applying the [digit](https://ourbigbook.com/codex/numerical-digit) formula to every $k$ from $1$ to $n$ gives

$$S(n)=\sum_{k=1}^{n}\left\lfloor \frac{10\left(10^{n-1}\bmod k\right)}{k} \right\rfloor.$$

The problem is therefore not about building [decimal expansions](https://ourbigbook.com/codex/decimal-expansion); it is about evaluating one modular power for each [denominator](https://ourbigbook.com/codex/denominator) and adding the resulting [digits](https://ourbigbook.com/codex/numerical-digit).

### Step 5: Worked Example for $n=7$

The small checkpoint $n=7$ illustrates the method clearly. We need the seventh [digit](https://ourbigbook.com/codex/numerical-digit) after the decimal point of $1/k$ for $1\le k\le 7$.

For $k=3$,

$$10^6\bmod 3 = 1,\qquad d_7\left(\frac{1}{3}\right)=\left\lfloor \frac{10\cdot 1}{3} \right\rfloor=3.$$

For $k=6$,

$$10^6\bmod 6 = 4,\qquad d_7\left(\frac{1}{6}\right)=\left\lfloor \frac{40}{6} \right\rfloor=6.$$

For $k=7$,

$$10^6\bmod 7 = 1,\qquad d_7\left(\frac{1}{7}\right)=\left\lfloor \frac{10}{7} \right\rfloor=1.$$

The complete [digit](https://ourbigbook.com/codex/numerical-digit) list is

$$0,0,3,0,0,6,1,$$

so

$$S(7)=0+0+3+0+0+6+1=10.$$

This matches the checkpoint used by the implementations.

## How the Code Works

The C++, Python, and Java implementations all follow the same structure. They iterate through every [denominator](https://ourbigbook.com/codex/denominator) $k$ from $1$ to $n$, compute the residue $10^{n-1}\bmod k$ by [repeated squaring](https://ourbigbook.com/codex/repeated-squaring), convert that residue into the required decimal [digit](https://ourbigbook.com/codex/numerical-digit) via

$$\left\lfloor \frac{10r}{k} \right\rfloor,$$

and add the [digit](https://ourbigbook.com/codex/numerical-digit) to a running total.

No decimal string is ever built, and no long-division table is stored. The implementation keeps only a fixed set of [integers](https://ourbigbook.com/codex/integer) for the current modulus, current base, remaining exponent, current residue, and the cumulative sum.

## Complexity Analysis

For one [denominator](https://ourbigbook.com/codex/denominator) $k$, [binary exponentiation](https://ourbigbook.com/codex/exponentiation-by-squaring) for exponent $n-1$ needs $O(\log n)$ [modular multiplications](https://ourbigbook.com/codex/modular-multiplication). Repeating that for every $k=1,2,\dots,n$ gives total time

$$O(n\log n).$$

The auxiliary space is $O(1)$, since only a constant number of [integer](https://ourbigbook.com/codex/integer) variables is maintained in addition to the final sum.
