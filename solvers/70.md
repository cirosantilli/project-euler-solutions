# Project Euler 70 Solution - Totient Permutation

<https://projecteuler.net/problem=70>:

* [70.py](70.py)
* [70.lean](70.lean)

We need `1 < n < 10^7` such that `phi(n)` is a digit-permutation of `n`, and `n/phi(n)` is minimal.

## Key ideas used

1. **Compute all [totients](https://ourbigbook.com/codex/euler-totient-function) efficiently**
   - Use a **[linear sieve](https://ourbigbook.com/codex/linear-sieve)** to compute `phi(k)` for every `k ≤ 9,999,999` in `O(N)` time.
   - Store `phi` in `array('I')` (32-bit) to keep memory reasonable.

2. **Fast [permutation](https://ourbigbook.com/codex/permutation) check**
   - Two numbers are [permutations](https://ourbigbook.com/codex/permutation) iff their digit counts match.
   - Compute a compact **[digit](https://ourbigbook.com/codex/numerical-digit) signature** by packing digit counts into an [integer](https://ourbigbook.com/codex/integer):
     - Use 3 [bits](https://ourbigbook.com/codex/bit) per [digit](https://ourbigbook.com/codex/numerical-digit) (base 8) since counts are ≤ 7 for numbers `< 10^7`.
     - Compare `signature(n) == signature(phi(n))`.

3. **Cheap filters before signature**
   - Same digit multiset ⇒ same [digit sum](https://ourbigbook.com/codex/digit-sum) ⇒ `n ≡ phi(n) (mod 9)`.
   - Same [multiset](https://ourbigbook.com/codex/multiset) ⇒ same number of [digits](https://ourbigbook.com/codex/numerical-digit) (checked via range bounds).

4. **Minimize ratio without floats**
   - Compare `n/phi(n)` using [cross multiplication](https://ourbigbook.com/codex/cross-multiplication):
     - `n1/phi1 < n2/phi2` ⇔ `n1*phi2 < n2*phi1`.

The program prints the minimizing `n`.
