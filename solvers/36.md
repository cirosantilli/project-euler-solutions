# Project Euler 36 Solution - Double-base Palindromes

<https://projecteuler.net/problem=36>:

* [36.py](36.py)
* [36.lean](36.lean)

We need the [sum](https://ourbigbook.com/codex/sum) of all numbers `< 1,000,000` that are palindromic in both base 10 and base 2 (no leading zeros allowed).

## Key ideas
- Instead of checking every number up to one million, we **generate only [decimal palindromes](https://ourbigbook.com/codex/decimal-palindrome)** below the limit.
- Any [decimal palindrome](https://ourbigbook.com/codex/decimal-palindrome) below `1,000,000` has at most 6 [digits](https://ourbigbook.com/codex/numerical-digit). These can be built by mirroring a "half":
  - **Odd length**: `s + reverse(s[:-1])`
  - **Even length**: `s + reverse(s)`
  where `s = str(i)` and `i` ranges from `1` to `999`.
- A [binary palindrome](https://ourbigbook.com/codex/binary-palindrome) cannot be even (it would end in `0`, and reversing would create a leading zero), so we skip even candidates.
- For each generated [decimal palindrome](https://ourbigbook.com/codex/decimal-palindrome), check if its [binary representation](https://ourbigbook.com/codex/binary-representation) `bin(n)[2:]` is also a [palindrome](https://ourbigbook.com/codex/palindrome).

This approach is fast and simple.
