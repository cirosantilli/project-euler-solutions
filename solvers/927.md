# Project Euler 927 Solution - Prime-ary Tree

<https://projecteuler.net/problem=927>:

* [927.py](927.py)

This repository contains a pure-Python solution for **[Project Euler](https://ourbigbook.com/codex/project-euler) 927**.

## Key observations

### 1) Tree counting recurrence
Let `t_k(n)` be the number of full `k`-ary trees of height at most `n`.
A tree is either
- a leaf, or
- a root with `k` ordered children, each itself a full `k`-ary tree of height at most `n-1`.

So

- `t_k(0) = 1`
- `t_k(n) = 1 + t_k(n-1)^k`

For a fixed `k`, the [sequence](https://ourbigbook.com/codex/sequence) [modulo](https://ourbigbook.com/codex/modulo-operation) `m` is generated by iterating the map

`f_k(x) = 1 + x^k (mod m)`

starting at `x = 1`.

### 2) Reaching 0 is equivalent to being on the same cycle
`m ∈ S_k` means there exists `n` with `t_k(n) ≡ 0 (mod m)`, i.e. the orbit of `1` under `f_k` reaches `0`.
Since `f_k(0) = 1`, if `0` is ever reached then the orbit immediately returns to `1`, so the orbit is purely periodic
(there is no “tail”). In particular, `0` and `1` lie on the same cycle.

### 3) Big simplification for prime moduli
When the modulus is a [prime](https://ourbigbook.com/codex/prime) `q`, we work in the [finite field](https://ourbigbook.com/codex/finite-field) `F_q`.

If `gcd(k, q-1) = 1`, then the map `x ↦ x^k` permutes `F_q`, so `f_k(x) = 1 + x^k` is also a [permutation](https://ourbigbook.com/codex/permutation).
In a [permutation](https://ourbigbook.com/codex/permutation), if `0 → 1` then `0` and `1` are automatically in the same cycle, which means starting from `1`
we must eventually reach `0`.

**Consequence:** for [prime](https://ourbigbook.com/codex/prime) `q`, the only exponents `k` that can possibly fail are those with `k | (q-1)`.

The problem requires intersection over **[prime exponents](https://ourbigbook.com/codex/prime-exponent)** `p`, so for a [prime](https://ourbigbook.com/codex/prime) modulus `q` we only need to test
[prime divisors](https://ourbigbook.com/codex/prime-divisor) of `q-1` (and for odd `q`, that always includes `p = 2`).

### 4) Building composite solutions by multiplicativity (squarefree products)
For [coprime](https://ourbigbook.com/codex/coprime) moduli, the iteration [modulo](https://ourbigbook.com/codex/modulo-operation) the product is just the [CRT](https://ourbigbook.com/codex/chinese-remainder-theorem) product of the iterations [modulo](https://ourbigbook.com/codex/modulo-operation) each factor.
Because reaching `0` forces a pure cycle with `0` immediately before returning to `1`, the “hit time” is congruent to `-1`
[modulo](https://ourbigbook.com/codex/modulo-operation) the cycle length for each [prime factor](https://ourbigbook.com/codex/prime-factor). Those [integer congruences](https://ourbigbook.com/codex/integer-congruence) always align, so if every [prime factor](https://ourbigbook.com/codex/prime-factor) is “good” then their
(squarefree) product is also good.

So after collecting all [primes](https://ourbigbook.com/codex/prime) `q ≤ N` that work for every required [prime exponent](https://ourbigbook.com/codex/prime-exponent), we generate all [subset](https://ourbigbook.com/codex/subset) products of these
[primes](https://ourbigbook.com/codex/prime) that are `≤ N`, and sum them.

## Algorithms used

- **Odd-only [number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve)** to list [primes](https://ourbigbook.com/codex/prime) up to `N`.
- **[Cycle detection](https://ourbigbook.com/codex/cycle-detection) (Brent’s [algorithm](https://ourbigbook.com/codex/algorithm))** to decide whether the orbit of `1` under `x ↦ 1 + x^p (mod q)` reaches `0`,
  without storing visited values.
- **[Trial division](https://ourbigbook.com/codex/trial-division) factorization** of `q-1` (only for the very small set of candidate [primes](https://ourbigbook.com/codex/prime) that pass the `p=2` test).
- **Subset-product enumeration** to sum all squarefree products `≤ N`.

## How to run

```bash
python3 main.py
```

This prints `R(10^7)`.

You can also pass a custom `N`:

```bash
python3 main.py 1000
```

The code includes the two assertions given by the problem statement.
