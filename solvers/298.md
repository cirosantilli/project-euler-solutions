# Project Euler 298 Solution - Selective Amnesia

<https://projecteuler.net/problem=298>:

* [298.py](298.py)

This solution computes the [expected value](https://ourbigbook.com/codex/expected-value) of \(|L-R|\) after 50 turns.

## Main techniques

### 1) Model the players as cache policies
- **Larry** behaves exactly like an **[LRU cache](https://ourbigbook.com/codex/lru-cache)** of capacity 5: on a hit, the item becomes most-recently-used; on a miss, insert and evict the least-recently-used.
- **Robin** behaves like a **[FIFO cache](https://ourbigbook.com/codex/fifo-cache)** ([FIFO queue](https://ourbigbook.com/codex/fifo-queue)) of capacity 5: hits do not change order; misses append and evict the oldest.

So a game state is fully described by two *ordered* memories:
- Larry: MRU → [LRU](https://ourbigbook.com/codex/lru-replacement)
- Robin: oldest → newest

### 2) Symmetry reduction via canonicalization
The numbers 1…10 are i.i.d. and [uniformly distributed](https://ourbigbook.com/codex/uniformly-distributed), so the *labels* do not matter—only the **equality/overlap pattern** between the two memories does.

After each update, the state is **canonicalized** by renaming the distinct numbers that appear in either memory to `0..k-1` in deterministic “first-seen” order (scan Larry then Robin).  
All states that differ only by a [permutation](https://ourbigbook.com/codex/permutation) of labels collapse to the same canonical state.

This reduces the reachable [Markov chain](https://ourbigbook.com/codex/markov-chain) to **438 states** (including the empty state), making exact [DP](https://ourbigbook.com/codex/dynamic-programming) feasible.

### 3) Exact DP with integer sequence counts
Instead of floating [probabilities](https://ourbigbook.com/codex/probability), the [DP](https://ourbigbook.com/codex/dynamic-programming) carries **exact [integer](https://ourbigbook.com/codex/integer) counts**:

- After `t` turns there are `10^t` equally likely call [sequences](https://ourbigbook.com/codex/sequence).
- For each `(state, score_difference)` we store how many [sequences](https://ourbigbook.com/codex/sequence) lead there.

Each transition has [probability](https://ourbigbook.com/codex/probability) `w/10` where `w` is the number of actual labels producing the same canonical transition (including the “absent number” bucket with weight `10-k`).  
Updating counts is just multiplying by small [integers](https://ourbigbook.com/codex/integer) and adding—no [rounding error](https://ourbigbook.com/codex/round-off-error).

### 4) Final expectation and rounding
After 50 turns:

\[
\mathbb{E}[|L-R|] = \frac{\sum_{d} |d| \cdot \#(d)}{10^{50}}
\]

Because the [denominator](https://ourbigbook.com/codex/denominator) is a power of 10, the value is an **exact [terminating decimal](https://ourbigbook.com/codex/terminating-decimal)**; we then round (half-up) to 8 decimal places.

## Output
Running `python3 main.py` prints the required 8-decimal answer.
