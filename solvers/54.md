# Project Euler 54 Solution - Poker Hands

<https://projecteuler.net/problem=54>:

* [54.py](54.py)
* [54.lean](54.lean)
* [54.py.lean](54.py.lean) (partial Python source proof)

Each poker hand is mapped to a **comparable rank [tuple](https://ourbigbook.com/codex/tuple)** so that normal lexicographic comparison determines the winner.

## Key idea: normalize each hand into a rank tuple
For 5 cards we compute:
- `values` (2..14) and `suits`
- `is_flush` (all suits equal)
- `is_straight` (5 distinct values and consecutive), including the special case **A-2-3-4-5** treated as straight-high = 5
- a frequency table of card values (pairs, trips, quads)

We then return a [tuple](https://ourbigbook.com/codex/tuple) of the form:

`(category, tiebreakers...)`

Where `category` increases with hand strength:
0 High card  
1 One pair  
2 Two pairs  
3 Three of a kind  
4 Straight  
5 Flush  
6 Full house  
7 Four of a kind  
8 Straight flush (covers royal flush as the highest straight flush)

Tiebreakers are added in the exact order used by poker rules, e.g.:
- Pair: `(1, pair_value, remaining_kickers_desc)`
- Two pairs: `(2, high_pair, low_pair, kicker)`
- Full house: `(6, trip_value, pair_value)`
- Flush/high card: `(category, values_desc)`

## Algorithm
For each input line:
1. Split into 10 cards (first 5 for Player 1, last 5 for Player 2)
2. Compute both rank [tuples](https://ourbigbook.com/codex/tuple)
3. Count cases where Player 1's [tuple](https://ourbigbook.com/codex/tuple) is greater

This runs in O(N) with tiny constant factors (N=1000), easily within limits.

The provided code includes `assert`s for the five example hands.

The Python source proof covers card parsing, exact frequency counts, Unicode tokenization, whitespace-only lines, and splitting the two hands. It composes the nonempty-line path with supplied proofs of the hand ranks and their comparison, and proves that different categories decide the winner without inspecting tie-breakers.

The reference repeats each rank according to its frequency in pair, trip, and related tie-break keys. [PokerTiebreaks.lean](../ProjectEulerSolutions/Lib/PokerTiebreaks.lean) proves that these fixed repetitions preserve the compressed keys' lexicographic order. The [reference comparator source proof](../data/project-euler-statements/data/py/project_euler_statements/p54.py.lean) covers empty and unequal-length integer lists as well. The hand-ranking proof and full solver equivalence remain in progress.
