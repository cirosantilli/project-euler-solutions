Suppose the common digit string is `d_r ... d_1 d_0`, and put

`D(x) = sum d_i x^i`.

The condition is `D(b) = 2D(a)`, or equivalently

`d_0 = sum_{i=1}^r d_i (b^i - 2a^i)`.

This immediately makes the infinite sum over `b` finite. If `b >= 3a`, then every coefficient on the right is at least `a`, so no positive solution is possible. Hence only `a < b < 3a` need be considered.

For `2a <= b < 3a`, all coefficients are non-negative and any term of degree at least two is already too large. Thus only two-digit strings are possible. At `b = 2a`, the maximum is `(a-1)0_a`; otherwise, with `w = b - 2a`, the largest leading digit is `floor((a-1)/w)`.

Now take `a < b < 2a`, and let `r` be the smallest positive integer with

`b^r > 2a^r`.

For `i < r`, `b^i - 2a^i < 0`, while the coefficient at `r` is positive. A solution cannot have degree below `r`. It cannot have degree above `r` either: the maximum available cancellation from all negative coefficients, including the allowance `d_0 <= a-1`, is less than `2a^r`, whereas

`b^(r+1) - 2a^(r+1) > 2(b-a)a^r >= 2a^r`.

So every non-zero solution has degree exactly `r`.

Set

`w_r = b^r - 2a^r`,

and, for `i < r`,

`v_i = 2a^i - b^i > 0`.

Then

`d_0 = d_r w_r - sum_{i=1}^{r-1} d_i v_i`.

For a fixed leading digit `d_r`, the lower weighted sum therefore has to lie in

`[d_r w_r - (a-1), d_r w_r]`.

To maximize `n`, maximize the digits lexicographically. The solver tries each digit from `a-1` down to zero and prunes exactly using

`C_i = (a-1) sum_{j=1}^i v_j`,

the largest sum that the remaining lower digits can make. The first feasible branch is consequently the largest valid digit string, not a heuristic choice.

Finally, sum `F(a,b)` only for `a < b < 3a`, and then sum `G(a)` for `2 <= a <= 20`.
