# Project Euler 79 Solution - Passcode Derivation

<https://projecteuler.net/problem=79>:

* [79.py](79.py)
* [79.lean](79.lean)

Each successful login attempt is a 3-digit [string](https://ourbigbook.com/codex/string) `abc` meaning:

- `a` appears before `b`
- `b` appears before `c`

These are precedence constraints. Collect all [digits](https://ourbigbook.com/codex/numerical-digit) that appear, build a [directed graph](https://ourbigbook.com/codex/directed-graph) with [edges](https://ourbigbook.com/codex/edge) for each constraint (e.g., `a -> b`, `b -> c`), and then compute a **[topological ordering](https://ourbigbook.com/codex/topological-ordering)** of this [graph](https://ourbigbook.com/codex/graph).

Because the passcode must include each used [digit](https://ourbigbook.com/codex/numerical-digit) at least once and must respect all ordering constraints, the shortest possible passcode is exactly the [digits](https://ourbigbook.com/codex/numerical-digit) in a valid [topological order](https://ourbigbook.com/codex/topological-order) (one occurrence per unique [digit](https://ourbigbook.com/codex/numerical-digit)). The provided solution uses [Kahn's algorithm](https://ourbigbook.com/codex/kahn-s-algorithm) (indegree-based [topological sort](https://ourbigbook.com/codex/topological-sorting)) with a [heap](https://ourbigbook.com/codex/heap) for deterministic output.
