# Project Euler 511 Solution - Sequences with Nice Divisibility Properties

<https://projecteuler.net/problem=511>:

* [511.py](511.py)

We count “nice” [sequences](https://ourbigbook.com/codex/sequence) `(a1..an)` where:

1. `ai | n` for every `i` (so each `ai` is a **positive [divisor](https://ourbigbook.com/codex/divisor)** of `n`)
2. `n + a1 + … + an ≡ 0 (mod k)`

Let `Seq(n,k)` be the number of such [sequences](https://ourbigbook.com/codex/sequence). The task asks for the **last 9 digits** of `Seq(1234567898765, 4321)`.

---

## Key ideas

### 1) Reduce the problem to a cyclic convolution power

Let `D` be the set of [divisors](https://ourbigbook.com/codex/divisor) of `n`. Only the [residue classes](https://ourbigbook.com/codex/residue-class) `d mod k` matter.

Create a [vector](https://ourbigbook.com/codex/vector) `v` of length `k`:

- `v[r] = #{ d ∈ D : d ≡ r (mod k) }`

Choosing each `ai` independently means the distribution of the sum of [residue classes](https://ourbigbook.com/codex/residue-class) is the **n-fold [cyclic convolution](https://ourbigbook.com/codex/cyclic-convolution)** of `v` with itself:

- `v^{*n}[s] = # of length-n picks whose residue-sum ≡ s (mod k)`

The constraint `n + sum(ai) ≡ 0 (mod k)` is equivalent to:

- `sum(ai) ≡ -n (mod k)`

So:

- `Seq(n,k) = v^{*n}[ (-n) mod k ]`

We only need it [modulo](https://ourbigbook.com/codex/modulo-operation) `10^9` (last nine digits).

---

### 2) Exponentiation by squaring in the convolution algebra

We compute `v^{*n}` with [binary exponentiation](https://ourbigbook.com/codex/exponentiation-by-squaring):

- [Identity element](https://ourbigbook.com/codex/identity-element) is `[1,0,0,…]`
- Multiplication is [cyclic convolution](https://ourbigbook.com/codex/cyclic-convolution) [modulo](https://ourbigbook.com/codex/modulo-operation) `10^9`

This takes `O(log n)` multiplications.

---

### 3) Fast cyclic convolution for `k = 4321 = 29 × 149`

A naive [convolution](https://ourbigbook.com/codex/convolution) is `O(k^2)`, too slow for `k=4321` and ~60 multiplications.

We accelerate each [cyclic convolution](https://ourbigbook.com/codex/cyclic-convolution) with a length-4321 [DFT](https://ourbigbook.com/codex/discrete-fourier-transform):

- Because `4321 = 29 × 149` and `gcd(29,149)=1`, we can use the
  **[Good-Thomas algorithm](https://ourbigbook.com/codex/good-thomas-algorithm) / [Prime Factor Algorithm](https://ourbigbook.com/codex/good-thomas-algorithm)** to compute the [DFT](https://ourbigbook.com/codex/discrete-fourier-transform) via two small [DFTs](https://ourbigbook.com/codex/discrete-fourier-transform):
  - 29-point [DFTs](https://ourbigbook.com/codex/discrete-fourier-transform) on columns
  - 149-point [DFTs](https://ourbigbook.com/codex/discrete-fourier-transform) on rows
- This gives about `29^2·149 + 149^2·29` operations per transform (much less than `4321^2`).

---

### 4) Exact modular results with floating FFT via coefficient splitting

We must compute [convolution](https://ourbigbook.com/codex/convolution) **mod `10^9`**, but the [FFT](https://ourbigbook.com/codex/fast-fourier-transform) uses floating [complex numbers](https://ourbigbook.com/codex/complex-number).

To keep rounding reliable, each coefficient `x (mod 10^9)` is split into 15-bit chunks:

- `x = x0 + x1·B`, with `B = 2^15`
- `x0 < B`, `x1` is small

Then only **three** [integer](https://ourbigbook.com/codex/integer) [convolutions](https://ourbigbook.com/codex/convolution) are needed:

- `c00 = conv(x0, y0)`
- `c11 = conv(x1, y1)`
- `cs  = conv(x0+x1, y0+y1)`
- `cross = cs - c00 - c11 = conv(x0,y1) + conv(x1,y0)`

Each intermediate [integer](https://ourbigbook.com/codex/integer) [convolution](https://ourbigbook.com/codex/convolution) coefficient stays below `2^53`, so rounding back to [integers](https://ourbigbook.com/codex/integer) is stable; then we recombine everything [modulo](https://ourbigbook.com/codex/modulo-operation) `10^9`.

We also use a faster “square” path for `a*a`, saving [FFTs](https://ourbigbook.com/codex/fast-fourier-transform) during [exponentiation](https://ourbigbook.com/codex/exponentiation).

---

## What the program outputs

Running `main.py` prints the last 9 digits of `Seq(1234567898765, 4321)`.

The script also includes the problem statement’s check values as `assert`s:

- `Seq(3,4) = 4`
- `Seq(4,11) = 8`
- last 9 digits of `Seq(1111,24)` is `840643584`
