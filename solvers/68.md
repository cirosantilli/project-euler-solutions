# Project Euler 68 Solution - Magic n-gon Rings

<https://projecteuler.net/problem=68>:

* [68.py](68.py)
* [68.lean](68.lean)

`solve(n=5, digits=16)` returns the greatest canonical decimal string of the requested length for a magic n-gon using labels 1 through 2n. It returns an empty string when no such ring exists, including sizes below three. The default solves the original magic five-gon problem.

Each line consists of `(outer[i], inner[i], inner[(i+1) % n])`. All lines have a common sum S. The representation starts at the least outer label and reads clockwise.

Let I be the sum of the inner labels. The sum of all labels is `n*(2*n+1)`. Summing the n lines counts every outer label once and every inner label twice, so

```
n*S = n*(2*n+1) + I.
```

An inner set determines S whenever the right-hand side is divisible by n. Once the inner labels are ordered, each outer label is forced:

```
outer[i] = S - inner[i] - inner[(i+1) % n].
```

The decimal length has a similar identity. Let D be the sum of the decimal widths of labels 1 through 2n. Then the representation has length `D + sum(width(x) for x in inner)`, since inner labels appear twice.

For the default five-gon, D is 11. A 16-digit result therefore needs five one-digit inner labels, which places 10 outside. A requested length of 17 instead permits 10 inside. The digit-count identity provides the filter for every size and requested length.

The solver:

1. Chooses n inner labels from all 2n labels and checks the required decimal length.
2. Derives the line sum and rejects nonintegral values.
3. Enumerates the cyclic orders of the selected inner labels.
4. Computes the forced outer labels and checks that they are exactly the unused labels, without repetition.
5. Rotates to the least outer label, serializes the lines, and retains the greatest string.

The default digit filter leaves 126 inner sets before the divisibility check, each with 120 orders. The reference independently enumerates complete assignments of all 2n labels.

Examples:

```
solve(3, 9)  = "432621513"
solve(4, 12) = "462723831516"
solve()     = "6531031914842725"
solve(5, 17) = "28797161103104548"
```
