# Project Euler 80 Solution - Square Root Digital Expansion

<https://projecteuler.net/problem=80>

* [Python solver](80.py)
* [Lean solver](80.lean)
* [Python equivalence proof](80.py.lean)

`solve(limit, digits)` sums the first `digits` decimal digits of each irrational square root from 1 through `limit`, counting digits before the decimal point. Its domain is `limit >= 0` and `digits >= 1`; the defaults are both 100. Perfect squares contribute zero.

Let `r = isqrt(n)` and let `width` be the number of decimal digits in `r`. For a nonsquare `n`, its integer square root has the same integer width as its square root.

* When `digits >= width`, the required prefix is `isqrt(n * 10 ** (2 * (digits - width)))`.
* When `digits < width`, the prefix lies entirely within the integer part and is `r // 10 ** (width - digits)`.

Summing the decimal digits of these integer prefixes avoids floating-point rounding. Accounting for `width` also handles bounds above 100, where square roots can have multiple digits before the decimal point. The statement's example is `sqrt_digits_sum(2, 100) == 475`.

The structural source proof establishes termination and equivalence for every pair of arguments in the specified domain. It covers both prefix branches, the reference’s allocated digit lists, the optimized digit-string sum, and the complete summation loops. Separate arithmetic lemmas bound the prefixes between consecutive squares; the proof does not evaluate the fixed Euler instance.
