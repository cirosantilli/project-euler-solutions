# Project Euler 23 Solution - Non-Abundant Sums

<https://projecteuler.net/problem=23>:

* [23.py](23.py)
* [23.lean](23.lean)

## Key idea
We need the [sum](https://ourbigbook.com/codex/sum) of all [positive integers](https://ourbigbook.com/codex/positive-integer) `n ≤ 28123` that **cannot** be written as the [sum](https://ourbigbook.com/codex/sum) of two [abundant numbers](https://ourbigbook.com/codex/abundant-number).

A number is **abundant** if the [sum](https://ourbigbook.com/codex/sum) of its [proper divisors](https://ourbigbook.com/codex/proper-divisor) is greater than the number.

## Approach
1. **Compute [sum of proper divisors](https://ourbigbook.com/codex/proper-divisor-sum) for every `n ≤ 28123`** using a sieve-like method:
   - For each [divisor](https://ourbigbook.com/codex/divisor) `d`, add `d` to all [multiples](https://ourbigbook.com/codex/integer-multiple) `2d, 3d, ...`.
   - This gives `sum_proper_divisors[n]` for all `n` in about `O(N log N)` time.

2. **Collect all [abundant numbers](https://ourbigbook.com/codex/abundant-number)**:
   - `abundant = [n | sum_proper_divisors[n] > n]`.

3. **Mark all [sums](https://ourbigbook.com/codex/sum) of two [abundant numbers](https://ourbigbook.com/codex/abundant-number)** up to the limit:
   - Use a `bytearray can` where `can[s] = 1` if `s` is representable.
   - For each abundant `a`, add it to [abundant numbers](https://ourbigbook.com/codex/abundant-number) `b ≥ a` and stop when `a + b > 28123`.

4. **[Sum](https://ourbigbook.com/codex/sum) all numbers not marked**:
   - `answer = sum(n for n in 1..28123 if can[n] == 0)`.

## Complexity
- [Number-theoretic sieve](https://ourbigbook.com/codex/number-theoretic-sieve) for divisors: `O(N log N)` with `N = 28123`.
- Marking [sums](https://ourbigbook.com/codex/sum): roughly `O(A^2)` in the number of abundant values `A`, but with early breaks when [sums](https://ourbigbook.com/codex/sum) exceed the limit; runs fast for this bound.

The program prints the final result.
