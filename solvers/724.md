# Project Euler 724 Solution - Drone Delivery

<https://projecteuler.net/problem=724>:

* [724.py](724.py)

This solution turns the drone process into a **[coupon-collector](https://ourbigbook.com/codex/coupon-collector-problem)** problem and computes the required [expectation](https://ourbigbook.com/codex/expected-value) using **[harmonic numbers](https://ourbigbook.com/codex/harmonic-number)** plus an **[asymptotic expansion](https://ourbigbook.com/codex/asymptotic-expansion)**.

## Key observations

### 1) Total distance depends only on the stopping time
Let `C` be the number of instructions until **every** drone has been instructed at least once ([coupon collector](https://ourbigbook.com/codex/coupon-collector-problem) completion time).

At second `t` (starting from `t = 0`), exactly one drone’s speed increases by 1, so the **sum of all speeds** after that update is always `t+1`.

Therefore, the **total distance** traveled by all drones over `C` seconds is deterministic given `C`:
\[
\sum_{t=0}^{C-1} (t+1)=\frac{C(C+1)}{2}.
\]

Since there are `n` packages, the average distance (and hence the expected distance of a randomly chosen package) is:
\[
E(n)=\mathbb{E}\left[\frac{C(C+1)}{2n}\right].
\]

### 2) Coupon collector moments
In [coupon collection](https://ourbigbook.com/codex/coupon-collector-problem) with `n` equally-likely coupons, the waiting times to collect a new coupon are independent [geometric random variables](https://ourbigbook.com/codex/geometric-random-variable) with parameters `j/n` for `j=1..n`.

This yields closed forms for the first two moments, which combine neatly into:
\[
\mathbb{E}[C(C+1)] = n^2\left(H_n^2 + H_n^{(2)}\right),
\]
where
- \(H_n = \sum_{k=1}^n \frac{1}{k}\) is the [harmonic number](https://ourbigbook.com/codex/harmonic-number)
- \(H_n^{(2)} = \sum_{k=1}^n \frac{1}{k^2}\) is the second-order [harmonic number](https://ourbigbook.com/codex/harmonic-number)

So the final formula is:
\[
E(n) = \frac{n}{2}\left(H_n^2 + H_n^{(2)}\right).
\]

### 3) Fast evaluation for `n = 10^8`
Direct [summation](https://ourbigbook.com/codex/summation) is too slow for \(10^8\), so the code uses [Euler–Maclaurin](https://ourbigbook.com/codex/euler-maclaurin-formula) [asymptotic expansions](https://ourbigbook.com/codex/asymptotic-expansion):

- \(H_n = \log n + \gamma + \frac{1}{2n} - \frac{1}{12n^2} + \cdots\)
- \(H_n^{(2)} = \frac{\pi^2}{6} - \frac{1}{n} + \frac{1}{2n^2} - \frac{1}{6n^3} + \cdots\)

For \(n=10^8\), only a few terms are needed to get **far better than 0.5** absolute accuracy in the final value, making rounding safe.
