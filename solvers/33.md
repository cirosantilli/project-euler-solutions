# Project Euler 33 Solution - Digit Cancelling Fractions

<https://projecteuler.net/problem=33>:

* [33.py](33.py)
* [33.lean](33.lean)

We search all two-digit [fractions](https://ourbigbook.com/codex/fraction) `n/d` with `10 ≤ n < d < 100` and look for the “curious” property where cancelling a common [digit](https://ourbigbook.com/codex/numerical-digit) (incorrectly) produces an equivalent [reduced fraction](https://ourbigbook.com/codex/reduced-fraction).

Key points:
- Exclude trivial cases like `30/50` by skipping [fractions](https://ourbigbook.com/codex/fraction) where both numbers end in `0`.
- Only attempt cancelling common [digits](https://ourbigbook.com/codex/numerical-digit) `1..9` (ignore `0` cancels).
- For each common [digit](https://ourbigbook.com/codex/numerical-digit) `c`, remove one occurrence from [numerator](https://ourbigbook.com/codex/numerator) and [denominator](https://ourbigbook.com/codex/denominator) to get single-digit `n2/d2`.
- Check exact equality using [cross-multiplication](https://ourbigbook.com/codex/cross-multiplication): `n * d2 == d * n2`.
- Multiply the four found [fractions](https://ourbigbook.com/codex/fraction) and reduce the [product](https://ourbigbook.com/codex/product) by `gcd`; output the reduced [denominator](https://ourbigbook.com/codex/denominator).

This finds exactly: `16/64, 19/95, 26/65, 49/98`, whose [product](https://ourbigbook.com/codex/product) in lowest terms has [denominator](https://ourbigbook.com/codex/denominator) `100`.
