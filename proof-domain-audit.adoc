= Python proof-domain audit

This audit covers the Python solver and reference interfaces for problems 1 through 62, their `Requires` annotations, default adapters, and the documented proof claims.

Prefer a meaningful argument shared by both implementations. A reference-only search limit changes an unbounded problem into a bounded one and is not an acceptable substitute. A mathematical bound derived from the inputs or the problem definition is acceptable. For a fixed problem without a useful parameter, retain `Equiv` and prefer structural proofs through shared mathematical models. A completed interpreter observation can establish termination; running out of observation fuel cannot.

Source proofs still awaiting replacement are retained as `.py.lean.attempt`; their README proof links are removed, and they are not counted as current proofs. Problem 36 has structural equivalence and termination proofs for every nonnegative limit, with no fixed prefix cutoff. Problem 40 has a structural equivalence and termination proof for every finite tuple of positive positions, with no maximum position. Problem 52 has structural equivalence for every positive multiplier: both searches terminate at the least positive solution for multipliers one through nine and diverge for larger multipliers, where digit widths rule out a solution. Unchanged zero-argument `Equiv` proofs remain in place; they need not be discarded merely because they have no arguments.

Problem 62 has structural equivalence and support proofs for every signed class size. Both unbounded source searches return exactly when a completed digit width contains a matching class, with the same result; otherwise both diverge. The reference root boundaries are derived from the requested digit width. No external search limit or assumption that every class size exists is needed.

Problem 45 has structural termination and equivalence proofs for every signed `after` threshold. A recurrence supplies arbitrarily large common pentagonal and hexagonal values. Both source loops reach the least common value above the threshold; the three-way merge advances its least cursor without passing that answer.

Problem 46 has structural equivalence and support proofs for every signed `after` threshold. Both functions terminate exactly when a counterexample above that threshold exists, returning the least one; otherwise both diverge. The default call has a separate termination proof from the explicit counterexample 5777.

Problem 34 has structural termination and equivalence proofs for every numeral base at least two. Both source searches sum fixed points with at least two digits in that base. A general bound theorem contains every positive fixed point, without a fixed base or digit-width cutoff. The default call inherits termination from the arbitrary-base proof.

Problem 23 has structural termination and equivalence proofs for every signed upper bound. Negative bounds return zero, and the empty abundant list and marking loops are covered for small nonnegative bounds. Statement examples execute outside the solver.

Problem 26 has structural termination and equivalence proofs for every signed upper bound. Both searches consider only positive denominators, keep the least denominator on equal cycle lengths, and return zero exactly when the candidate range is empty.

Problem 38 has structural termination and equivalence proofs for every signed target width. The reference collector and optimized running maximum implement the same complete candidate set. Seed and product-count bounds follow from the requested width. Both functions return zero for widths below two or above nine; two positive products need at least two digits, and decimal notation cannot supply digit ten. The default call inherits termination from the general proof.

Problem 37 has structural source equivalence and support proofs for every numeral base at least two. Both searches terminate exactly when the right-truncatable-prime tree exhausts, returning the sum of all primes with at least two digits that remain prime under truncation from either end; otherwise both supported-diverge. The proof establishes complete, duplicate-free frontiers and agreement of arithmetic suffix checks with the reference's digit-list truncations. The decimal certificate proves global completeness and default-call termination without imposing a bound on the arbitrary-base theorem.

Problem 51 has structural equivalence and support proofs for every signed family threshold. Both unbounded source searches return exactly when a qualifying family exists, returning its least prime; otherwise both diverge. The checked eight-member witness establishes termination for every threshold at most eight and for the default call. Thresholds above ten are impossible because there are only ten replacement digits. For thresholds nine and ten, termination retains the general existence condition. The Lean statement uses zero for absence in its mathematical minimum and makes no universal existence assumption.

== Remaining implementation and proof restrictions

[cols="1,3,3"]
|===
| Problem | Finding | Required follow-up
| 11 | The proof fixes the grid to the original 20 by 20 shape. | Consider general rectangular grids; the current theorem is restricted.
| 17 | Number spelling and its proof stop at 1000. | This is the original problem's range, not an exhaustion bound. A broader naming convention would be a new parameterized problem.

| 44 | Both implementations accept the same finite pentagonal-index bound. | This is a valid bounded parameterization, but equivalence alone does not prove that the default answer is the global minimum over all indices.
| 62 | Unbounded equivalence and a termination characterization hold for every signed class size. | A separate `Returns` theorem for the default target still needs a verified existence witness.
|===

Other explicit bounds were checked for their role: the quadratic coefficient ranges in problem 27, the fifth power in problem 30, the target decimal digits in problems 32 and 38, the four-digit progression in problem 49, the fifty reverse-and-add steps in problem 55, and the one-tenth spiral threshold in problem 58 come from their stated problem variants. Problem 60's bound is shared by both implementations and its theorem covers every signed bound; it is not a reference-only cutoff. Such shared parameters still deserve review when a more natural generalization is available.

Further useful shared parameters include coefficient ranges in problem 27, the digit-power exponent in problem 30, the target digit set in problem 32 and arbitrary digit subsets in problem 38, the substring divisors in problem 43, and the diagonal-prime ratio in problem 58. Existing fixed-input proofs do not replace these prospective generalized results. Problems 34, 40, 45, and 46 have shared base, position, and threshold parameters.

The default root-partition certificate for problem 62 is numerical evidence toward a termination witness, not an execution cap. Its class batches were checked, but final assembly has not passed and is not a completed proof.
