# Project Euler 703 Solution - Circular Logic II

<https://projecteuler.net/problem=703>:

* [703.py](703.py)

This solution counts the number of [Boolean functions](https://ourbigbook.com/codex/boolean-function) \(T : B^n \to B\) such that
for every state \(x\), the pair \((x, f(x))\) is **never** simultaneously mapped to `true`.
The program outputs \(S(20) \bmod 1{,}001{,}001{,}011\).

## Key ideas

### 1) Functional graph viewpoint
The map \(f : B^n \to B^n\) gives a [directed graph](https://ourbigbook.com/codex/directed-graph) where every [graph vertex](https://ourbigbook.com/codex/vertex-of-a-graph) has **[out-degree](https://ourbigbook.com/codex/outdegree) 1**.
Such [graphs](https://ourbigbook.com/codex/graph) are *[functional graphs](https://ourbigbook.com/codex/functional-graph)*: each [connected component](https://ourbigbook.com/codex/connected-component) consists of one [directed cycle](https://ourbigbook.com/codex/directed-cycle),
with directed in-trees feeding into the cycle.

The constraint

\[
T(x) \land T(f(x)) = \text{false}
\]

means you can’t select both endpoints of any directed [edge of a graph](https://ourbigbook.com/codex/edge-of-a-graph). Since every [graph vertex](https://ourbigbook.com/codex/vertex-of-a-graph) appears as
the tail of exactly one [edge of a graph](https://ourbigbook.com/codex/edge-of-a-graph), this is exactly the **[independent set](https://ourbigbook.com/codex/independent-set)** constraint on the
underlying (undirected) [graph edges](https://ourbigbook.com/codex/edge-of-a-graph) \(\{x, f(x)\}\).

So \(S(n)\) = *number of [independent sets](https://ourbigbook.com/codex/independent-set)* in that [functional graph](https://ourbigbook.com/codex/functional-graph).

### 2) Pruning to find cycles (Kahn-style indegree elimination)
To separate [trees](https://ourbigbook.com/codex/tree-graph-theory) from cycles efficiently:

- compute [indegrees](https://ourbigbook.com/codex/indegree) of all nodes
- repeatedly remove nodes with [indegree](https://ourbigbook.com/codex/indegree) 0, decrementing their successor’s [indegree](https://ourbigbook.com/codex/indegree)
- what remains are exactly the cycle nodes

This runs in \(O(2^n)\) time and avoids [recursion](https://ourbigbook.com/codex/recursion).

### 3) Tree DP absorbed into cycle node “weights”
For every node, consider its incoming nodes (its “children” in the in-tree rooted at its successor).

For a [rooted tree](https://ourbigbook.com/codex/rooted-tree), the independent-set [DP](https://ourbigbook.com/codex/dynamic-programming) is:

- `dp0[v]`: ways in the subtree when `v` is **not** chosen  
  \(\prod_{u \in children(v)} (dp0[u] + dp1[u])\)
- `dp1[v]`: ways in the subtree when `v` **is** chosen  
  \(\prod_{u \in children(v)} dp0[u]\)

During pruning, children are processed before their parent, so we can accumulate products
incrementally and end up with `acc0/acc1` values for each cycle node representing the whole
in-tree attached to that node.

### 4) Cycle DP with two boundary cases
After absorbing [trees](https://ourbigbook.com/codex/tree-graph-theory), each cycle node has:

- `weight0` = ways if the cycle node is **not** selected
- `weight1` = ways if the cycle node **is** selected

Now we count [independent sets](https://ourbigbook.com/codex/independent-set) on a cycle with weighted nodes. This is done by converting
it into two path problems:

1. first node **not** selected
2. first node **selected** (which forces the last node **not** selected)

Each path is solved with a simple two-state [DP](https://ourbigbook.com/codex/dynamic-programming) (previous node selected vs not selected).

### 5) Modular arithmetic + memory efficiency
All computations are done [modulo](https://ourbigbook.com/codex/modulo) the required modulus.
The [state space](https://ourbigbook.com/codex/state-space) is size \(2^n\), so the implementation uses:

- `array('I')` (32-bit [integers](https://ourbigbook.com/codex/integer)) for large numeric arrays
- `bytearray` for boolean markers

This keeps memory usage low enough even for \(n=20\).

## Complexity
Let \(N = 2^n\).

- Time: \(O(N)\)
- Memory: \(O(N)\)
